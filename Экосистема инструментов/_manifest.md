# Экосистема инструментов — _manifest

## Что это за проект

База решений по внешнему инструментарию для AI-разработки. North star — **не переисследовать один и тот же
инструмент дважды и не ломать рабочую среду импульсивной установкой**. Каждая оценка — отдельная карточка
с вердиктом.

## Что сюда заходит

- Оценки Claude Code плагинов, skill-паков, мета-харнессов, MCP-серверов.
- Решения об установке в глобальную среду и их влиянии на все проекты машины.

## Что не заходит

- Наши собственные навыки и движок → [`_Движок`](<../_Движок/Канон/_manifest.md>).
- Инструментарий конкретного клиента → в PARA-дерево этого проекта (напр. `viklimat\06 — Инструменты\`).

- [Справочник — Обзор SEO-инструментов с GitHub](<03 — Ресурсы/Оценки инструментов/Справочник — Обзор SEO-инструментов с GitHub.md>) — 267 репозиториев, 12 направлений; популярные «замены Semrush» — оболочки над DataForSEO (закрыт для РФ); берём `advertools`, на примете GSC-MCP, Яндекс-MCP с несколькими кабинетами, тренды; ключи конкурентов в Рунете — только Keys.so.
- [Справочник — Оценка Keys.so](<03 — Ресурсы/Оценки инструментов/Справочник — Оценка Keys.so.md>) — база выдачи Рунета с API: ключи конкурентов, реклама, ссылки, нейровыдача; вердикт: забрать, подписку брать под план; правила — навык `keysso`.
- [Справочник — Оценка codex (второй агент)](<03 — Ресурсы/Оценки инструментов/Справочник — Оценка codex (второй агент).md>) — вторая модель для независимого ревью; правила вызова — навык `second-agent`.
- [Справочник — Оценка AISA (aisa.one)](<03 — Ресурсы/Оценки инструментов/Справочник — Оценка AISA (aisa.one).md>) — шлюз «один ключ ко всему» (581 инструмент через MCP, SEO-данные, 110+ LLM); вердикт: механика хорошая, но для российского контура два ключевых провайдера запрещены их же условиями, Яндекса в данных почти нет.
