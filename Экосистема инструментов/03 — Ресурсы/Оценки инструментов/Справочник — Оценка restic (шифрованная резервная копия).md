# Справочник — Оценка restic (шифрованная резервная копия)

## Краткая суть

- **Что.** [restic/restic](https://github.com/restic/restic) — утилита командной строки: копирует папки в
  зашифрованное хранилище, повторные копии передают только изменения.
- **Вердикт: `забрать`.** Агентную среду не трогает, наружу сам ничего не шлёт, откатывается удалением одного
  файла программы.
- **Зачем нам.** Копия домашних папок агентов — это вся переписка и, вероятно, токены (на машине владельца
  найдены в настройках MCP двух сред и в 9 файлах сессий, проверка 13.10.2026). Такую копию нельзя хранить
  открытой; restic шифрует до записи на носитель.
- **Главный риск — пароль хранилища:** потерян пароль — копия потеряна. Пароль хранится отдельно от носителя.
- **Состояние на 13.10.2026:** не установлен (`command -v restic` — нет). Установка и первый запуск — только
  после «да» владельца.

## 1. Что это и тип

| | |
|---|---|
| Тип | Утилита командной строки, один исполняемый файл. Не плагин, не навык, не MCP |
| Автор | Alexander Neumann и сообщество |
| Лицензия | BSD-2-Clause |
| Версия | 0.19.1 от 05.07.2026 (GitHub API и каталог winget, 13.10.2026) |
| Популярность | 36,5 тыс. звёзд, последнее изменение 11.10.2026, не в архиве |

## 2. Как ставится

Дословно из [документации](https://restic.readthedocs.io/en/stable/020_installation.html), раздел Windows:

```
winget install --exact --id restic.restic --scope Machine
scoop install restic
```

На машине владельца есть `winget`, `scoop` нет. Ключ `--scope Machine` ставит в `%ProgramFiles%` и требует
прав администратора; без него winget ставит в `%LOCALAPPDATA%` текущего пользователя — для копии своих папок
этого достаточно. Откат: `winget uninstall --id restic.restic`.

## 3. Требования

Ничего, кроме носителя под хранилище. Сборка под Windows amd64 есть в выпуске. Ключи API не нужны.

## 4. Что создаёт и меняет

- Хранилище — папка на выбранном носителе (`restic init`). Больше ничего на диске не появляется.
- Фоновых процессов нет. Расписания встроенного нет: документация отсылает к Планировщику заданий Windows.
- `CLAUDE.md`, `AGENTS.md`, настройки агентов, хуки не трогает.

## 5. Глобальность влияния

На агентную среду не влияет: это программа рядом, а не часть среды. Один исполняемый файл в PATH.

## 6. Конфликты с нашей средой

Нет: имени `restic` среди команд, навыков и MCP машины нет (проверено 13.10.2026).

## 7. Безопасность

- **Шифрование:** «All data stored by restic in the repository is encrypted with AES-256 in counter mode and
  authenticated using Poly1305-AES» ([справочник](https://restic.readthedocs.io/en/stable/100_references.html)).
  Без пароля содержимое и имена файлов не читаются.
- **Телеметрия:** в документации не упомянута; по сети утилита ходит только к хранилищу, которое ей указали.
  Локальная папка на внешнем диске — сети нет совсем.
- **Установка:** из каталога winget, без скрипта с чужого сайта. К выпуску приложены контрольные суммы
  `SHA256SUMS` и подпись `SHA256SUMS.asc` (GitHub, 13.10.2026) — при ручной загрузке архива их сверяют.
- **Пароль:** хранить в менеджере паролей и на бумаге, не на том же носителе. У хранилища может быть несколько
  паролей — второй как запасной.
- **Открытые файлы:** базы SQLite сред заняты, пока среда запущена. Для Windows есть ключ `--use-fs-snapshot`
  (теневая копия тома, нужны права администратора); проще — делать копию при закрытых Cursor и приложениях.
- **Что не копировать:** `~/.claude/.credentials.json` и `~/.codex/auth.json` — это вход в аккаунт, документация
  Codex велит обращаться с файлом «как с паролем». Кэши, плагины, журналы, временные файлы — тоже нет.

## 8. Профильность для нас

Прямая: закрывает четвёртый вид обрыва — потерю диска. На машине владельца диски `C:` и `D:` — разделы
одного накопителя, поэтому хранилище на `D:` от потери диска не защищает; нужен внешний носитель.

Замена без установки: `tar` и `gpg` уже есть в Git for Windows, архив шифруется командой
`gpg --symmetric --cipher-algo AES256`. Годится как разовая мера; для еженедельной копии 5–6 ГБ хуже —
каждый раз полный архив.

## Вердикт

**`забрать`** — как утилиту вне агентной среды. Что копировать, куда и как часто — в
[Стандарте — Непрерывность работы с агентами](<../../../Методологии/Стандарт — Непрерывность работы с агентами.md>).

Рассматривались и не выбраны: Kopia (то же с графическим интерфейсом — запасной вариант, если командная
строка неудобна), архив 7-Zip с паролем (не установлен, каждый раз полный архив), облачные диски без своего
шифрования (переписка и токены уходят третьей стороне).
