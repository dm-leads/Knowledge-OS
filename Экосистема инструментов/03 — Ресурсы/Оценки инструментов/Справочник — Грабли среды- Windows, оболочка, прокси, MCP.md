# Справочник — Грабли среды: Windows, оболочка, прокси, MCP

## Краткая суть

- Каждая строка — ловушка, на которой уже теряли время, симптом и проверенное лечение.
- Общий урок: симптом часто указывает не туда. «Нет доступа» оказывается неустановленной зависимостью, «нет
  данных» — отказом доступа, «ошибка сертификата» — кэшем клиента.
- Первое действие при непонятном сбое MCP — запустить сервер руками: клиент глотает настоящую ошибку.

> Для быстрого знакомства человеку может хватить блока выше.
> Ниже начинается полный каноничный текст документа.
> Для агентов, правок, анализа, ревью и разрешения расхождений обязателен полный текст.

## Windows, файлы, git

| Ловушка | Симптом | Лечение |
|---|---|---|
| Python переписывает переводы строк | `open(..., 'w')` на Windows превращает каждый `\n` в `\r\n` — дифф показывает весь файл | Точечная правка — инструментом правки; в скрипте `open(p, encoding='utf-8', newline='')` |
| `git show HEAD:путь` при `autocrlf=true` | Отдаёт CRLF, хотя в индексе LF | Сырой блоб — `git cat-file -p HEAD:путь`; формат — `git ls-files --eol` |
| Клон чужого репозитория с `autocrlf=true` | Правка приходит «файлом целиком», сверка с сервером врёт | В клоне `core.autocrlf false`; сверять по объектам git |
| Двоеточие и `\ / * ? " < > \|` в имени | Запись не падает, а создаёт пустой файл с обрезанным именем без расширения | Проверять имя до записи |
| Ссылка-переход (junction) | Работает без прав администратора и между дисками одного ПК | Для навыков и `.kos`; удалять как ссылку, не рекурсивно по содержимому |

## Оболочка

| Ловушка | Симптом | Лечение |
|---|---|---|
| Кавычки, обратные кавычки, `$` | Команда отработала с кодом 0, содержимое другое | Текст, JSON, SQL, сообщения коммитов — файлом (`-F файл`, `-d @файл`) |
| Длинная команда с кириллицей в Git Bash агента | «unexpected EOF while looking for matching» — строка обрезана по длине в байтах | Файл-скрипт; короткие команды; `git -C` вместо `cd` |
| `git add` со списком путей, один из которых исчез | Ошибка pathspec — не добавлено ничего, коммит уходит пустым по содержимому | Добавлять существующие каталоги (`git add -A -- каталог`), смотреть `git diff --cached --name-status` перед коммитом |
| Кириллица в имени переменной bash | `$имя` раскрывается в литерал, условие всегда истинно | Имена переменных — латиницей |
| `ssh` с потоком через `\|` и сценарием через heredoc одновременно | Одно из двух молча не доходит: вход у команды один | Сценарий — файлом на сервер или поток — отдельной командой |
| PowerShell: `` ` `` и `$` внутри строки в двойных кавычках | Обратные кавычки Markdown пропадают, `$0,13` превращается в пустоту | Текст с ними — в одинарных кавычках или правка инструментом редактирования |

## Сеть и прокси

| Ловушка | Симптом | Лечение |
|---|---|---|
| Прокси в переменных пользователя | Корпоративные и российские домены ломаются через прокси | Домены в `NO_PROXY`, прокси не сносить целиком; проверки делать без прокси |
| «UNABLE_TO_GET_ISSUER_CERT» у MCP-клиента | Выглядит как авторизация или сертификат | Сначала проба из Node (`https.get`): 200 — причина в клиенте, не в сети |

## MCP и доступы

| Ловушка | Симптом | Лечение |
|---|---|---|
| «Connection closed» | Похоже на «слетел доступ» | Запустить сервер руками — видна настоящая ошибка. Частые причины: после обновления кода не выполнен `npm install`; `uvx …@latest` подтянул несовместимую мажорную версию библиотеки — закрепить (`--with "mcp<2"`) |
| Тихий 401/403 | Скрипт рапортует успех с нулём данных | 204 отделять от не-2xx; на 401/403 — ошибка с текстом «доступ отозван» |
| Чужой кабинет | MCP отдаёт данные другого аккаунта без ошибки | Первым вызовом — «кто я / какой кабинет»; логин кабинета — явно в запросе |
| Сэмплирование отчёта | Дробные значения там, где считаются штуки | Точечные запросы с полной точностью; писать фактическую долю выборки |
| MCP GitHub: «does not support dynamic client registration» или «Authorization header is badly formatted» | Кнопка входа в `/mcp` не помогает | Сервер `api.githubcopilot.com/mcp/` работает только по личному токену: переменная пользователя `GITHUB_PERSONAL_ACCESS_TOKEN` (fine-grained, нужные репозитории), затем полный перезапуск редактора. Git push от MCP не зависит |
| OAuth «app secret invalid» | Кажется, что секрет протух | Может означать режим приложения (пользовательский вместо общего). Проба обмена: `invalid_grant` значит, что секрет в порядке. Сначала читать инструкцию проекта |

## Claude Code

| Ловушка | Симптом | Лечение |
|---|---|---|
| Импорт `@путь` в CLAUDE.md | Путь с кириллицей не грузится; внешний абсолютный — не грузится без подтверждения | Латинская строка через ссылку-переход внутри проекта (ADR-0004) |
| Проверка сессией `claude -p` | Модель сама открывает файлы и даёт ложное «видно» | `--disallowedTools "Read,Glob,Grep,Bash,PowerShell,Agent,WebFetch,Edit,Write"`; `--tools ""` раздувает контекст — не влезает в Haiku, Sonnet просит оплату за длинный контекст |
| Дата в артефакте | Вчерашняя дата после полуночи: дата контекста зафиксирована на старте сессии | Дату брать из системных часов (`Get-Date`, `date`) прямо перед записью |
