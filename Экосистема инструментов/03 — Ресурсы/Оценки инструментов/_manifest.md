# Оценки инструментов — _manifest

## Что это за ресурс

Переиспользуемая коллекция оценок внешних инструментов (по одному «Справочник — Оценка <name>» на инструмент).
Ассеты для решения, а не операционка. Формат каждой карточки единый: что это → как ставится → требования →
что создаёт/меняет → конфликты с нашей средой → профильность → вердикт.

## Что сюда заходит

- Оценка одного внешнего инструмента = один документ типа «Справочник». Исключение — стек из одного источника,
  который используют вместе: одной карточкой с разделом на каждый инструмент (пример — «Оценка стека Красинского»).

## Что не заходит

- Инструкции по нашим собственным навыкам → `_Движок`.
- Операционные скрипты/конфиги проекта → `06 — Инструменты\` соответствующего проекта.

## Как не перепутать

- Здесь — **оценка и вердикт** по чужому инструменту. Не установка и не исходники. Установку (если решим)
  делаем отдельно и в изолированной среде.

## Owner и актуализация

- Владелец: Дмитрий Заичкин. Пересмотр — при выходе новых версий инструмента или смене решения.
