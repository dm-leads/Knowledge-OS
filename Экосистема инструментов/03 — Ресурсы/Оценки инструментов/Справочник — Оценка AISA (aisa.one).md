# Справочник — Оценка AISA (aisa.one)

## Краткая суть

- **AISA** — «единая сеть ресурсов для AI-агентов»: один ключ даёт агенту доступ к **581 инструменту на 26 MCP-серверах** (SEO, соцсети, финансы, поиск, sales) и **110+ LLM**, оплата **за вызов**.
- Компания настоящая: **AIPAY SINGAPORE PTE. LTD.**, Сан-Франциско/Сингапур, основана 2025, CEO Jordan Liu, **$6,5 млн seed** от Alibaba и Tribe Capital (пресс-релиз GlobeNewswire 07.07.2026). Домен зарегистрирован 31.12.2024 — сервису ~21 месяц.
- **Инженерия действительно сильная:** 581 инструмент не грузится в контекст — в корне 5 мета-инструментов (`search`, `list_categories`, `get_details` — бесплатны; `use`, `batch_use` — платные), и у каждого платного вызова обязательный потолок `max_price_usd`, который отклоняет вызов **до** списания.
- 🔴 **Но для нас это не работает по трём причинам, в порядке тяжести:** (1) в ToS Semrush прямой запрет для России с формулировкой «directly or indirectly» — покупка через посредника его не обходит, Ahrefs блокирует РФ с 03.03.2022; (2) Ahrefs/Semrush/Similarweb строят базы на Google, **данных по Яндексу у них практически нет**, а у нас весь трафик — Яндекс; (3) то, что нужно, у нас **уже есть прямыми ключами** дешевле и легальнее.
- **Вердикт: ⛔ не покупаем ни лично, ни компании.** Не из-за цены — $39 мелочь. Из-за юридического риска и нулевой профильности по Рунету.

## 1. Что это и тип

Шлюз-агрегатор («capability layer») между AI-агентом и платными внешними API. Три слоя: модельный шлюз (LLM), каталог data-API, готовые «скиллы». Позиционирование — «Unified Resource and Transaction Network for AI Agents».

Отдельная особенность: продукт построен вокруг **машинных микроплатежей** — протокол x402, USDC, Circle Nanopayments на блокчейне Arc. Агент технически может сам оплачивать вызовы без участия человека. Основатель пришёл из крипто-кошелька UXUY, и это объясняет архитектуру.

## 2. Как подключается

Три способа:

```bash
# 1. MCP — главный путь для агентов
claude mcp add --transport http -s user aisa https://mcp.aisa.one/mcp
claude mcp login aisa
# срезы каталога: /seo/mcp, /gtm/mcp, /social/mcp, /finance/mcp, /search/mcp, /sales/mcp

# 2. OpenAI-совместимый REST — меняются только base_url, api_key, model
# https://api.aisa.one/v1  +  Authorization: Bearer <key>

# 3. CLI и скилл
npm i -g @aisa-one/cli && aisa login
npx skills add AIsa-team/agent-skills --skill aisa --agent codex --global
```

⚠️ Вариант 3 с флагом `--global` ставит скилл **в глобальную среду** — по нашей матрице это запрещённый уровень для исполняемого инструмента. Если когда-нибудь тестировать, то MCP в project-scope, не `--global`.

## 3. Требования

Node.js 22.20.0+ для скилла (18+ для CLI), `skills` 1.5.25+. Аккаунт и ключ формата `sk-aisa-*`. Для Similarweb — отдельная подписка Hive GTM Growth.

## 4. Что создаёт / меняет

MCP-режим: запись в конфигурации MCP клиента, OAuth-токен. Скилл с `--global` — в глобальную папку навыков. В репозитории проекта ничего не пишет. Состояние (баланс, ключи, логи) — на их стороне.

## 5. Глобальность влияния

MCP в user-scope и `--global` скилл затрагивают **все проекты машины**. Проектной изоляции продукт не предполагает — он спроектирован как «один ключ везде». Для нас это означает: тестировать только точечно, `-s project`, а не `-s user`.

## 6. Конфликты с нашей средой

- **Дублирует то, что уже есть прямыми ключами:** Firecrawl (у нас skill), Perplexity, Tavily, LLM (Google AI Studio корпоративный, OpenRouter). Через AISA те же вызовы идут **дороже** — посредник берёт наценку.
- **Пересечение с нашим SEO-контуром:** Topvisor, Yandex Search API, SerpApi, Rush Analytics закрывают Яндекс лучше.
- **AgentMail непригоден:** в их же документации — «Inboxes are shared across callers on this deployment», ящики общие между пользователями деплоя. Для рабочей переписки исключено.

## 7. Безопасность, данные, юридическая сторона

**Заявлено:** no-storage на контент («Prompts are not stored», «responses are not stored»), данные не используются для обучения. **Логируются** метаданные: таймстемпы, идентификаторы ключей, счётчики, коды ошибок, число токенов. Хостинг — США. Трансграничная передача по SCC. Аудитов SOC 2 / ISO 27001 **не заявлено**.

🔴 **Санкционная рамка — главное.**

В ToS самой AISA High-Risk Jurisdiction — это Куба, Иран, КНДР, Сирия, Крым, ДНР, ЛНР. **России в этом списке нет.** Право — Калифорния, споры — арбитраж в Сан-Франциско.

Но есть пункт, который перекладывает ответственность на пользователя: вы обязаны «comply with … the terms of service, acceptable use policies, and usage restrictions of **each Connected Service Provider**». А у провайдеров картина такая:

| Провайдер | Статус для РФ |
|---|---|
| **Semrush** | 🔴 В ToS (раздел 10) прямой запрет: услуги не могут предоставляться «either **directly or indirectly** … in … **Russia, Belarus**». Формулировка «indirectly» закрывает и путь через посредника |
| **Ahrefs** | 🔴 Блокирует доступ из РФ и Беларуси с 03.03.2022 (официальное заявление компании) |
| **Similarweb** | ✅ У AISA заявлено официальное партнёрство: «As an authorized Similarweb partner … data delivered directly from the source, not third-party marketplaces, mirror services, or web scraping» |
| **Ahrefs / Semrush** | ⚠️ Аналогичной формулировки о партнёрстве **нет** — там, где для Similarweb партнёрство названо явно, про эти два молчание. Происхождение данных не раскрыто |
| **Соцсети** | ⚠️ Описаны как «public data»; в каталоге присутствует **Oxylabs** с прямым описанием «scrape behind anti-bot layers» — скрейпинг в стеке есть как класс операций |

Вывод: риск нарушения чужих ToS договором переложен на нас. Для данных, которые пойдут в отчёты руководителю или наружу, это неприемлемо без письменного ответа AISA о происхождении данных Ahrefs и Semrush.

## 8. Профильность для нас — ключевой пункт

**Нулевая, и это не про цену.**

- Ahrefs, Semrush, Similarweb строят базы на **Google-выдаче**. Специализированного отслеживания позиций в Яндексе ни у одного не подтверждено. Semrush продал российские юрлица в августе 2022 — российская база с тех пор не обновляется.
- У нас **весь трафик — Яндекс**: SEO даёт 42,4% New First SQL (август 2026), Директ работает только по Москве.
- Мы уже закрыли эти задачи прямыми ключами: Yandex Search API, Topvisor, SerpApi, Метрика, Roistat, Firecrawl, Google AI Studio.
- Единственная реальная дыра — **бэклинки конкурентов по Рунету**. Но её AISA не закрывает: Ahrefs/Semrush нам запрещены, а их данные по Рунету всё равно бедные.

## Цены — что в ролике упростили

В видео звучит «$39 и все инструменты доступны». Фактически:

| Тариф | Цена | Включено | Множитель цены вызова |
|---|---|---|---|
| Pay-as-you-go | 0 | сколько пополнил | **1,5–2× от базы** |
| Builder | $39/мес | $50 кредитов | 1,2× |
| Team | $200/мес | $260 кредитов | 1× (база) |

То есть публикуемые «медианные» цены ($0,012 за вызов) — это ставка тарифа **Team за $200**, а не Builder за $39. На pay-as-you-go те же вызовы в полтора-два раза дороже. **Кредиты невозвратны и сгорают через год.** LLM-токены тарифицируются **сверх** плана.

Конкретные цены за вызов: DataForSEO $0,012 · Pinterest $0,012 · Tavily $0,0096 · Firecrawl $0,005 · Oxylabs $0,001 · Twitter от $0,0036 до $0,036.

## Оплата — отдельный барьер

Валюта — USD. Заявлено «fiat or USDC», в экосистеме логотипы Stripe и Visa, но **страницы со списком платёжных методов в документации нет** (гайд «Wallet and Payments» редиректит на общий pricing). Юрлицо сингапурское, эквайер предположительно Stripe — российская карта, скорее всего, не пройдёт. Рабочий путь — **USDC**, то есть криптоплатёж.

Для корпоративной закупки это означает: оплата криптовалютой требует отдельного решения бухгалтерии, а не «привязать карту компании». Это само по себе аргумент против того, чтобы нести предложение Павлу в текущем виде.

## Что в сервисе сделано хорошо (взять как приём, не как продукт)

Даже отказавшись от покупки, стоит запомнить их архитектурное решение — оно применимо к нашим MCP:

1. **Мета-инструменты вместо вываливания каталога.** 581 инструмент за пятью функциями: `search` → `get_details` → `use`. Поиск и схема бесплатны, платный только вызов. Контекст агента не забивается.
2. **Потолок цены на каждый вызов.** Обязательный `max_price_usd`; дороже — отказ до списания, а не после.
3. **Квота на ключ.** Ключ тратит `min(квота, баланс)` — лимит расходов не на аккаунт, а на конкретную интеграцию.

Это ровно тот подход, который стоит держать в голове при развитии собственных контуров: дешёвая разведка, дорогое действие под явным потолком.

## Вердикт

**⛔ Не покупаем — ни лично, ни компании.** Причина не в цене, а в том, что два ключевых провайдера запрещены для РФ по их собственным ToS (и «indirectly» закрывает обход через посредника), западные данные почти не покрывают Яндекс, а профильные задачи у нас закрыты прямыми ключами.

**Павлу в текущем виде не нести.** Предложение упрётся в оплату криптовалютой и в юридический вопрос о происхождении данных — а выгоды под наш рынок нет.

**Пересмотреть, если:** появится российский рынок в их каталоге (Яндекс-данные, Keys.so, Rush Analytics), либо появится фиатная оплата картой и письменное подтверждение партнёрства по SEO-провайдерам, либо у нас возникнет проект под западный рынок, где Google-данные и есть целевые.

**Если всё же тестировать** — только так: бесплатная регистрация (дают $2–5 стартовых), MCP в **project-scope** (`-s project`, не `-s user`), никакого `npx skills add --global`, потолок `max_price_usd` на каждый вызов, ничего рабочего в AgentMail, и **не трогать эндпоинты Ahrefs и Semrush** до письменного ответа о происхождении данных.

## Чем закрывать реальные потребности вместо этого

| Потребность | Чем закрываем |
|---|---|
| Позиции и семантика по Яндексу | Topvisor (есть), Yandex Search API (есть), Rush Analytics API — рубли, договор с РФ-юрлицом |
| Конкуренты по Рунету | Keys.so, Rush Analytics |
| Бэклинки конкурентов | реальная дыра; наименее рискованный вариант — DataForSEO Backlinks API, но до депозита $50 проверить их ToS на санкционный пункт |
| Парсинг и соцсети | Firecrawl (есть); Apify точечно, если Firecrawl не справится |
| LLM | Google AI Studio (корпоративный), OpenRouter |

## Что осталось непроверенным

- Цена Яндекс-эндпоинта DataForSEO в их кабинете и их ToS на предмет РФ.
- Принимает ли AISA российские карты — выясняется только регистрацией и доходом до экрана пополнения.
- Происхождение данных Ahrefs и Semrush — только письмом на developer@aisa.one.
- Расхождения в их собственных документах: юрлицо (AIPAY SINGAPORE vs AIPAY GLOBAL), стартовые кредиты ($2 в доках vs $5 в блоге), размер каталога (5000 на главной vs 950 в доках vs 581 живым счётом с сервера).
- Независимых отзывов о сервисе не нашлось — ни на Reddit, ни на Hacker News, ни на Habr, ни на vc.ru. Вся выдача — их собственные страницы, пресс-релизы и каталоги-агрегаторы.
