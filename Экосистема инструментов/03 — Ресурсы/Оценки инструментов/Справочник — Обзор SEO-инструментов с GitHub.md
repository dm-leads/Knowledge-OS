# Справочник — Обзор SEO-инструментов с GitHub

## Краткая суть

- **Бесплатной базы «по каким ключам получают трафик конкуренты» на GitHub нет и быть не может**: эти данные
  кто-то годами собирает за деньги. Самые популярные «открытые замены Semrush и Ahrefs» — оболочки над
  чужими платными данными: `open-seo` (20,5 тыс. ★) и `keywordpro` в README требуют ключ DataForSEO,
  `claude-seo` (17,5 тыс. ★) берёт данные через DataForSEO и Ahrefs. DataForSEO с 07.03.2022 исключил
  Россию из всех сервисов и запрещает доступ резидентам РФ (см. [Оценка AISA](<Справочник — Оценка AISA (aisa.one).md>)).
- На GitHub есть **механики** — обход сайтов конкурентов, тренды, обёртки над официальными API Яндекса.
  Из них собирается бесплатная часть анализа ниши, но без ответа «по каким ключам конкурент получает трафик».
- Этот ответ для Рунета даёт только коммерческая база — Keys.so (API в тарифе «Профессиональный»,
  9 300 ₽/мес, проба «Промо» ~990 ₽/сутки).

## Как собирается анализ ниши и что из этого даёт GitHub

| Вопрос | Источник | Откуда |
|---|---|---|
| Какой спрос и как он меняется в Яндексе | Wordstat API v2 (Yandex Cloud) | официальный API, уже есть у нас |
| Как меняется спрос в Google | Google Trends | бесплатно: `pytrends-modern`, `trend-pulse` |
| Кто стоит в выдаче Яндекса по запросу | Yandex Search API | официальный, у нас есть адаптер |
| Какие темы и страницы есть у конкурентов | карты сайтов и обход их сайтов | бесплатно: `advertools` |
| По каким ключам конкурент получает трафик, чего нет у нас | накопленная база выдачи | только платно: Keys.so |
| Что обсуждают в соцсетях за последний месяц | площадки соцсетей | `last30days` — только западные площадки |

## Что поставлено 24.09.2026

- Навык `seo-niche-research` — маршрутизатор «вопрос → инструмент» и два скрипта:
  `wordstat.py` (частотности и динамика через Wordstat v2 в Yandex Cloud — старый API мёртв, новый работает
  на ключе Search API) и `competitor_inventory.py` (карты сайтов конкурентов через `advertools`).
- MCP `gsc` (`mcp-gsc`) — ждёт доступа сервисного аккаунта к Search Console.
- Навык `last30days` + `yt-dlp`; выгрузка `--publish` заблокирована хуком.
- `Yurich-ru/yandex-ads-mcp` не поставлен: для SEO дублирует имеющееся, а проблема с чужим кабинетом
  Директа оказалась настройкой нашего сервера (он из проекта viklimat), чинится без чужого кода.

Первые находки: в карте сайта бризекс.рф нет ни одной даты `lastmod` (у tion.ru — 96%) и есть страница `404`;
спрос «очиститель воздуха» 93 842 (08.2025) → 160 986 (08.2026), +71% за год.
