# Команды для Claude или ChatGPT

Готовые тексты, которые вы вставляете в чат по одному, на каждом шаге. Работают и в Claude, и в ChatGPT: есть путь и без Claude Code. Замените {{...}} своим. Если ассистент спросит ключ, не отвечайте: ключ в чат не кладут.

Перед началом прикрепите к чату файлы: `NASTROYKA-JEV.md`, `pravila-offera.md`, `shablony-otvetov.md` и три файла из `voprosy/`.

---

## Шаг 0. Знакомство

```
Прочитай прикреплённый файл NASTROYKA-JEV.md и веди меня по нему. Задавай вопросы по одному.
```

Первый вопрос ассистента будет про нишу и про то, где ваши клиенты пишут «ищу» или «посоветуйте». Ответьте как есть, по-простому.

## Шаг 1. Собрать данные

```
Моя ниша: {{ВАША_НИША}}, город: {{ВАШ_ГОРОД}}, продукт: {{ВАШ_ПРОДУКТ}}.
Помоги собрать данные для трёх потоков, без платных вызовов:
1) сайт: какие 5 типов посетителей у меня бывают и по каким поисковым фразам они приходят;
2) отзывы: где найти отзывы на 5-10 моих конкурентов (карты, отзовики, соцсети) и как выгрузить их в один файл, по одному отзыву в строке;
3) рынок: в каких открытых чатах и на каких форумах мои клиенты пишут «ищу» и «посоветуйте», и как выгрузить такие сообщения в файл, по одному сообщению в строке.
Скажи пошагово, что нажимать. Не предлагай парсить то, что запрещено правилами площадок. Данные, где есть телефоны и фамилии, сначала очищаем.
```

## Шаг 2. Подогнать вопросы под вас

```
Вот три файла вопросов к JEV (sayt-posetitel.json, otzyvy-konkurentov.json, soobshcheniya-rynka.json).
Подставь мои данные вместо {{...}} и покажи итоговые версии. В soobshcheniya-rynka.json отдельно спроси меня, что я делаю и что НЕ делаю. В отзывах предложи варианты жалоб на основе 20 отзывов, которые я пришлю. Каждый вопрос проверяет один признак.
```

## Шаг 3. Прогнать JEV

Сначала без денег:

```
Мы готовы прогнать данные через JEV. Сначала составь для меня скрипт на основе файла primer-zaprosa-jev.py, который читает мой файл с сообщениями, и режим dry-run, который ничего не отправляет, а печатает, сколько будет запросов. Затем скажи, сколько это примерно стоит, и жди моего «да». Ключ скрипт берёт из переменной окружения JEV_KEY, в чат его не присылаем.
```

Затем, когда сказали «да» и ключ лежит у вас на компьютере:

```
Запускаем на первых 20 записях. Скажи, какую команду вставить в Терминал, и что должно появиться на экране. Потом сверим результат с моей ручной разметкой и поправим формулировки вопросов, где совпало меньше 80%.
```

Только после этого прогон на всей выгрузке.

## Шаг 4. Карта слабостей конкурентов

```
Вот результаты JEV по отзывам на конкурентов (таблица). Построй карту слабостей: по каждому конкуренту, какая жалоба встречается чаще всего, и сколько отзывов от людей, которые ищут замену (ishchet_zamenu = да, уверенность выше 70%). Какую одну гарантию мне стоит сделать главной на сайте? Если данных мало для вывода, так и скажи, не выдумывай.
```

## Шаг 5. Ответы найденным людям

```
Вот список людей, которых JEV отметил как «ищут исполнителя, наш профиль, горячесть 2 и выше». Для каждого напиши черновик ответа по правилам из pravila-offera.md и шаблонам из shablony-otvetov.md. Начинай с его слов. Ничего не выдумывай, обещай только то, что записано в моих фактах. В каждом ответе поставь статус ЧЕРНОВИК. Те записи, где уверенность JEV ниже 70%, вынеси отдельным списком, ответы им не пиши: их смотрю я. Для каждого ответа напиши, куда его отправлять: в личку только если человек сам позвал, иначе в чате по его правилам.
```

## Шаг 6. Утренний отчёт

```
Собери утренний отчёт для меня, одной страницей: сколько человек найдено, сколько горячих, крупный ли клиент среди них, что готово к отправке (с черновиками), что требует моего решения. В конце: какие два пункта мне нужно сделать руками сегодня. Отправляю ответы я сам, ты ничего не отправляешь.
```

## Шаг 7. Раз в неделю (по желанию)

```
Вот новая выгрузка за неделю. Прогони её по тому же порядку: найди новых людей, обнови карту слабостей конкурентов, напиши черновики и утренний отчёт. Покажи, сколько вопросов JEV ответил с низкой уверенностью, возможно, пора поправить формулировки.
```
