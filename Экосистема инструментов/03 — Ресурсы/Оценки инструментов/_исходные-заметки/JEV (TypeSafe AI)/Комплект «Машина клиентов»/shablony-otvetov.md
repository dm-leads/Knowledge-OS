# Шаблоны ответов

Плейсхолдеры в `{{ }}` заменяет Claude или ChatGPT по данным найденного человека и вашему файлу `pravila-offera.md`. Статус каждого готового текста: ЧЕРНОВИК, пока человек не утвердил. Отправляете вы сами.

Ниже по шаблонам идут примеры для трёх ниш. Это образцы тона и длины, а не готовые тексты: факты (сроки, условия) подставляйте свои.

## 1. Личное сообщение: человек ищет исполнителя (только если сам позвал в личку)

```
Здравствуйте, {{имя}}. Увидел ваше сообщение про {{его_задача}}.
Мы делаем {{ВАШ_ПРОДУКТ}} в {{ВАШ_ГОРОД}}: {{одно_отличие_из_фактов}}.
Пришлите {{два_параметра: объём_и_срок}}, вернусь с вилкой цены и реальным сроком за {{СРОК}}.
{{подпись}}
```

Пример, стройка и ремонт:

```
Здравствуйте, Андрей. Увидел ваше сообщение про отделку двухкомнатной квартиры.
Работаем по этапам: оплата после приёмки каждого, смета не меняется без вашей подписи.
Пришлите площадь и адрес, вернусь со сметой и сроком за 2 рабочих дня.
Мария, мастерская «Дом-Сервис»
```

Пример, B2B-услуги:

```
Здравствуйте, Ирина. Увидел ваш вопрос про бухгалтерию на аутсорс.
Мы отвечаем в тот же рабочий день, календарь сроков отчётности у вас перед глазами.
Напишите систему налогообложения и сколько у вас сотрудников, вернусь с вилкой стоимости.
Олег, «Баланс-Партнёр»
```

Пример, клиника:

```
Здравствуйте, Елена. Увидела ваше сообщение про консультацию стоматолога.
План лечения и стоимость вы получаете письменно до начала, изменения только с вашего согласия.
Если подскажете, что беспокоит, подберу ближайшее время для консультации.
Анна, администратор клиники «Улыбка»
```

## 2. Личное сообщение: человек ищет более сложное или дорогое решение (только если сам позвал в личку)

```
Здравствуйте, {{имя}}. Вы искали подрядчика на {{объект_или_задача}}.
Делали похожее: {{один_реальный_пример_из_ваших_работ}}.
Если пришлёте {{срок_и_объём}}, прикинем вилку и срок за {{СРОК}}.
{{подпись}}
```

Пример, стройка и ремонт: «Вы искали бригаду на отделку офиса 120 кв. м. Делали похожее: открытый офис под ключ, сдача по актам. Пришлите срок и планировку, прикинем вилку за 2 дня». (Замените на свой реальный объект.)

Пример, B2B-услуги: «Вы искали подрядчика на настройку CRM для отдела продаж. Делали похожее: внедрение в компании на 20 менеджеров. Напишите, какая сейчас система и что не устраивает, прикинем срок и стоимость за 2 дня». (Замените на свой реальный кейс.)

Пример, клиника: «Вы искали клинику для комплексного лечения. Составляем план с врачом на консультации, стоимость называем письменно до начала. Удобно в {{день}}?». Без слов «гарантируем результат».

## 3. Ответ в открытом чате (без рекламы)

```
{{имя}}, по вашему вопросу: {{полезный_факт_по_существу_без_ссылок}}.
Детали могу написать в личные сообщения.
```

Пример, стройка и ремонт: «Андрей, при отделке под ключ смета обычно растёт из-за скрытых работ, просите в договоре отдельный список. Детали могу написать в личные сообщения».

Пример, B2B-услуги: «Ирина, при выборе аутсорса бухгалтерии спросите, кто отвечает за штрафы за просрочку отчётности: это решает многое. Детали в личные сообщения».

Пример, клиника: «Елена, перед записью попросите письменный план лечения со стоимостью, так проще сравнивать клиники. Детали могу написать в личные сообщения».

## 4. Крупный клиент (несколько объектов или длинный договор)

```
Здравствуйте, {{имя}}. Вы писали про {{несколько_объектов_или_долгая_работа}}.
Для серии работ предлагаем {{что_у_вас_реально_есть: один менеджер, единые условия, график}}.
Удобно созвониться {{день}}? Подготовим предварительный расчёт на всю программу.
{{подпись}}
```

## 5. Оффер для баннера или поста (по слабости конкурента)

```
Заголовок:  {{гарантия_против_жалобы_на_конкурента}}
Строка:     {{одно_проверяемое_доказательство}}
Кнопка:     {{действие: Узнать срок / Посчитать / Записаться}}
```

Пример, стройка и ремонт: заголовок «Платите по этапам, после приёмки», строка «Акт на каждый этап, смета не растёт без вашей подписи», кнопка «Посчитать мою квартиру».

Пример, B2B-услуги: заголовок «Отвечаем в тот же рабочий день», строка «Календарь сроков у вас перед глазами», кнопка «Узнать стоимость».

Пример, клиника: заголовок «Стоимость лечения письменно до начала», строка «Изменения плана только с вашего согласия», кнопка «Записаться на консультацию». Текст рекламы медицинских услуг согласуйте с тем, кто отвечает за рекламу в клинике.

## 6. Утренний отчёт владельцу (внутренняя записка)

```
Найдено: {{N}} человек. Горячих: {{N_hot}}. Крупный клиент: {{есть/нет}}.
Ответы-черновики лежат в папке otvety/. Прочитайте, поправьте, отправьте сами.
Что не отправлять: {{записи_с_низкой_уверенностью_JEV}}.
```
