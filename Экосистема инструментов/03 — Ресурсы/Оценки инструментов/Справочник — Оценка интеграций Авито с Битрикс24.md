# Справочник — Оценка интеграций Авито с Битрикс24

## Краткая суть

- **У Битрикс24 есть штатный канал Avito** в Контакт-центре — с осени 2025 года, без приложения
  ([справка 28202720](https://helpdesk.bitrix24.ru/open/28202720/), обновлена 01.09.2026). Переписка в обе стороны, ссылка
  на объявление — системным сообщением; номер и город объявления в поля сделки справка не обещает.
- **Номер, город и ссылку объявления в выбранные поля сделки пишет приложение ITera «Авито: чаты и товары»**
  (`integrationpart.avito_chaty_sdelki_tovary`). Два аккаунта Авито — в рамках подписки Маркет, дальше 700–1 000 ₽ за аккаунт.
- **Вердикт:** ITera — забрать, когда нужна разбивка заявок по объявлениям и городам; штатный канал — запасной;
  приложения со входом по логину и паролю Авито — не ставим.
- **Главная ловушка:** ITera по умолчанию кладёт в сделку товар по объявлению с его ценой. Если вкладка «Товары» в
  сделке у проекта — история оплат, это ломает учёт. Режим «Не создавать товары» — до первого сообщения.

## 1. Что это и тип

Способы подключить чаты Авито к открытым линиям Битрикс24, все 14.10.2026:

| Вариант | Тип | Что пишет в сделку об объявлении | Цена в месяц | Права в Битрикс24 |
|---|---|---|---|---|
| Штатный канал Avito | канал Контакт-центра | ссылку системным сообщением в чате | 0 ₽, официальной цены нет | приложение не ставится |
| ITera «Авито: чаты и товары» | приложение Маркета | **в поля на выбор:** номер, название, ссылка, цена, город, адрес, дата, статус | 0 ₽ за 1–2 аккаунта в подписке; 1 000 ₽ за один дополнительный, от двух — по 700 ₽ | CRM, открытые линии, чат, встраивание, пользователи — минимальный |
| Wazzup | сервис + приложение | имя покупателя и название объявления — в имя контакта | 2 000–4 000 ₽ (цены рисуются скриптом, сняты одним проходом) | широкие: + бизнес-процессы, служба сообщений, чат-боты |
| ChatApp | сервис + приложение | ссылку и название; город и номер — внутри ссылки | 600 ₽ | самые широкие: + Диск, Задачи, Телефония, хранилище данных |
| АСМО, Umnico | приложение / сервис | не описано или «город для маршрутизации» | 0–2 000 ₽ | — **вход по логину и паролю Авито** |
| Radist, i2crm, Wappi | сервис + приложение | ссылка и название / всё в одну сделку / не перечислено | 700–3 990 ₽ | от средних до очень широких |

## 2. Как ставится

Из Маркета Битрикс24 администратором портала. Авито подключается окном входа Авито (штатный канал, ITera, Wazzup,
ChatApp) или логином и паролем кабинета, которые хранит сторонний сервис (АСМО, Umnico).

## 3. Требования

- Битрикс24: подписка Маркет — для любых приложений; на «Базовом» 2 открытые линии (таблица тарифов, 14.10.2026).
- Авито: профессиональный профиль; API чатов для «Услуг» — с подписки «Расширенная» (с 20.11.2025), для «Товаров» — только
  «Максимальная» (с 06.11.2025). Проверка доступа ключом кабинета: `GET /messenger/v2/accounts/{id}/chats` отвечает 200.

## 4. Что создаёт и меняет

Открытую линию, контакты и сделки. Сделку создаёт сама линия: в простой CRM — в основной воронке, на первой стадии;
источник Битрикс ставит по каналу сам, выбрать его в линии нельзя. ITera в режиме «Базовый» создаёт товары в каталоге
«AVITO» и строку товара в сделке, сумма сделки = цена объявления.

## 5. Глобальность влияния

Портал Битрикс24 целиком; агентную среду не трогает.

## 6. Конфликты с нашей средой

- **Строка товара в сделке.** Если скрипт проекта считает оплаты по строкам вкладки «Товары», чужая строка с названием
  объявления станет «оплатой». Слова из заголовка вроде «практика», «модуль», «курс» распознаются как то, что оплачено.
  Защита — в коде: оплатой считать только строки, которые пишет сам скрипт (метка «заказ N»).
- **Почты и телефона покупателя у Авито нет.** Скрипт, который при оплате ищет контакт по почте и телефону, заведёт второй
  контакт. Защита: искать сделку по ссылке на оплату; правило менеджеру — почту в контакт до ссылки.
- **Wazzup на каждое объявление заводит свой контакт** — один человек по двум объявлениям становится двумя клиентами.
- ITera пишет данные объявления с задержкой после создания сделки — роботы первой стадии срабатывают раньше.

## 7. Безопасность

- Вход по логину и паролю Авито у стороннего сервиса — полный доступ к кабинету; у АСМО жалобы на обрывы (30.07.2026).
- Переписка и имена покупателей проходят через сервер разработчика приложения; у штатного канала — только Битрикс и Авито.
- Права ChatApp включают Диск, Задачи и Телефонию — больше, чем нужно для чатов.

## 8. Профильность

Для проектов, где реклама идёт на Авито, а продажи ведутся в Битрикс24: заявки по объявлениям и городам видны в CRM
без ручного переноса. Звонки не закрывает ни один вариант: звонок на номер из объявления идёт обычной телефонией,
интернет-звонки Авито до CRM не доходят, API звонков Авито (`/calltracking/v1/getCalls/`) отдаёт номер объявления —
привязка звонка к объявлению делается своим кодом.

**Вердикт:** ITera — забрать, режим товаров выключить до первого сообщения; штатный канал — запасной; вход по логину и
паролю — не ставим.
