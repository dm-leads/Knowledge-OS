# Справочник — Оценка ruflo

## Краткая суть

- **ruflo** (автор `ruvnet`, наследник `claude-flow`) — не отдельный навык, а **мета-надстройка над Claude Code**: оркестрационная платформа.
- Внутри одного пакета: **~98 агентов + 60+ команд + ~30 навыков + MCP-сервер + hooks + фоновый daemon**; 33 нативных плагина + 21 npm-плагин; векторная память (AgentDB+HNSW), федерация между машинами, AIDefence.
- npm `ruflo` **v3.32.25**, MIT, Node ≥ 20, 1 зависимость `@claude-flow/cli`, **postinstall-скриптов нет** (пакет при установке произвольный код не выполняет).
- **Вердикт: пока НЕ ставим.** Тяжёлый (демон+MCP), заточен под разработку ПО, а не под наш маркетинг. Уместнее для будущего IT-проекта. Пробовать — только в изолированной песочнице, не глобально и не в Breezeks-Git.

## Что это

Execution-слой поверх Claude Code: агенты, оркестрация «роёв» (hierarchical/mesh/adaptive), векторная память, self-learning (SONA), федерация, фоновые воркеры. Работает с Anthropic Claude, OpenAI, Gemini, Cohere, Ollama. Web UI — flo.ruv.io, Goal Planner — goal.ruv.io.

## Как ставится — два пути

| Путь | Команды | Что даёт |
|---|---|---|
| **A — только плагины (лёгкий)** | `/plugin marketplace add ruvnet/ruflo` → `/plugin install ruflo-core@ruflo` | slash-команды и определения агентов/навыков; **MCP-сервер НЕ регистрируется** → `memory_store`, `swarm_init`, векторная память недоступны |
| **B — полная (демон+MCP)** | `npx ruflo@latest init wizard` → `claude mcp add ruflo -- npx ruflo@latest mcp start` | весь цикл: агенты, MCP-сервер, hooks, daemon |

Windows-нюанс: `curl … | bash` требует POSIX-shell (Git-Bash/WSL). На Windows корректный путь — **`npx ruflo@latest init wizard`** (работает в PowerShell/cmd).

## Требования

- Node.js ≥ 20 (у нас v24 — ок), npm/npx.
- Claude Code CLI (install.sh доустанавливает при отсутствии).

## Что создаёт / меняет

- Пишет в рабочую папку: `.claude/`, `.claude-flow/`, **свой `CLAUDE.md`**.
- Векторная память (AgentDB+HNSW) хранится локально (вероятно в `.claude-flow/`).
- Регистрирует MCP-сервер (по умолчанию локальный stdio); ставит hooks; запускает фоновый daemon.

## Конфликты с нашей средой

- **Свой `CLAUDE.md` + свои hooks + своя память** при `init` в рабочей папке → пересечение/переопределение нашего поведения. **`init` внутри Breezeks-Git не запускать** — затрёт/засорит канон, который потом идёт в GitLab.
- **Фоновый daemon + MCP + self-learning память** на машине с корпоративными ПДн/секретами — требует осознанности. **Телеметрия в README не раскрыта** (ни подтвердить, ни опровергнуть). Федерация между машинами — opt-in (по умолчанию выключена).

## Безопасность

- npm-пакет **без postinstall** (не выполняет код при установке).
- `ruflo verify` — криптопроверка, что установленные байты совпадают с подписанным witness.
- AIDefence: защита от prompt-injection, детект PII (14 типов), политики BLOCK/REDACT/HASH/PASS в федерации.
- Установщик `curl|bash` через jsDelivr CDN: доустанавливает Claude CLI, делает глобальные npm-install, регистрирует MCP, может поднять daemon. Sudo не требует.

## Профильность для нас

Низкая: платформа под автономную разработку ПО и оркестрацию агентских роёв. Наша работа — маркетинг/контент/аналитика. Затраты (демон, Bun/Node-инфраструктура, риск для среды) не окупаются нашими задачами.

## Вердикт

**Пока не ставим.** Если пробовать — изолированная папка вне Second Brain, сначала **Путь A** (плагины, без демона, обратимо через `/plugin`), только потом Путь B в песочнице. Держать подальше от репозиториев Second Brain. Пересмотреть, если появится собственный IT/девелоперский проект.
