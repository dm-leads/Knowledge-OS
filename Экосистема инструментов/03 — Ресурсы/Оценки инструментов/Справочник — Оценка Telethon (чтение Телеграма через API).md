# Справочник — Оценка Telethon (чтение Телеграма через API)

## Краткая суть

- **Telethon** — открытая библиотека Python (MIT), клиент протокола MTProto: работает от имени обычного
  Телеграм-аккаунта, видит то же, что видит этот аккаунт, — в том числе открытые группы и их историю.
- **Зачем:** ScrapeCreators отдаёт только публичные каналы, группы и чаты ему недоступны (навык `social-scrape`,
  28.10.2026); бот читает только чаты, куда его добавили. Читать чужие открытые группы можно только аккаунтом.
- **Риск один и главный — аккаунт.** Telegram ставит под наблюдение все аккаунты неофициальных клиентов и навсегда
  банит за флуд и спам; Telethon советует работать только с устоявшимися, не только что созданными аккаунтами.
- **Вердикт:** брать для чтения, в изолированном окружении скрипта, с отдельным устоявшимся аккаунтом; из кода
  ничего не отправлять. Файл сессии хранить как секрет.

## 1. Что это и тип

Библиотека Python, версия 1.45.0 на PyPI (04.11.2026). Тип — клиент API пользователя (MTProto), не Bot API.
Ключи — `api_id` (число) и `api_hash` (32 знака) с my.telegram.org, раздел «API development tools»; к одному номеру
привязан один `api_id` (core.telegram.org/api/obtaining_api_id). Открытые RSA-ключи серверов («public keys»,
строка `-----BEGIN RSA PUBLIC KEY-----`) на той же странице библиотеке передавать не нужно: они встроены в неё
`[вывод]` по устройству MTProto-клиентов; документацией Telethon не подтверждено.

## 2. Как подключается

Скрипт проекта с зависимостью, объявленной в самом файле, запуск через `uv run` — пакет не ставится в общую среду
Python. Первый вход — номер телефона, код из Телеграма, при включённой защите — облачный пароль. После входа
создаётся файл сессии `*.session`; дальше код не нужен.

## 3. Требования

Python 3, `uv`; Телеграм-аккаунт, на телефон которого придёт код; `api_id` и `api_hash` в `.env` проекта.

## 4. Что создаёт / меняет

Файл сессии (SQLite) рядом со скриптом или по указанному пути. В Телеграме — ничего, пока код ничего не отправляет;
вступление в группу — видимое действие аккаунта.

## 5. Глобальность влияния

Нет: окружение скрипта изолировано `uv`, сессия — файл в папке секретов проекта.

## 6. Конфликты с нашей средой

Один файл сессии нельзя открывать двумя процессами сразу («database is locked» — FAQ Telethon): каждый скрипт
работает со своей сессией или по очереди. Прокси — по «Справочнику — Грабли среды» (сброс системного прокси, как
для Вордстата).

## 7. Безопасность

- **Файл сессии даёт доступ к аккаунту без кода** `[вывод]`: хранится в папке секретов проекта, в git и в чат не
  попадает; утечка — завершить сеанс в настройках Телеграма («Устройства»).
- **Бан аккаунта:** «If you use the Telegram API for flooding, spamming … you will be banned forever»; «all
  accounts that log in using unofficial Telegram API clients are automatically put under observation»
  (core.telegram.org/api/obtaining_api_id). «Use the library only on well-established accounts (and not an account
  you just created)»; VoIP-номера банят чаще (FAQ Telethon). Точных лимитов «nobody knows» (Telethon, errors).
- **Флуд:** `FloodWaitError` — Telegram сам говорит, сколько ждать; до 60 с библиотека ждёт сама
  (`flood_sleep_threshold`). `PeerFloodError` — признак ограничения аккаунта, проверяется в @SpamBot.
- **Данные:** условия API запрещают обучать и дообучать модели на данных Телеграма (core.telegram.org/api/terms,
  п. 1.5); оценка сообщений моделью — не обучение. Ники и сообщения людей — персональные данные: правила — в
  [Политике персональных данных](<../../../Методологии/Политика — Персональные данные, секреты и доступ к внешним системам.md>)
  и разборе [«Ловец лидов»](<../../../Методологии/Эфиры (разборы)/NOTE-SRC — Ловец лидов (Кадыров, Альфа-Курс, 2026-11-03).md>).

## 8. Профильность

Профильный для задач «прочитать открытые группы и чаты»: исследование аудитории, ловец лидов, мониторинг упоминаний.
Не для рассылок.

## Проверка на известном ответе

Ещё не проводилась: нужен вход аккаунтом. План — прочитать одну заранее известную открытую группу за 1 день и
сверить число сообщений с тем, что видно в приложении.

## Вердикт

**Забрать для чтения.** Условия: отдельный устоявшийся аккаунт (не основной владельца, не рабочий аккаунт
компании, не только что зарегистрированный); только открытые группы; вступать по несколько в день; из кода ничего
не отправлять — ни сообщений, ни реакций; сессия — секрет; изолированное окружение `uv`. Первое применение —
пилот ловца лидов «Учебного центра» (04.11.2026).
