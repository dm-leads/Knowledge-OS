# Справочник — Заметки до оценки: Hermes Agent и Screaming Frog

> Статус: **заметки, не оценка.** Собраны в штабе ИИ-практики (06.2026) по официальной документации и
> материалам курсов. Оценки по [рамке](<Стандарт — Как оцениваем внешний инструмент.md>) и вердикта пока
> нет — перед установкой в новый проект сделать оценку.

## Общий принцип: сначала данные, потом синтез

Агент — не кнопка результата, а слой синтеза и автоматизации поверх **детерминированных** данных: выгрузок,
краулинга, воспроизводимой выдачи, API. Конвейер: данные → нормализация → компактный контекст → синтез агента
→ отчёт → ревью человека → точечные правки → замер результата.

- **Хорошие сценарии:** синтез по выдаче и выгрузкам, сравнение посадочных конкурентов, пробелы контента с
  отсечением каннибализации, внутренние ссылки, технические проверки, мониторинг по расписанию.
- **Плохие:** стратегия с нуля без данных; массовая генерация страниц без карты каннибализации; изменения
  CMS без подтверждения человека; выдуманные частотности; «доказательство роста» без замеров.

## Hermes Agent (Nous Research)

Различать: **Hermes 4** — семейство открытых моделей; **Hermes Agent** — открытый фреймворк автономного
агента (релиз 02.2026).

- **Что даёт:** постоянного агента на своём сервере — память между сессиями, навыки, задачи по расписанию,
  шлюзы (Telegram и другие мессенджеры, CLI), инструменты (SSH, файлы, браузер, MCP), субагенты, любая модель
  (OpenRouter, локальные Ollama и vLLM).
- **Роль:** внутренний исполнитель задач по расписанию и оркестратор контура — мониторинг метрик с
  оповещением, дайджест звонков, срез цен конкурентов. Это серверная реализация схемы «диспетчер и потоки»
  из [Методологии работы с ИИ-агентами](<../../../Методологии/Методология — Работа с ИИ-агентами в проекте.md>).
- **Ограничения и безопасность:**
  - модель безопасности — «личный агент, один доверенный оператор», не многопользовательский продукт;
  - SSH, терминал и выполнение кода — в изоляции (Docker), мессенджер — только для своего ID, без боевых
    доступов и автопубликации до проверки;
  - персональные данные (звонки, CRM) — только локальной моделью;
  - синтез — один на пакет или кластер, не на каждую единицу, иначе дорого.
- **Где уже используется:** на сервере компании Бризекс (`/opt/docker/deploy/aidm/hermes-agent`) — факт
  проверен 28.09.2026 по списку папок, конфигурация не читалась.

Источники: [документация Hermes Agent](https://hermes-agent.nousresearch.com/docs/), hermes-agent.org.

## Screaming Frog + LLM

- **Что даёт:** технический аудит сайта (структура, дубли, мета, коды ответа, рендеринг JS), извлечение данных
  со страниц своих и конкурентов (Custom Extraction, Custom Search, Custom JavaScript), интеграции по API
  (Search Console, Ahrefs, PageSpeed, LLM), генерацию title, description и ALT на масштабе — поверх
  собранных краулером данных.
- **Ограничения:** уважать robots и лимиты; большим сайтам нужны память и аккуратные ограничения обхода;
  LLM на масштабе стоит денег — считать целесообразность до запуска.
- **Источник:** курс «Screaming Frog — от парсинга до AI функций» (транскрипты и пресеты у владельца),
  [screamingfrog.co.uk](https://www.screamingfrog.co.uk/seo-spider/).
