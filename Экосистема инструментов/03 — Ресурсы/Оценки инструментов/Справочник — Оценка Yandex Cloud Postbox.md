# Справочник — Оценка Yandex Cloud Postbox

Источник — документация Yandex Cloud, прочитана 30.10.2026: тарифы (обновлены 15.09.2026), квоты (08.10.2026),
концепции, DNS-записи, отписка, отслеживание. Первый проект — «Учебный центр», приглашения на тематические зумы.

| # | Пункт | Ответ |
|---|---|---|
| 1 | Что это и тип | Облачный сервис отправки писем Yandex Cloud. Не ставится в среду агента — внешний API |
| 2 | Как подключается | В консоли Yandex Cloud: адрес отправителя → записи DNS → проверка домена. Отправка — SMTP или `sesv2 send-email` на `https://postbox.cloud.yandex.net` (boto3, AWS CLI) |
| 3 | Требования | Платёжный аккаунт Yandex Cloud; статический ключ сервисного аккаунта; доступ к DNS домена: Easy DKIM — 2 CNAME (или свой ключ — 1 TXT); SPF `include:spf.postbox.yandexcloud.net` и DMARC — рекомендуются |
| 4 | Что создаёт | Ничего на машине. В облаке — адрес, конфигурации, журнал событий |
| 5 | Глобальность | Нет: подключается в конкретный проект ключом из его `.env` |
| 6 | Конфликты | Записи DNS основного домена: если на домене уже есть почта и SPF — отправлять с поддомена, чтобы не сломать ящики |
| 7 | Безопасность | Ключ — секрет проекта. Отслеживание открытий и переходов выключаемо (включается в конфигурации); при переходах ссылки заменяются ссылками Postbox. Отписка — заголовки `List-Unsubscribe` (RFC 8058), если передать параметры списка; обязанность соблюдать отписки — на отправителе |
| 8 | Профильность | Высокая для рассылок из своих функций: приглашения, напоминания, служебные письма |

**Цена и квоты.** Первые 2 000 писем в месяц — бесплатно, остаток не переносится; дальше ~80 ₽ за 1 000 (2 001–10 000),
70 ₽ (до 50 000), с НДС. Платятся все принятые к отправке письма, даже недоставленные. Квота по умолчанию — 200 писем
за 24 часа и 1 письмо в секунду; повышается запросом в консоли. Получателей в письме — до 200, размер — 30 МБ.
Проверка без реальных адресов — симулятор доставки.

**Чего нет на страницах:** песочницы для новых аккаунтов, правил для маркетинговых рассылок.

**Вердикт: `забрать`** — для рассылок из своих функций. Сравнение с платформами: GetCourse оборачивает каждую ссылку
письма во вход в кабинет (проба «Учебного центра» 30.10.2026) — для тех, кто ещё не ученик, это лишний «активный»
пользователь в квоте тарифа.
