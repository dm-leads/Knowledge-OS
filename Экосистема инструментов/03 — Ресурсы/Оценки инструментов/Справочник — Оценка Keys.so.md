# Справочник — Оценка Keys.so

## Краткая суть

- **Keys.so** — российская коммерческая база снятой выдачи: по каким запросам стоит любой сайт, чего нет у
  нас, но есть у конкурентов, что конкуренты покупают в Директе и РСЯ, их ссылки, упоминания в ответах Алисы.
  Закрывает единственный вопрос, на который нет ответа ни в Вордстате, ни в Вебмастере, ни на GitHub
  (см. [Обзор SEO-инструментов](<Справочник — Обзор SEO-инструментов с GitHub.md>)).
- **Вердикт: забрать** — навык `keysso` в `_Движок\Исходники скиллов\` (правила, клиент, спецификация,
  справочник 155 методов). Подписку брать под конкретный план разбора, а не «на всякий случай».
- Главные оговорки: трафик и бюджеты — **модельные оценки**; данные доступны только пока идёт подписка —
  ценное снимать в файлы.

## 1. Что это и тип

Облачная база с веб-интерфейсом и REST API (`https://api.keys.so`, заголовок `X-Keyso-TOKEN`). Российское
юрлицо, оплата в рублях. Базы: Яндекс по Москве и ~20 регионам, Google Москва, Дзен.

## 2. Как подключается

Ключ API в кабинете (тарифы «Профессиональный» и «Корпоративный»). У нас — переменная `KEYSO_API_KEY`
в мастер-.env устройства; работа через навык `keysso` (клиент `scripts/keysso.py`). Ничего не ставится.

## 3. Требования

Python с `python-dotenv` для клиента. Установки, демонов и MCP нет.

## 4. Что создаёт / меняет

Локально — только файлы снимков в папке, которую указали. В аккаунте Keys.so объекты создают методы
проектов, мониторинга, трекера нейросетей, кластеризации и парсеров — они тратят месячные лимиты,
а при удалении теряется накопленная история.

## 5. Глобальность влияния

Навык глобальный, вызывается осознанно; поведение агента не меняет. Данные проекта кладутся в папку проекта.

## 6. Конфликты с нашей средой

Нет. Дополняет `seo-niche-research`: Wordstat через Yandex Cloud, Search API, карты сайтов, Search Console.
На время подписки массовую частотность выгоднее снимать парсером Wordstat в Keys.so (входит в тариф),
чем платными запросами Yandex Cloud.

## 7. Безопасность

Отправляем в сервис только домены и фразы. Ключ даёт доступ к аккаунту компании: не печатать, не коммитить.

## 8. Профильность

Прямая: SEO, контент-план, контекстная реклама, ссылки, видимость в нейросетях. Первый прогон по
бризекс.рф (28.09.2026, `msk`): 57 137 запросов в топ-50, 7 782 упоминания в ответах Алисы, карта из
~40 органических и ~40 рекламных конкурентов за два вызова.

## Ловушки API (проверены на живых вызовах)

- `code: 202` внутри ответа с HTTP 200 — отчёт ещё строится, данных нет; ждать до 5 минут.
- Кириллический домен — как есть; punycode даёт 404 «Домен не найден».
- Постраничная выгрузка без второго поля сортировки теряет или дублирует строки на стыках; набор полей
  у отчётов разный — второе поле подбирать под отчёт.
- `ws` завышает спрос в разы — решения по `wsk` (точная частотность).
- В Git Bash путь метода с ведущим `/` превращается в путь к файлу — передавать без слеша.

## Правила работы и стандартный цикл

Источник правды — навык `keysso` (`_Движок\Исходники скиллов\keysso\SKILL.md`): какой вопрос каким методом,
как читать поля, базы, одиннадцать правил, цикл «паспорт → карта конкурентов → разрывы → решения → замер → архив».

## Вердикт

**Забрать.** Брать подписку под план с конкретными решениями на выходе и на срок, за который план
выполняется; всё ценное снимать в файлы до окончания доступа.
