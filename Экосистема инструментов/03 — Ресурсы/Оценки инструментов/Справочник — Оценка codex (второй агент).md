# Справочник — Оценка codex (второй агент)

## Краткая суть

- **codex** — CLI OpenAI + плагин для Claude Code (агент `codex:codex-rescue`, навыки `rescue`/`setup`/`review`). Даёт **вторую независимую модель** с другими слепыми пятнами.
- «Два агента всегда лучше» — **миф**: это удвоение стоимости и времени. Выигрыш только в трёх паттернах: **независимое ревью**, **rescue при застревании**, **проверка дорогих фактов**.
- Проверено 03.09.2026: установлен (CLI 0.149.1), авторизован, модель `gpt-5.6-terra`.
- **Вердикт: ✅ забрать**, вызывать осознанно по трём паттернам. Решение о вызове — на стороне Claude, не пользователя.

## 1. Что это и тип

CLI `codex` (OpenAI, v0.149.1) + плагин `openai-codex/codex` 1.0.6 для Claude Code: субагент `codex:codex-rescue`, команды `rescue`/`review`/`adversarial-review`/`status`/`setup`, внутренние навыки промптинга.

## 2. Как ставится / вызывается

Уже установлен. Прямой вызов:

```
cd "<папка>" && codex exec --sandbox read-only --skip-git-repo-check "<prompt>" < /dev/null
```

Или субагент `codex:codex-rescue` через Agent tool — для крупных задач с правками.

## 3. Требования

Codex CLI + активная подписка OpenAI. Конфиг `~/.codex/config.toml`.

## 4. Что создаёт / меняет

В наших репозиториях — **ничего**. Свой конфиг, сессии и кэш в `~/.codex/`.

## 5. Глобальность влияния

Плагин глобальный, но **пассивный**: сам не срабатывает, вызывается осознанно. Поведение Claude в других
проектах не переопределяет.

## 6. Конфликты

Конфликтов с нашей средой нет. **Ограничение:** у `codex:codex-rescue` из инструментов только `Bash` —
он видит файлы, но **не видит нашу память, Lark MCP, Roistat и наши навыки**. Отсюда его роль: код,
диагностика, ревью по файлам. Не наш маркетинговый контекст.

## 7. Безопасность и данные

Код и содержимое задачи **уходят в OpenAI**. На ПДн и секреты не направлять. Sandbox по умолчанию
`read-only`; `workspace-write` — только осознанно.

## 8. Профильность и результат обкатки

Обкатано на реальной задаче: состязательное ревью стартера чата по юнит-экономике против двух источников.

| Итог | Значение |
|---|---|
| Всего замечаний | 9 |
| Ложных срабатываний | **3 из 4 «ошибок»** — не понял «48 КБ» как размер, принял артефакт кодировки за неверные пути, цитировал устаревший документ как актуальный |
| Ценных находок | **2** — путаница двух разных «3 000 ₽» (разные знаменатели) и отсутствие порога статзначимости для гипотез на малых числах |
| Расход | ~60 тыс. токенов |

**Вывод:** вывод Codex — мнение, не истина. Ценность есть, но требует разбора по пунктам: обоснованное
принимать, ложное отклонять вслух. Принимать пачкой нельзя.

## Известные грабли

- `Not inside a trusted directory` → добавить `--skip-git-repo-check` (Breezeks-Git не git-репозиторий).
- CLI ждёт stdin и висит → добавить `< /dev/null`.
- Шум `ERROR rmcp::transport::worker` (Linear/Figma без авторизации) — безвреден, фильтровать.
- Кириллица в stdout Windows может прийти кракозябрами — смотреть на суть.
- Название навыка `gpt-5-4-prompting` — гайд по стилю промптов, **не выбор модели**.

`~/.claude/CLAUDE.md`.
