# Справочник — Обзор навыков маркетинга и медиапланирования с GitHub

## Краткая суть

- Искали: что на GitHub помогает составить медиаплан и выбрать площадки, и есть ли готовые наборы
  навыков «маркетолог для агента».
- **Программ-медиапланировщиков нет.** Поиск по названиям и описаниям дал один учебный пример.
- **Есть навыки-инструкции.** Крупные наборы рассчитаны на западные площадки. Два русскоязычных навыка
  близки к нашей задаче, но малоизвестны и содержат фактические ошибки.
- **Модели распределения бюджета по истории расходов** существуют и поддерживаются, но требуют
  год-два собственных данных.
- **Решение:** ничего не ставим. Из `ai-hub-open/marketing-strategist` взята шкала оценки площадок по шести
  критериям — в [Методологию — Медиапланирование](<../../../Методологии/Платный трафик/Методология — Медиапланирование.md>),
  со ссылкой и версией. Числа из чужих навыков не переносим.

## Как искали

Поиск GitHub 13.10.2026: репозитории по словам `media plan`, `media planning`, `marketing skills`,
`ai marketing`, `marketing mix modeling`; поиск по содержимому файлов `SKILL.md` на `media plan`,
`budget allocation` и по слову «медиаплан». Число звёзд и даты — на день поиска. Файлы навыков
читались как данные; ничего не запускалось.

## Что из этого следует

1. Методику медиапланирования из готового репозитория взять нельзя — её пришлось собрать: форма и этапы —
   из курса MAED, шкала выбора — из открытого навыка, деньги — из Красинского.
2. Открытые навыки по рекламе быстро устаревают по фактам: оба русскоязычных не знают о позиции ФАС
   от марта 2026 года. Их можно читать как структуру, но не как справочник.
3. Набор `coreyhaines31/marketingskills` — первый кандидат, когда понадобится закрыть следующий пробел
   карты маркетинга; читать по одному навыку и сверять с каноном.

## Что не сделано

- Не читались подробно: `digital-marketing-pro`, навыки `ads`, `marketing-plan`, `attribution` из
  `marketingskills`, плагины Anthropic, роли `agency-agents`.
- Не проверялся каталог skills.sh и число установок.
- Не запускался ни один скрипт из найденных репозиториев.
