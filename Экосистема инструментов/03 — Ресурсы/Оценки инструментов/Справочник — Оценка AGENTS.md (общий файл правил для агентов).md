# Справочник — Оценка AGENTS.md (общий файл правил для агентов)

## Краткая суть

- **Что.** [AGENTS.md](https://agents.md/) — «a simple, open format for guiding coding agents»: обычный
  Markdown в корне проекта. Формат ведёт Agentic AI Foundation при Linux Foundation.
- **Вердикт: `забрать` как паттерн.** Это не программа: ничего не ставится и не запускается.
- **Зачем нам.** Сейчас паспорт проекта — `CLAUDE.md`, его читает только Claude Code (и Cursor). Codex читает
  `AGENTS.md`; при импорте он сам сделал копию паспорта, и копия разошлась с оригиналом.
- **Как брать.** Источник паспорта — `AGENTS.md`; в `CLAUDE.md` остаётся строка `@AGENTS.md`. Так велит
  документация Claude Code. Это меняет шаблон паспорта и `kos_connect.py` — отдельная задача по цепочке
  постановки.
- **Чего не проверено:** раскрывают ли Codex и Cursor ссылки на другие файлы внутри `AGENTS.md`. Документация
  обоих об этом молчит, поэтому правила канона подключаются фразой «прочитай файл по пути», а не импортом.

## 1. Что это и тип

Пассивный формат, по водоразделу стандарта — «справочник»: один файл Markdown без обязательных полей
(«AGENTS.md is just standard Markdown»). Репозиторий [agentsmd/agents.md](https://github.com/agentsmd/agents.md),
24,9 тыс. звёзд на 13.10.2026, лицензия MIT.

## 2. Как ставится

Никак. Файл `AGENTS.md` кладётся в корень проекта.

## 3. Требования

Для выбранной схемы — строка `@AGENTS.md` в `CLAUDE.md` — версия Claude Code не важна: импорт работает и
в старых версиях. Версия 2.1.277 нужна только для чтения `AGENTS.md` без `CLAUDE.md` и для настройки Project
instructions (значение `claude-md-and-agents-md` велит читать оба файла). На машине владельца расширение
в Cursor — 2.1.296, терминальная версия — 2.1.143.

## 4. Что создаёт и меняет — кто как читает

| Агент | Как читает | Источник |
|---|---|---|
| Codex | Глобальный `~/.codex/AGENTS.md`, затем файлы от корня проекта до рабочей папки; предел 32 КиБ (`project_doc_max_bytes`) — входит ли в него глобальный файл, страницы документации говорят по-разному | [документация](https://learn.chatgpt.com/docs/agent-configuration/agents-md.md) |
| Cursor | `AGENTS.md` в корне и подпапках; `CLAUDE.md` читает так же | [правила](https://cursor.com/docs/rules), [справка](https://cursor.com/help/customization/rules) |
| Claude Code | «By default, Claude reads `AGENTS.md` only when you have no `CLAUDE.md` in your working directory or above it». Чтобы работали оба — строка `@AGENTS.md` в `CLAUDE.md`. Символическую ссылку на Windows документация не советует | [документация](https://code.claude.com/docs/en/memory#agents-md) |

## 5. Глобальность влияния

Файл в проекте действует только в нём — но на любой запуск Codex в этой папке, включая независимые проверки
навыком `second-agent`: навык запускает проверяющего в рабочей папке. Глобальный `~/.codex/AGENTS.md`
действует во всех запусках Codex на машине. Карта Knowledge-OS (28.09.2026) требует, чтобы второе мнение было
независимым от правил канона; с общим паспортом это выполняется, только если проверяющий запускается из
папки вне проекта. Решение — за владельцем канона.

## 6. Конфликты с нашей средой

- **Два файла в одном корне.** Где уже лежат и `CLAUDE.md`, и `AGENTS.md`-копия (рабочая папка компании, один
  личный проект), Cursor читает оба, а Claude Code — только `CLAUDE.md`. Копию нужно заменить источником.
- **Импорт Codex.** Не перезаписывает непустой `AGENTS.md` (по коду импорта), но в проекте без него создаст
  копию из `CLAUDE.md`. Свой `AGENTS.md` в каждом проекте закрывает и это.
- **`kos_connect.py`** пишет блок канона в `CLAUDE.md`. После перехода — в `AGENTS.md`; шаблон паспорта и
  стандарт «Три файла проекта» правятся тем же изменением.
- **Предел 32 КиБ у Codex.** Паспорт рабочей папки компании — 9 КБ, запас есть.

## 7. Безопасность

Наружу ничего не уходит. Риск один: файл читает любой агент, открытый в папке, — секретам и персональным
данным в паспорте не место (как и сейчас).

## 8. Профильность для нас

Прямая: без общего файла правил запасной агент в день обрыва начинает работу, не зная паспорта проекта.

## Вердикт

**`забрать` как паттерн.** Порядок: решение владельца → постановка на изменение `kos_connect.py` и шаблона
паспорта → перевод проектов по одному, с проверкой «свежая сессия в каждой из трёх сред называет путь точки
возврата из паспорта».

Рассматривалась замена без перехода: оставить источником `CLAUDE.md`, а Codex научить читать его параметром
`project_doc_fallback_filenames`. Меньше правок, но держится на одной строке настроек устройства и ломается
импортом Codex, который в проекте без `AGENTS.md` создаёт свою копию.
