# Справочник — Оценка API VK Рекламы

## Краткая суть

- **API VK Рекламы** — официальный интерфейс рекламного кабинета `ads.vk.ru`: кампании, группы, объявления,
  аудитории, статистика, баланс.
- **Вердикт: забрать — чтение** (14.10.2026, после первых вызовов настоящим ключом). Методы записи известны
  только по копии документации 2024 года — их проверять сухим прогоном.
- Главная ловушка: **Client Secret дают получить только в течение 10 минут**. Потом в кабинете остаётся один
  Client ID, и вернуть секрет можно только через поддержку.

## 1. Что это и тип

Облачный REST API площадки. Не ставится: к нему ходит наш клиент. Доступ, по справке площадки, могут получить
агентства и прямые рекламодатели — юридические и физические лица.

## 2. Как подключается

Порядок из официальной справки `ads.vk.ru/help/articles/help_api`, прочитана 13.10.2026:

1. Реквизиты заполнены: у агентств и юридических лиц — раздел «Бюджет», и они проверены модерацией;
   у физических лиц — раздел «Настройки».
2. «Настройки» → «Доступ к API» → «Запросить доступ к API», указать ответственного, «Запросить доступ».
3. В разделе появляются `client_id` и кнопка получения `client_secret`. Справка: «получить его можно только
   в течение 10 минут» и «повторный запрос отправить невозможно».
4. Вопросы — личному менеджеру или на `ads_api@vk.team`.

**Ключи привязаны к тому, кто запросил доступ.** Кабинет, к которому даёт доступ пара ключей, — кабинет
пользователя, нажавшего «Запросить доступ к API». 14.10.2026 в одном из проектов поддержка выслала ключи,
и они оказались от личного кабинета владельца с чужими кампаниями, а не от кабинета компании. «Ключ принят» этого
не показывает: сверять номер кабинета с ответом площадки и смотреть, чьи кампании видны.

Для своего кабинета — схема Client Credentials Grant: `POST /api/v2/oauth2/token.json`,
`grant_type=client_credentials`. Приложение и Redirect URI нужны только для доступа к чужим кабинетам
(Authorization Code Grant), и эта схема выдаётся по условиям.

**Как не потерять секрет.** Справка не говорит, от какого момента идут 10 минут. Поэтому до нажатия кнопки:
открыт файл ключей с пустой строкой под секрет, открыто окно с командой проверки. После нажатия — вставить,
сохранить, сразу проверить получением токена, второй экземпляр — в менеджер паролей.

## 3. Требования

Проверенные реквизиты в кабинете. Python со стандартной библиотекой. Демонов и MCP нет.

## 4. Что создаёт / меняет

Клиент на чтение ничего не меняет в кабинете. Локально — файл с токеном рядом с ключами: у кабинета не больше
5 токенов одновременно, поэтому токен хранится и обновляется, а не выписывается при каждом запуске. Методы записи
создают и меняют кампании, ставки и бюджеты — только через модуль с белым списком.

## 5. Глобальность влияния

Локально в проекте. Общего навыка и глобальной установки нет.

## 6. Конфликты с нашей средой

Нет. Сторонние MCP-коннекторы к VK Рекламе не оценивались и не ставятся.

## 7. Безопасность

- Токен даёт доступ к бюджету кабинета; ключ, токен и токен обновления в вывод и журналы не попадают.
- Метод «чей кабинет» (`/api/v2/user.json`) отдаёт имя, фамилию и почту — в вывод идут номер, тип и
  состояние. Остатка в нём нет (проверено 14.10.2026).
- **В объявлении есть блок маркировки** `about_company_*` — ФИО и ИНН рекламодателя. 14.10.2026 он попал в
  вывод команды чтения; теперь блок вырезается в коде, длинные номера в текстах закрываются.
- **Лимит токенов.** Не больше 5 на кабинет, следующий запрос — отказ 403. Метод `token/delete.json` удаляет
  все токены кабинета разом — это запись, по команде владельца. Источник — копия документации от 08.05.2024.
- Переадресацию в клиенте выключить: `ads.vk.com` отвечает переадресацией на `ads.vk.ru`.

## 8. Профильность для нас

Высокая, если реклама идёт в VK Рекламе: расход, показы, переходы, заявки и остаток снимаются командой.

Что проверено 13.10.2026 и что нет:

| Утверждение | Статус |
|---|---|
| Порядок получения доступа и окно 10 минут | официальная справка, живая страница |
| Раздел документации `ads.vk.ru/doc/api` отдаёт 404 | проверено в браузере; ссылка на него из справки не работает |
| Метод токена существует и проверяет ключи: на неверную пару — 401 `invalid_client` на `ads.vk.ru` и `ads.vk.com` | пробный запрос |
| Client Credentials Grant настоящим ключом | работает, 14.10.2026 |
| Срок токена — сутки, обновление, лимит 5 токенов | копия документации от 08.05.2024; обновление ещё не проверялось |
| Методы чтения `ad_plans.json`, `ad_groups.json`, `banners.json`, `packages.json` с параметрами `fields`, `limit`, `offset` | отвечают 200, поля подобраны живыми вызовами 14.10.2026 |
| `lead_ads/lead_forms.json` | 404 — у лид-форм другой адрес, не найден |
| Методы записи и статистики | не проверено |
| Сбрасывает ли поддержка секрет и за какой срок | не подтверждено |

## Вердикт

**Забрать — чтение** (14.10.2026). Перед работой — проверить, что ключи от нужного кабинета. Запись — отдельным
модулем: белый список, сухой прогон, журнал, откат, команда владельца на каждое изменение и каждую сумму.
