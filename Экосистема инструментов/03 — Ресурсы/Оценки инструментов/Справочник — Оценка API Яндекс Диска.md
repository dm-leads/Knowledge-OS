# Справочник — Оценка API Яндекс Диска

## Краткая суть

- **REST API Яндекс Диска** (`cloud-api.yandex.net/v1/disk`) — папки, загрузка файлов, публичные ссылки.
- **Вердикт: забрать** — для файлов, которые площадки забирают по ссылке, и для рабочих папок команды.
  Граница папки — в коде клиента, удаления в клиенте нет.
- Главная ловушка: токен выдаётся на весь Диск, если при создании приложения отметить общие права. Тогда
  граница — только в коде.

## 1. Что это и тип

Облачный REST API Диска. Не ставится. Нужен Диск владельца аккаунта; Авито умеет привязать Диск к профилю,
«тогда ссылки будут работать без ошибок» — так написано в кабинете.

## 2. Как подключается

Документация Яндекса — «Регистрация приложения для доступа к API» и «Быстрый старт» API Диска, сверено
14.10.2026:

1. `oauth.yandex.ru/client/new/` → «Для доступа к API или отладки» — **под аккаунтом владельца Диска**.
2. Права: самое узкое — «Доступ к папке приложения на Диске» (`cloud_api:disk.app_folder`, папка
   «Приложения/<название>», путь `app:/`). Шире — чтение и запись всего Диска.
3. Redirect URI у таких приложений один — `https://oauth.yandex.ru/verification_code`.
4. Токен — по ссылке `oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>`; показывается один
   раз, при потере выдаётся заново той же ссылкой.
5. Заголовок запроса — `Authorization: OAuth <токен>`.

## 3. Требования

Python со стандартной библиотекой. Демонов, MCP и приложения Диска на компьютере не нужно.

## 4. Что создаёт / меняет

Папки и файлы на Диске, публичные ссылки. Загрузка — в два шага: запрос адреса загрузки, затем сам файл;
`overwrite=true` заменяет файл на месте, публичная ссылка при этом сохраняется. Успех — файл прочитан обратно
и размер совпал.

## 5. Глобальность влияния

Локально в проекте: клиент и токен — в проекте.

## 6. Конфликты с нашей средой

Нет.

## 7. Безопасность

- **Права шире нужного — граница в коде.** В одном из проектов 14.10.2026 владелец выдал полный доступ «на
  будущее». Клиент считает все пути от одной папки, не принимает `..`, абсолютные пути и корзину, удаления не
  имеет.
- **Публичная ссылка открывает файл всем, у кого она есть.** Публиковать только то, что и так уходит наружу:
  файл объявлений, фото объявлений.
- Логин и имя владельца Диска в вывод не попадают; проверка «тот ли Диск» — по наличию нужной папки.

## 8. Профильность для нас

Высокая там, где площадка забирает файл по ссылке: автозагрузка Авито, фиды. Агент обновляет файл на месте,
ссылка не меняется, площадка подхватывает изменения по своему расписанию.

| Проверено 14.10.2026 | Статус |
|---|---|
| Токен, сведения о Диске, список папки | работает |
| Создание папок; «уже есть» — ответ 409 | работает |
| Загрузка с заменой и чтение обратно | работает |
| Публичная ссылка на файл — вида `yadi.sk/d/…` | работает с полным доступом; с правом только на папку приложения — не проверено |
| Примет ли Авито ссылку и фото с Диска | не проверено — первая загрузка покажет |

## Вердикт

**Забрать.** Права — самые узкие, какие владелец готов дать; граница папки — в коде всегда.
