Задание 1. Сцепка для 5 уникальных объявлений


Создайте новую таблицу с именем «Сцепка_[Ваш проект]» со столбцами: Заголовок, Описание, Цена, Фото.
Заполните 5 строк, создав 5 вариантов объявлений для вашего проекта. Если актуально для вашего проекта, создавайте варианты объявлений для разных видов трафика (горячий/тёплый/холодный). Используйте разные заголовки. Для «Описания» берите финальный текст из задания «Продающее описание с ИИ». В каждом описании используйте разные характеристики вашего товара или разное имя исполнителя, если это услуги. Если уникализация по смыслу не подходит, найдите на Авито сильных конкурентов и примените их уникализацию.

Задание 2. Шаблон файла «Автозагрузки» *


Изучите справочник для бизнеса Авито (help.avito.ru), раздел «Автозагрузка». Найдите шаблон для своей категории.
В новой Google Таблице создайте шаблон с обязательными колонками для начала: Id, Address, Title, Description. Добавьте 2–3 колонки, специфичные для вашей категории (например, Condition, GoodsType).
Заполните 3 тестовые строки данными из вашей сцепки для каждого вида трафика (горячий/тёплый/холодный), проверьте ваш файл на соответствие формату Avito XML v.3 https://autoload.avito.ru/format/xmlcheck/, внесите корректировки.
Отдельно укажите 3 главных нюанса при работе с автозагрузкой в вашей нише. Например: 1) важность уникализации ID; 2) точное заполнение атрибута «Состояние»; 3) нельзя загружать все объявления разом, если уже есть активные.

Задание 3. Профиль и безопасность



Пропишите в вашем файле:

название компании/профиля (максимум 30 символов, чтобы корректно отображалось в мобильной версии)

описание профиля (4–5 предложений, которые не дублируют описание объявления, а рассказывают о вас/компании)

шаблон первого сообщения в чате (приветствие + ответ на частый вопрос или уточняющий вопрос клиенту)

3 самые вероятные причины блокировки в вашей нише и как их избежать (формат: «1. Причина: ... –> Профилактика: ...»)

тип трафика для основного объявления (выберите один: горячий/тёплый/холодный, объясните в одном предложении, почему).
