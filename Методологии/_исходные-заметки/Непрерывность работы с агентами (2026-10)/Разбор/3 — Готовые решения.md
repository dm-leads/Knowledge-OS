# 3 — Готовые решения: что есть снаружи и что из этого брать

Поиск 13.10.2026: GitHub и статьи по семи темам из брифа. Просмотрено 18 кандидатов и около десяти наводок,
отобрано 10. Звёзды, даты и лицензии — из GitHub API на 13.10.2026 (факт на дату). Ничего не устанавливалось
и не запускалось. Вердикты — по [стандарту оценки](<../../../../Экосистема инструментов/03 — Ресурсы/Оценки инструментов/Стандарт — Как оцениваем внешний инструмент.md>);
карточки заведены только для того, что рекомендую и что приходит снаружи: AGENTS.md и restic.

Главный вывод: под задачу Дмитрия не нужен ни один новый агентный инструмент. Нужны два паттерна без
установки (общий файл правил и точка возврата) и одна утилита вне агентной среды (шифрованная копия).

## Что искал и не нашёл

- Готовый зрелый скрипт шифрованной копии `~/.claude` и `~/.codex`: в поиске GitHub — только репозитории
  с 0–1 звездой и без шифрования. Отсюда обычная утилита резервного копирования.
- Единое имя файла точки возврата у Anthropic, OpenAI или Cursor: его нет, есть только паттерны с разными
  именами (`claude-progress.txt`, `HANDOFF.md`, `.baton/`).
- Зрелый перенос живой сессии между агентами: только молодые проекты с десятками звёзд. Единственный
  работающий мост — встроенный импорт Codex (см. «2 — Разбор сред»).
- Про обход блокировок и региональных ограничений ничего не искал и в список не включал.

Проверка: агент с чистым контекстом сверил по GitHub API десять репозиториев из этого списка — звёзды,
лицензии и версии совпали. Описания claude-mem, beads, Continuous-Claude и cass он не открывал: по ним
остаётся слово субагента, который вёл поиск.
