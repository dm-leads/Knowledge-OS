# 2 — Разбор трёх сред: что каждая умеет для продолжения работы

Проверено 13.10.2026. У каждого утверждения — источник и статус:

- **док** — официальная документация, ссылка в конце раздела;
- **диск** — проверено на этой машине (см. «1 — Карта машины»);
- **форум** — слова сотрудника на форуме, вторичный источник;
- **не найдено** — в документации нет, указано, где искал. Это не значит «невозможно»: в интерфейсе не
  проверялось, если не сказано обратное.

Среды у Дмитрия: Cursor (в нём агент Cursor и два расширения — Claude Code и Codex), настольное приложение
ChatGPT с Codex, настольное приложение Claude. Расширение и терминал одного агента делят одну домашнюю папку,
поэтому ниже три столбца по агентам, а не по окнам.

## Сильные и слабые стороны для продолжения работы

| Среда | Сильное | Слабое |
|---|---|---|
| **Claude Code** | Вся локальная часть — обычные файлы: история, память, навыки, настройки. Расширение и терминал делят историю. Правила канона уже подключены импортом. Настройки из Codex и Cursor забирает командой `/import`. Есть штатный запасной вход по ключу API | Чужую историю чатов не импортирует (не найдено). Память и история привязаны к пути папки. Очистка по умолчанию — 30 дней: часть истории на машине уже удалена. Настольное приложение не работает с запасным входом. Терминальная версия на машине (2.1.143) старее расширения (2.1.296): сама `AGENTS.md` не читает, команды `/import` не знает и старше исправления, после которого очистка перестала трогать вложенные папки памяти |
| **Codex** | Единственный, кто переносит историю чатов: импорт правил, навыков, MCP и чатов из Claude Code и Cursor. Приложение и терминал делят одну папку. `AGENTS.md` — родной формат. Автоочистки истории не видно | Импорт берёт чаты за 30 дней; автообновление по документации есть, но на этой машине уже импортированный чат новые сообщения не получал. Импорт отдаёт переписку целиком другому поставщику. Импорт сам создаёт копии паспорта, и они расходятся с оригиналом. Правила канона не подключены. Память выключена по умолчанию. Предел 32 КиБ на файлы правил |
| **Агент Cursor** | Читает и `AGENTS.md`, и `CLAUDE.md`, и навыки из папок Claude без настройки. Правила пользователя можно держать локально, файлами в `~/.cursor/rules`. Это оболочка, в которой живут оба других агента | Правила из настроек держит в аккаунте. Истории на сервере нет, она в одной большой базе и привязана к пути. Нет памяти. Нет рабочих MCP компании (Lark, Google Sheets, Search Console) — диск. Если упало само приложение Cursor, вместе с ним недоступны оба расширения. Навыки из `~/.claude/skills` и `~/.agents/skills` читает одновременно; как ведёт себя при одном навыке в двух папках — не описано, а навыки компании уже лежат в обеих |

## Что переносится само и что нет

| Переносится само | Нужна разовая настройка | Не переносится |
|---|---|---|
| Файлы проекта — любой агент открывает папку | Правила канона для Codex и Cursor: сейчас не доходят | История чатов: только импортом в Codex |
| `AGENTS.md` — Codex и Cursor из коробки | `AGENTS.md` для Claude Code: строка импорта в `CLAUDE.md` | Автопамять Claude Code: другие агенты её не загружают, но могут прочитать как файл |
| `CLAUDE.md` — Claude Code и Cursor из коробки | Навыки канона для Codex: ссылки в `~/.agents/skills` | Всё, что живёт в аккаунте |
| Навыки из `~/.claude/skills` — Claude Code и Cursor | MCP: три формата и три набора; разовый перенос — импортом Codex или командой `/import` Claude Code, дальше наборы ведутся раздельно | |

## Утверждения из расшифровок: что подтвердилось

| Утверждение автора | Вердикт | Источник |
|---|---|---|
| В `~/.claude` лежат сессии, память, навыки, настройки | Подтверждено. Уточнение: вход и личные MCP — в `~/.claude.json`, вне папки | [4] |
| Локальные сессии удаляются через 30 дней, срок задаётся параметром | Подтверждено: `cleanupPeriodDays`, минимум 1, ноль — ошибка проверки. Верхний предел не найден | [4] |
| Память репозитория хранится в `~/.claude`, а не в репозитории | Подтверждено; переносится параметром `autoMemoryDirectory` | [21] |
| MCP из терминала локальные, коннекторы claude.ai — только в облаке | Подтверждено. Без входа по подписке коннекторы не загружаются | [3] |
| Навыки из каталога в облаке теряются с аккаунтом | Частично: синхронизированные навыки скачиваются в `~/.claude/skills/synced`, копия на диске остаётся | [2] |
| Экспорт данных в настройках; файлы проектов не выгружаются | Экспорт подтверждён, ссылка живёт 24 часа. Про файлы проектов — подтверждено косвенно, другой страницей | [32], [33] |
| Проекты: координатор и треды, память файлами, инструкции до 16 000 символов | Подтверждено: публичная бета для Pro и Max. Локальный тред — через Remote Control, с версии 2.1.280 | [29] |
| Даты 17.09 и 23.09.2026 | Не подтверждено: на странице документации дат нет | [29] |
| «Рутины запускают треды по расписанию» | Неточно: routines — отдельная сущность аккаунта, создаётся из проекта | [28] |
| В `~/.claude` всё переживает смену аккаунта | Прямо не описано. Ближайшее: у каждой папки настроек «свои настройки, история сессий и вход» | [24] |

Советы автора про одноразовые номера, карты и подтверждение личности другой страны в разбор не взяты:
это нарушение условий сервиса.
