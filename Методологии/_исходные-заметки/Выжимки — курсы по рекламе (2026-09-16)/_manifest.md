# Выжимки — курсы по рекламе (2026-09-16) — _manifest

## Что это

Три курса, купленных и транскрибированных Дмитрием, прочитаны целиком (только `.txt`,
4,3 МБ, ~1,4 млн токенов работы читателей). Из каждого блока извлечено **только
проверяемое** — механика кабинетов, лимиты, правила площадок, пороги решений, формулы —
с пометкой источника `(модуль, файл)`. Мнение автора курса отделено от правила площадки.
Мотивация, кейсы без цифр, «как продавать свои услуги» — выброшены.

Исходники: `../Avito-text` (80 расшифровок), `../VK40-text` (107), `../TG-text` (33).

## Что с этим уже сделано

- **Независимая проверка (Codex, GPT-5)** юридических и экономических выводов —
  `Учебный центр/02 — Области/Маркетинг и продажи/Привлечение/Аналитика — Проверка выводов
  из курсов по ВК и Авито — 2026-09-16.md`. **Опровергнуты:** «штрафы 4–20 тыс.» (реально
  200–500 тыс. ₽ для юрлица, ч. 15–16 ст. 14.3 КоАП), «самореклама не маркируется»
  (первоисточник не найден), «рекламодатель не платит 3 % никогда» (неверно для договоров
  с иностранными лицами). Любая юридическая цифра берётся оттуда, не из выжимок.
- Память устройства: `ad-marking-law-real-penalties.md`.

## Как пользоваться

1. Это **сырьё**, не канон. Канонические документы — в `Методологии/Платный трафик/`
   (строятся из этих выжимок), навыки — `ads-*`.
2. Цифры (цены, лимиты, ставки) — на дату записи курса (2025). Перед применением
   проверять в живом кабинете; расхождение записывать в канонический документ строкой
   «замер ДД.ММ: было / стало».
3. Внутри выжимок есть разделы «Спорное и требующее проверки» и «Признаки устаревания» —
   читать их первыми.
4. Курсы ориентированы на товарку, инфобиз и локальные услуги. **Пороги и конверсии
   других ниш на онлайн-образование с чеком 70 000 ₽ не переносятся** — переносится метод
   расчёта. Что именно нельзя переносить — раздел 4.2 проверки Codex.

## Чего в курсах нет

Вебинарная воронка (доходимость, конверсия регистрация → эфир → оплата), экономика
длинного цикла при высоком чеке, взаимный пиар, API VK Рекламы, суммы штрафов
(были на слайдах, в звуке отсутствуют). Это добирается из других источников или меряется.
