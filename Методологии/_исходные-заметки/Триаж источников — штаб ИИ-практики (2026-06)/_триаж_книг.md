# Триаж библиотеки книг (склад источников)

Карта «папка → домен компетенций» для библиотеки деловых книг. **Это склад источников, а не контент для контекста агента.** Карточки методологий извлекаем точечно и инкрементально — только под домен, который реально берём в работу.

- **Расположение библиотеки:** `E:\Cursor\Обучающие материалы\Для транскрибации\Книги_текст`
- **Объём:** 1486 книг (уникальных), у каждой есть `.txt` и `.simple.txt` (упрощённая версия — быстрее для извлечения).
- **Дата триажа:** 2026-06-06.

## Очередь извлечения карточек

1. **Продажи** (первый) — закрывает пустой домен в карте компетенций; связка с транскрибацией звонков менеджеров.
2. Управление проектами / менеджмент.
3. Далее — по потребности проекта.

**Правило извлечения:** под выбранный домен читаем `.simple.txt` нужных книг → выделяем именованные методологии/авторов → оформляем карточку по `_шаблон_карточки.md`. Не «прочитать домен целиком», а взять то, что действительно работает.
