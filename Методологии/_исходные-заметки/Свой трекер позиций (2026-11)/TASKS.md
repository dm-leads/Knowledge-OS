## Найдено по ходу

- Topvisor (API, чтение, 03.11.2026): проект-пример — несколько тысяч фраз; Яндекс снимался нерегулярно, Google не
  снимался почти год. Метод цены `checker/price` вернул сумму по отбору, который охватывает все проекты
  аккаунта, — как цену проекта не брать.
- Третий поставщик выдачи Яндекса — официальный Yandex Search API v2: отложенный запрос 30,5 ₽ / 1 000 днём и
  25,41 ₽ ночью (с НДС), до 100 результатов в одном запросе, ответ от 5 минут, хранится 12 часов. Google нет.
  В XML — только органика, без рекламы и колдунщиков. Адаптер `yandex_search` уже есть в Контент-машине.
- Контент-машина уже даёт: интерфейс `SerpSource`, клиент только-чтение, бюджет-гейт, учёт расхода, кэш выдачи,
  позиции из консолей (`core/positions.py`).
