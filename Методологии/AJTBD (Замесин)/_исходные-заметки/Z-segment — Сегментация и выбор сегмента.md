## 1. Концепции и идеи

- **Выбор сегмента = выбор судьбы.** Решение о том, за какую работу (джобу) конкурировать, — одно из важнейших стратегических решений в продуктовой работе. По стоимости последствий ошибки сравнимо только с выбором сооснователя. (источник → [txt-1.1])
- **Сегментировать по работам, не по демографии.** Демография (возраст, доход, регион) — описание группы; работа — то, за что реально конкурируешь. Демографические признаки можно и нужно комбинировать с работами («когда + кто»). (источник → [txt-1.1])
- **Целевые работы вместо целевой аудитории.** Термин «целевые работы» точнее: он привязан к джобе, а не к безликому демографическому портрету. (источник → [txt-1.1])
- **Работа первична.** Всё, что делает продукт (ценность, продажи, возвращаемость), — следствие того, что нашли людей с важной, частотной, неудовлетворённой, денежной работой. (источник → [txt-1.1])
- **Локальный оптимум.** Высокая вероятность, что без систематической оценки сегментов команда работает не на экономически самый привлекательный сегмент. (источник → [diag-1.1], [diag-1.2], [diag-1.3])
- **Точки роста кроются вне текущих работ.** Граф работ содержит предыдущие и следующие работы, смотри кейс Самолёт/Живика и Practicum QA. (источник → [txt-1.1])
- **Малый рынок — не приговор для стартапа.** Питер Тиль: успешные компании начинали с маленьких рынков и расширялись концентрическими кругами. (источник → [txt-1.1])
- **Бизнес-возможности бесконечны.** Появляются новые джобы, старые решения устаревают — пространство для конкуренции не исчерпывается. (источник → [txt-1.1])
- **MVP при поиске сегмента имеет ограниченный ROI.** При нулевых продажах нет качественной информации «почему». MVP оправдан только если он очень дёшев и даёт доступ к качественной обратной связи. (источник → [txt-1.1])

## 2. Точные определения

- **Сегмент по работам** — группа людей, у которых прямо сейчас есть работа, либо которые выполняли эту работу в прошлом, либо с высокой вероятностью начнут её выполнять в ближайшее время. (источник → [txt-1.1])
- **Целевые работы** — работы (джобы) сегмента, которые наречены целевыми после прохождения полного цикла: исследование → количественная валидация → акт выбора. (источник → [txt-1.1])
- **Super Discovery** — особый этап исследования при отсутствии даже гипотезы работы; начинается с экспертных интервью для понимания устройства рынка. Термин авторский, в литературе не встречается. (источник → [txt-1.1])
- **Широкая гипотеза работы** — гипотеза максимально высокого уровня, из которой убраны все заужения; описывает то, зачем человек что-то делает, а не что именно он делает. (источник → [txt-1.1])
- **Не-сегменты** — группы респондентов, за работы которых компания не хочет или не может конкурировать; выделяются отдельно при кластеризации результатов исследования. (источник → [txt-1.1], [diag-1.3])
- **Экономическая карта сегментов** — матрица оценки привлекательности сегментов: Size × AMMPPU (или AMMPPU) × Extra Value × Competition. (источник → [diag-1.1], [diag-1.2], [diag-1.3], [seg-pdf])
- **Фокусный сегмент** — сегмент, выбранный как приоритетный; на него направлено целеполагание, зоны ответственности, планирование спринтов. (источник → [diag-1.1])
- **Opportunity cost** — издержки упущенной возможности: цена неправильного выбора сегмента, когда конкурент вырос на соседнем, более денежном сегменте. (источник → [txt-1.1])
- **ЛПР / ЛВР** — лицо, принимающее решение / лицо, влияющее на решение; в B2B важна их личная работа (джоба), а не только бизнес-работа. (источник → [diag-1.3], [seg-pdf] стр.4)

## 3. Формулы

**Экономическая карта сегментов:**
```
Size × AMMPPU × Extra Value × Competition
```
(в разных слайдах фигурирует как AMMPPU и AMPPU — оба варианта присутствуют в источниках; расшифровка в источниках не раскрыта)
(источник → [diag-1.1], [diag-1.2], [diag-1.3], [seg-pdf])

**Формула оценки сегментов при ранжировании (4 фактора):**
```
Важность × Частотность × Размер × Неудовлетворённость (текущим решением)
```
(на слайде — оси графика: Размер по вертикали, Частотность, Важность-Денежность; Удовлетворённость — цветовая шкала красный→зелёный)
(источник → [txt-1.1])

**Скоринг зрелости сегментации (диагностика):**
Три вопроса с весами × 2 и × 3:
- Используете ли Core Jobs + Big Jobs в сегментации? (вес X3)
- Есть ли знание/гипотеза, что работаете на экономически самый привлекательный сегмент? (вес X2)
- Можете ли поддерживать фокус на фокусных сегментах (5 последних гипотез → всё ли на фокусный сегмент)?
Шкала ответов: 0 (худший) / 1 (средний) / 2 (лучший)
(источник → [diag-1.1], [seg-pdf] стр.1)

**Скоринг: источник информации про сегменты (диагностика):**
- Делали ли кастдев за последние 1,5 года?  Шкала: нет=0 / проблемное интервью=1 / JTBD-исследование=2 (вес X2)
- Сколько интервью: до 10=0 / 10–19=1 / 20+=2 (вес X2)
(источник → [diag-1.2], [seg-pdf] стр.2)

**Скоринг: знание сегментов конкурентов:**
- Знаете ли, на какие сегменты работают конкуренты? Нет=0 / думаем=1 / знаем=2
- Знаете ли, почему конкуренты выбрали эти сегменты? Нет=0 / есть догадки=1 / знаем=2
(источник → [diag-1.3], [seg-pdf] стр.3)

**Скоринг B2B: знание личных работ ЛПРов/ЛВРов и личные продажи:**
- Знаете ли личные работы ЛПРов/ЛВРов? Нет=0 / думаем, но не продаём через них=1 / знаем и продаём=2
- Сколько продаж сделали лично? 0=0 / 1–9=1 / >10=2 (вес X2)
(источник → [diag-1.3] стр.4, [seg-pdf] стр.4)

## 4. Пошаговые процедуры / алгоритмы

### Алгоритм поиска и выбора целевых работ (5 этапов)
1. **Формирование гипотезы высокоуровневой работы** — убрать все заужения, сгенерировать максимально широкую джобу. Три ситуации:
   - Нет идей → идти к экспертам (Super Discovery)
   - Есть идея и уверены → забыть идею, преобразовать её в гипотезу джобы
   - Есть идея, не уверены → сгенерировать гипотезу работы и забыть идею
2. **Оценка рынка в деньгах** — итерировать параллельно с п.1 до тех пор, пока гипотеза не попадёт на достаточно денежный рынок
3. **Качественное Job-driven исследование** (итерации по 6–8 интервью):
   - Рекрутировать по критерию «платит деньги за решение, связанное с широкой гипотезой работы»
   - Рекрутировать из разных каналов, ~10 кандидатов → 6–8 проведённых интервью
   - После каждой итерации объединять в сегменты, выделять не-сегменты
   - Останавливаться, когда за последние 10 интервью ничего принципиально нового не услышано (~80% полноты)
4. **Количественная валидация** — ранжировать сегменты по: важность × частотность × размер × неудовлетворённость; убирать те, за которые нет ресурсов/компетенций или не совпадают с принципами
5. **Акт выбора** — назначить работы целевыми; после этого можно прокапывать граф ниже уровня
(источник → [txt-1.1])

### Процедура Super Discovery (нет гипотезы рынка)
1. Найти 3+ экспертов, которые продавали что-то на интересующем рынке
2. Задавать три вопроса:
   - «Что на этом рынке покупают и почему?»
   - «Что за сегменты?»
   - «Что я могу на этом рынке продать? Кому? Почему? Как?»
3. Триангулировать: слушать только то, в чём соглашаются минимум 2 из 3 экспертов
4. Фиксировать логику эксперта (почему именно это), а не только его рекомендацию
(источник → [txt-1.1])

### Процедура формирования широкой гипотезы работы из идеи
1. Взять идею продукта (узкую)
2. Поднять на уровень выше: убрать конкретный формат («слушать ушами» → «узнавать»), убрать конкретный объект («город» → «город/страна/достопримечательность»)
3. Убрать все дополнительные фильтры — получить максимально высокоуровневую джобу
4. Далее заузить опционально на последующих итерациях
(источник → [txt-1.1])

### TODO-план для команды с низким скором по диагностике (приоритет 1, ДО всех действий)
1. Если хватает экспертизы — выделить сегменты по работам экспертно
2. Если экспертизы не хватает → делать AJTBD-исследование [интервью + опросы] с последующей количественной валидацией
3. Сделать экономическую карту сегментов: Size × AMMPPU × Extra Value × Competition
4. Выбрать экономически самые привлекательные сегменты и отбрасывать непривлекательные
(источник → [diag-1.1], [diag-1.2], [diag-1.3], [seg-pdf])

## 5. Фреймворки / модели

### Экономическая карта сегментов
Матрица для ранжирования сегментов по 4 измерениям:
- **Size** — количество людей, выполняющих эту работу
- **AMMPPU / AMPPU** — средний/рентабельный денежный показатель на пользователя (расшифровка не раскрыта в источниках)
- **Extra Value** — возможность создать дополнительную ценность
- **Competition** — конкурентная ситуация (чем меньше конкуренция, тем привлекательнее)
(источник → [diag-1.1], [seg-pdf])

### Матрица принятия решения «Стартап vs Корпорация»
| Приоритет выбора сегмента | Логика |
|---|---|
| Стартап | Неудовлетворённость (красные сегменты); маленький рынок не проблема |
| Корпорация | Размер (большой рынок); требуется достаточно большой TAM |
(источник → [txt-1.1])

### Простая логика выбора сегмента (7 факторов)
Внешние: Размер → Денежность → Неудовлетворённость → Частотность
Внутренние: Компетенции и ресурсы → Риски → Совпадение с ценностями/стратегией акционеров
Процесс: ранжировать → минусовать те, за которые нельзя конкурировать → оставить небольшое число → выбрать
(источник → [txt-1.1])

### Граф работ как инструмент стратегии
Продукт конкурирует не за одну джобу, а за кусочек графа. Точки роста — смежные работы:
- Предыдущие работы (подготовка к целевой работе)
- Следующие работы (что делают после)
- Высокоуровневые работы (зачем всё это нужно)
Знание графа позволяет применять 30+ механик продуктовой стратегии.
(источник → [txt-1.1])

### Диагностический чеклист «Сегментация и выбор ниши» (4 блока)
1. **1.1 Фокусные сегменты и их работы** — используют ли Core/Big Jobs в стратегических решениях?
2. **1.2 Источник информации про сегменты** — делали ли JTBD-исследование?
3. **1.3 НЕ сегменты и сегменты конкурентов** — знают ли, кто чьи сегменты и почему?
4. **1.4 B2B-специфика** — знают ли личные работы ЛПРов/ЛВРов, продают ли через них?
По каждому блоку — скоринг 0/1/2, некоторые вопросы с весом x2, x3. TOD-план даётся в зависимости от скора с указанием приоритета (1/2-3) и момента («ДО всех действий» / «в параллель»).
(источник → [diag-1.1], [diag-1.2], [diag-1.3], [seg-pdf])

## 6. Разобранные примеры / кейсы / цифры

### Кейс 1: Мета (психотерапевт) — личный опыт Замесина
- 2017 год: 40 интервью о поиске психотерапевта → влюбился в джобу «найти психотерапевта»
- Сделал сервис подбора психотерапевта; монетизация: половина первых 4-х сессий
- 2020: узнал, что конкурент (сервис онлайн-психотерапии «Ясно») имеет выручку в 10–30 раз больше
- Причина: выбрана не та джоба; ценность не в «найти», а в самой терапии; деньги — в сессиях, а не в подборе
- [вывод Замесина]: «Я заплатил огромный opportunity cost»
(источник → [txt-1.1])

### Кейс 2: HotBot AI (Федя Киреев)
- Проблема: клиенты не понимали ценность, сравнивали по фичам, продажи тяжёлые
- Решение: ABC-сегментация по работам (джобам), уже для которых нанимали HotBot
- Результат: переписка коммуникации под ценность работ → управляемые продажи
- Второй шаг (упоминается): нашли более маржинальный соседний сегмент
(источник → [txt-1.1])

### Кейс 3: Самолёт / Живика (кейс про предыдущие работы)
- Застройщик: все конкуренты конкурировали за джобу «найти и купить квартиру»
- Самолёт нашёл предыдущую работу: «накопить на первый взнос» при одновременном «жить в квартире» (аренда мешала копить)
- Продукт Живика: «заезжай с первого дня, арендные выплаты идут в счёт накопления первого взноса»
- Это кардинальная смена парадигмы для конкурентов; копирование займёт 1–2 года
(источник → [txt-1.1])

### Кейс 4: Practicum QA (предыдущие работы в edtech)
- Работа «обучиться на QA в США» — 4-я–5-я в последовательности
- Ключевая предыдущая работа: «понять, что я могу работать в IT тестировщиком»
- Механика: выходить на более ранние работы в коммуникации («ты можешь работать в IT → ты можешь быть тестировщиком → вот как обучиться → иди к нам»)
(источник → [txt-1.1])

### Кейс 5: StarKurs / SnapCourse (широкая vs узкая гипотеза)
- Идея: обучение сейлзов и сотрудников поддержки о том, что изменилось в продукте
- Широкая гипотеза: «руководители, которые чему-то обучают любых сотрудников»
- Ограничение: обучение не дольше 2–3 часов (формат мобильного приложения)
- Критерий рекрута: платят деньги за любой инструмент обучения сотрудников
- Найденные сегменты: IT-менеджер госпиталя (заинтересовать врачей-фрилансеров), тренер команды, Continuous Improvement Manager логистики (показать изменения правил в физическом мире, проблема безопасности), cybersecurity (Loom-конкурент — не сегмент)
- Итог: 4 сегмента за ~30 интервью / 4 итерации / ~2 месяца
(источник → [txt-1.1])

### Кейс 6: Джуниор-продакты США — провал с узкой гипотезой
- Гипотеза: джунам нужны алгоритмы создания ценного продукта
- 50 решенческих интервью → 0 продаж
- Причина (от эксперта): реальная джоба джуна — «получить минимальное доверие от команды», а не создавать ценность для клиентов
(источник → [txt-1.1])

### Кейс 7: Путь к беременности (граф работ и спящие работы)
Четыре последовательных работы:
1. «Хочу забеременеть, занимаясь сексом» — no-brainer, мало проблем
2. (Спустя 3–6 мес.) «Хочу понять, что делать, чтобы забеременеть» — идут к гинекологу; нарастают страх, тревога, вина; гинеколог некомпетентен → частая смена гинеколога
3. (Спустя год страданий) «Могу ли я вообще иметь детей?» — нет однозначного решения; часть случайно находит репродуктолога; появляются работы «сохранить брак», «получить поддержку»
4. (Итог) «Мне нужно ЭКО» — только те, кому не помог репродуктолог; клиники уже работают
Цифры: до ЭКО доходят очень немногие (оценка фаундера Димы Кудрявцева, не верифицированная)
Стратегический вывод: за джобу 2 (сильная привычка → гинеколог) конкурировать тяжело; за джобу 3 (нет устойчивого решения, высокая боль) — легче; за джобу 4 — уже занято клиниками
(источник → [txt-1.1])

### Цифры из источников
- За последние 10 интервью ничего нового → ~80% полноты знания о сегментах (источник → [txt-1.1])
- Типичное исследование поиска сегмента: 1,5–6 месяцев (в зависимости от доступности респондентов) (источник → [txt-1.1])

## 10. Термины в глоссарий

| Термин | Краткое определение |
|---|---|
| Сегмент по работам | Группа людей с одной и той же работой (джобой) сейчас/в прошлом/в ближайшем будущем |
| Целевые работы | Джобы, официально наречённые целевыми после выбора по итогам исследования и валидации |
| Super Discovery | Начальный этап поиска сегмента при отсутствии гипотезы; основной инструмент — экспертные интервью |
| Широкая гипотеза работы | Максимально высокоуровневая гипотеза джобы без заужений |
| Не-сегменты | Группы, за работы которых компания не конкурирует; выявляются при кластеризации интервью |
| Экономическая карта сегментов | Size × AMMPPU × Extra Value × Competition |
| Opportunity cost сегмента | Цена выбора субоптимального сегмента в сравнении с более привлекательным рядом |
| Фокусный сегмент | Выбранный приоритетный сегмент; на него направлены все ресурсы команды |
| Локальный оптимум (в сегментации) | Ситуация: работаем на достаточно хороший сегмент, но рядом есть значительно лучший |
| Триангуляция (экспертов) | Брать 3+ экспертов и слушать только то, в чём соглашаются минимум 2 из 3 |
| Граф работ | Сеть взаимосвязанных работ с предыдущими, следующими и высокоуровневыми работами |
| Критерий рекрута | Признак, по которому отбираются респонденты: «платит деньги за решение для широкой гипотезы работы» |
| ЛПР / ЛВР | Лицо, принимающее решение / лицо, влияющее на решение (B2B) |

## 11. Типичные ошибки / антипаттерны

1. **Влюбиться в сегмент.** Влюблённость блокирует рациональную оценку opportunity cost. Кейс: Мета vs «Ясно». (источник → [txt-1.1])
2. **Начинать с узкой гипотезы работы.** Всё найдёте в ней что-нибудь и пропустите более привлекательные соседние сегменты. Кейс: StarKurs — узкая гипотеза (сейлзы/поддержка) vs широкая (любые сотрудники). (источник → [txt-1.1])
3. **Начинать с идеи и «искать, кому это надо».** Неизбежно что-то найдёте — это ловушка; процесс должен идти от гипотезы работы, а не от идеи. (источник → [txt-1.1])
4. **Быть свято уверенным, что взлетит.** Confirmation bias, селективное внимание — мозг будет игнорировать противоречащую реальность. (источник → [txt-1.1])
5. **Галлюцинировать про работы клиентов.** «Мужики очень плохо понимают девушек». Нужно изучать, а не проецировать. (источник → [txt-1.1])
6. **Делать MVP без доступа к качественной информации.** 95–98% случаев: 0 продаж → непонятно почему. Нет данных для итерации. (источник → [txt-1.1])
7. **Не оценивать рынок в деньгах до начала исследования.** Можно провести прекрасное исследование на рынке, где почти нет денег. (источник → [txt-1.1])
8. **Не знать, на какие сегменты работают конкуренты и почему.** Высокая вероятность локального оптимума. (источник → [diag-1.3])
9. **Регулярно размазывать ресурсы** (не сохранять фокус на фокусных сегментах). Проверка: 5 последних гипотез — на фокусный сегмент? (источник → [diag-1.1])
10. **Прокапывать граф низкоуровневых работ до выбора сегмента.** Инвестиции сгорят — большинство сегментов не станут целевыми; время интервью ограничено. (источник → [txt-1.1])
11. **В B2B не знать личные работы ЛПРов/ЛВРов.** Личные работы ЛПР могут значимо увеличить конверсию в продажу. (источник → [diag-1.3] стр.4, [seg-pdf] стр.4)
