## 1. Концепции и идеи

- Демо-интервью проводилось для поиска сегментов B2C и изучения **дерева высокоуровневых и низкоуровневых работ** на примере сервиса LaModa. (источник → весь транскрипт, вводная часть)
- Интервью служит достижению бизнес-цели: **ABCD-сегментация** → выбор AB-сегментов → выявление подсегментов внутри них → количественный опрос → таргетирование. (источник → вводная часть)
- Ключевая задача демо: показать, как **прокапывать дерево работ** — переходить от высокоуровневых к низкоуровневым работам через конкретные вопросы. (источник → вводная часть)
- **В B2C-интервью важно не фреймировать респондента**: не называть свой продукт и компанию при установлении границ интервью, чтобы человек не догадался, что именно вы хотите услышать. (источник → комментарий интервьюера после вводного блока)
- Для **частотных работ** (регулярно решаемых потребностей) изучают дополнительно работу первого использования решения — чтобы понять начальный триггер. (источник → комментарий перед блоком «первая покупка»)
- Для **каждого шага** (действия) респондента задаётся вопрос о желаемом результате — это и есть **низкоуровневая работа**. (источник → комментарий после блока низкоуровневых работ)
- Результат и проблемы — **минимум знания про работы**. При наличии времени изучают также контекст, триггер, частотность, удовлетворённость для каждой низкоуровневой работы. (источник → комментарий после блока низкоуровневых работ)
- Информацию по интервью хранят в Notion (конспект по каждому респонденту), затем выносят на борду FigJam для анализа паттернов. (источник → финальный блок про работу с заметками)
- Инсайты нескольких интервью по горизонтали → поиск повторяющихся паттернов → формирование гипотез о сегментах. (источник → финальный блок FigJam)

## 2. Точные определения

- **Дерево работ** — иерархическая структура: высокоуровневые работы (зачем в целом нанимают решение) → целевая работа (на что нанимают прямо сейчас) → низкоуровневые работы (отдельные шаги внутри целевой работы, каждый с желаемым результатом). (источник → вводная + методологические комментарии)
- **Целевая работа** — работа, на которую респондент нанимает изучаемое решение в данный момент. (источник → комментарий перед блоком целевой работы)
- **Работа первого использования** — работа, ради которой человек впервые нанял данное решение; изучается для частотных работ сокращённым списком вопросов. (источник → комментарий перед блоком первой покупки)
- **Предыдущие работы** — работы/решения, которые человек использовал до текущего решения; изучаются ещё более сокращённым списком (только «когда / хочу»). (источник → комментарий про предыдущие работы)
- **Низкоуровневые работы** — работы на уровне отдельных шагов использования решения; для каждого шага = желаемый результат этого шага. (источник → комментарий после блока низкоуровневых работ)
- **Квалифицирующий блок** — блок вопросов после знакомства: получаем общую информацию о респонденте, его поведении, особенностях — контекст, который определяет его как покупателя. (источник → комментарий после квалблока)
- **Сердцевина работы** — формула «когда [контекст/триггер], хочу [результат], чтобы [работа выше уровнем / ценность]». (источник → блок формулировки работ)

## 3. Формулы

- **Формула работы (сердцевина):**
  `Когда [контекст + триггер + психологические особенности], хочу [ожидаемый результат], чтобы [работа выше уровнем / ценность]`
  (источник → блок разбора конспекта и формулировки работ)

- **Шкала важности:** от 1 до 10, где 1 = «вообще не важно», 10 = «вопрос жизни, смерти и безопасности себя и семьи». (источник → блок целевой работы, вопрос Вики к Лене)

- **Шкала удовлетворённости решением:** от 1 до 10, где 1 = «вообще не подходит», 10 = «супер идеально». (источник → блок работы первого использования)

- **Шкала соответствия цены и ценности:** от 1 до 10, где 10 = полный матч, 1 = «слишком много плачу за это». (источник → блок целевой работы, вопрос про стоимость сервиса)

## 4. Пошаговые процедуры / алгоритмы

### 4.1 Структура блоков демо-интервью (порядок)

1. **Знакомство и установление границ** — представиться, получить согласие на запись, обозначить тему (без называния продукта/компании), установить комфорт. (источник → блок «знакомство»)
2. **Квалифицирующий блок** — рассказ о себе, о поведении (где покупает, как часто, что использует). Выявляем контекст и квалифицирующие факторы. (источник → блок «квалификация»)
3. **Целевая работа** — полный список вопросов (результат, ситуация, триггер, зачем это нужно, негативные эмоции без решения, частотность, важность 1–10, ценность, удовлетворённость 1–10, проблемы, мотивация продолжать использовать). (источник → блок «целевая работа»)
4. **Работа первого использования** (только для частотных работ) — сокращённый список вопросов (контекст, результат, удовлетворённость, проблемы). (источник → блок «первая покупка»)
5. **Предыдущие работы** — список решений, которые использовал до; для каждого: результат, ситуация, проблемы (очень сокращённо). (источник → блок «предыдущие работы»)
6. **Низкоуровневые работы** — просим рассказать по шагам, что происходило после принятия решения использовать решение; для каждого шага: желаемый результат, проблемы. (источник → блок «низкоуровневые работы»)
7. **Ключевая ценность** — открытый вопрос: «В чём для тебя основная ценность от [решения]?»; «Как бы ты убедил(а) друга начать использовать?»; «В какой момент ты осознал(а) эту ценность?» (источник → финальный блок интервью с Леной)
8. **Работа с заметками после интервью** — пересмотр конспекта, перенос в нужные секции, формулировка работ по шаблону, выгрузка в FigJam. (источник → блок разбора конспекта)

### 4.2 Алгоритм работы с заметками и формулировки работ

1. Делать заметки прямо во время интервью (респондент не видит экран — норма для демо).
2. Сразу после интервью: пересмотреть заметки, откорректировать, перенести реплики в нужные секции шаблона (контекст/триггер → «когда», результат → «хочу», связь с работой выше → «чтобы»).
3. Формулировать работу по сердцевине: «когда / хочу / чтобы».
4. Заполнить поля: важность (1–10), частотность (конкретные цифры), удовлетворённость (1–10), проблемы, драйверы, барьеры, ценности.
5. Вынести ключевую информацию на борду FigJam: фото респондента (опционально), легенда (цветовое кодирование — работа / проблемы / барьеры / ценности / инсайты), сам конспект, работы с полями, предыдущие работы, ключевая ценность, низкоуровневые работы.
6. По горизонтали добавлять следующих респондентов → искать паттерны.
(источник → финальный блок про работу с заметками и FigJam)

## 5. Фреймворки / модели

### 5.1 Структура карточки работы (шаблон Notion/FigJam)

- **Название работы** (суть, видна из «хочу»)
- **Когда** = контекст + триггер + предыдущий опыт + психологические особенности + негативные эмоции без решения
- **Хочу** = ожидаемый результат (что именно хочу получить)
- **Чтобы** = работа выше уровнем / ценность / эмоциональная составляющая
- **Важность** (1–10, шкала с якорями)
- **Частотность** (конкретные цифры, привязка к временному периоду)
- **Решение** (что нанимает)
- **Ценности** (что ценит в решении)
- **Удовлетворённость** (1–10)
- **Проблемы** (красные стикеры)
- **Драйверы** к использованию
- **Барьеры**
(источник → блок разбора конспекта + блок FigJam)

### 5.2 Структура FigJam-борды по интервью

- Фото респондента (опционально)
- Легенда с цветовым кодированием типов информации
- Конспект (копипаст из Notion)
- Базовая информация о респонденте
- Оранжевые карточки = интересные инсайты / факты о респонденте
- Карточки работ (целевая, первого использования, предыдущие)
- Драйверы / барьеры
- Ключевая ценность
- Низкоуровневые работы (под целевой работой)
(источник → блок FigJam)

### 5.3 Дерево работ (структура уровней)

```
Работа выше уровнем (зачем вообще)
  └── Целевая работа (на что нанимают решение сейчас)
        ├── Работа первого использования
        ├── Предыдущие работы (альтернативные решения раньше)
        └── Низкоуровневые работы:
              шаг 1 → желаемый результат шага 1
              шаг 2 → желаемый результат шага 2
              ...
```
(источник → методологические комментарии по всему тексту)

## 6. Разобранные примеры / кейсы / цифры

### Кейс: LaModa, респондент Лена (B2C-интервью)

**Контекст респондента:**
- 24 года, живёт в Анапе (маленький город), до этого 6 лет в Москве
- Работает удалённо (маркетинг в образовательных проектах + свои проекты)
- Спорт 3 раза в неделю
- 90%+ покупок одежды — онлайн (мало хороших магазинов в городе)
- Готовится к свадьбе → повышенная частотность покупок
(источник → квалификационный блок)

**Целевая работа (на что нанимает LaModa сейчас):**

> Когда я живу в маленьком городе, где нет брендов, которые я люблю, и у меня есть свободное время дома, и мне не хочется его тратить на торговые центры, и приближается сезон / мероприятие — хочу быстро найти/выбрать/заказать/примерить/оплатить/при необходимости легко вернуть понравившуюся вещь — чтобы хорошо выглядеть на мероприятии / не было жарко или холодно в сезон, сэкономить время и получить комфорт.

- **Важность:** 6/10 («не критично, можно обойтись»)
- **Частотность:** последний месяц — 4 заказа; в периоды активного поиска — каждый день; в спокойные периоды — полгода может не заходить
- **Удовлетворённость:** 7/10
- **Соответствие цены и ценности (сервисный сбор):** 10/10 («199 руб. за доставку — мелочь vs. ~1000 руб. при прямом заказе из шоурума»)

**Ключевые ценности LaModa для Лены:**
1. Огромный выбор (включая любимые бренды и шоурумы)
2. Очень быстрая доставка (до 3 дней максимум)
3. Возможность примерки в комфортном пункте выдачи (просторно, чисто, много света, панорамные окна)
4. Лёгкий возврат
5. Подборки-образы для вдохновения (относительно новая для неё фича)
(источник → блок целевой работы и блок ключевой ценности)

**Негативные эмоции без решения (до LaModa / при альтернативах):**
- Торговые центры: некомфортно физически (головокружение, плохое самочувствие от закрытых пространств, высокие потолки без света), очереди в примерочные, трата времени (3–4 часа vs. 10 минут онлайн)
- Прямой заказ из шоурумов: 1–2 недели доставки, платная доставка (~1000 руб.), платный возврат, поход на Почту России с очередями
(источник → блок целевой работы, вопросы про негативные эмоции)

**Проблемы с LaModa:**
- Технический сбой: вещь отменена, но деньги уже списаны — пришлось разбираться с поддержкой
- Не все нужные шоурумы/магазины есть на платформе, коллекции не всегда обновляются вовремя
- Получили бракованную вещь (последняя на складе) — нельзя вернуть и получить замену
- При дефиците вещи (последняя позиция) невозможно добавить её к уже сформированному заказу → отдельная доставка
(источник → блок целевой работы, вопросы про проблемы)

**Работа первого использования (2020 год, Москва):**
- Контекст: ковид-карантин, напряжённый график (учёба + работа + школы программирования), появился MacBook 16" (тяжёлый, не влазит в старые сумки)

## 9. Важные цитаты

- «В B2C-интервью это особенно важно, чтобы не фреймить респондента и чтобы он не мог понять, что же мы хотим вообще от него услышать.» (источник → комментарий интервьюера после вводного блока)

- «Для каждого шага, то есть для решения, которое называла Лена, я спрашивала про результат, который она хотела получить от этого действия. Это и есть низкоуровневая работа.» (источник → комментарий после блока низкоуровневых работ)

- «Результат и проблемы — это самый минимум, минимум знания про работы.» (источник → комментарий после блока низкоуровневых работ)

- «Сердцевина работы — это когда, хочу, чтобы.» (источник → блок формулировки работ)

- «У нас работа состоит из частей. Сердцевина работы — это когда, хочу, чтобы. Соответственно, когда — это наш контекст, это триггер, это предыдущий опыт, это психологические особенности.» (источник → блок формулировки работ)

- «Важно, чтобы это было понятно, нам могли бы по заголовку понять что это за работа.» [о названии работы = сути из «хочу»] (источник → блок формулировки работ)

- «Здесь не должно быть какой-то супербольшой интерпретации. То есть по факту нужно в работу формулировать на основе того, что человек говорил.» (источник → блок формулировки работ)

- «Это нормально, если у вас вначале не получается много записывать, это приходится временем. Но вам важно, чтобы у вас был полноценный конспект.» (источник → блок работы с заметками)

- Лена о ценности LaModa: «Это огромная экономия времени — я там выставляю правильные фильтры, полистала, ну не знаю, даже 10 минут от силы... и я этим сэкономила там 3–4 часа, которые бы у меня ушли на дорогу до торгового центра, походить в торговом центре.» (источник → блок ключевой ценности)

## 10. Термины в глоссарий

- **JTBD-интервью (JobsToBeDone Interview)** — метод глубинного интервью для изучения «работ», на которые люди нанимают продукт/сервис.
- **Дерево работ** — иерархия: высокоуровневые → целевая → низкоуровневые работы.
- **Целевая работа** — работа, на которую нанимают решение в данный момент.
- **Работа первого использования** — причина, по которой человек впервые нанял данное решение (для частотных работ).
- **Предыдущие работы** — альтернативные решения, использовавшиеся до текущего.
- **Низкоуровневые работы** — желаемые результаты отдельных шагов использования решения.
- **Сердцевина работы** — формула «когда / хочу / чтобы».
- **Квалифицирующий блок** — блок вопросов о контексте и поведении респондента.
- **Фреймирование** — задание рамки восприятия (чего нужно избегать при установлении границ в B2C-интервью).
- **ABCD-сегментация** — сегментация клиентов по ценности/характеристикам на 4 группы (AB-сегмент = наиболее ценные).
- **FigJam** — онлайн-борда для визуализации и анализа данных интервью.
- **Частотная работа** — работа, которую человек решает регулярно (не разово).
- **Драйверы** — факторы, которые мотивируют использовать решение.
- **Барьеры** — факторы, которые мешают/останавливали от использования решения.

## 11. Типичные ошибки / антипаттерны

- **Называть продукт/компанию при установлении границ интервью** в B2C → фреймирует респондента, он отвечает «то, что хотят услышать». (источник → комментарий после вводного блока)
- **Не изучать предыдущие работы** → теряем понимание пути и триггеров смены решения. (источник → методологические комментарии)
- **Пытаться интерпретировать, а не цитировать** при формулировке работы → «не должно быть супербольшой интерпретации». (источник → блок формулировки работ)
- **Не делать заметки во время интервью** → без полного конспекта невозможно сформулировать работы и выгрузить на FigJam. (источник → блок работы с заметками)
- **Пропускать вопрос про эмоции** → теряем важный контекст, который обогащает формулировку работы и раскрывает настоящую важность. (источник → комментарий после блока целевой работы)
- **Изучать низкоуровневые работы без привязки к результату каждого шага** → получаем список действий, а не работ. (источник → комментарий после блока низкоуровневых работ)
- **Не спрашивать про соответствие цены и ценности отдельно** (не цену самого товара, а цену сервисного сбора) → смешиваем разные уровни цены. (источник → блок целевой работы, уточнение про 199 руб.)
