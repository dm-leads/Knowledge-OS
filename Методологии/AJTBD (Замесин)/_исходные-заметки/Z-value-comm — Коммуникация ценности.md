## 1. Концепции и идеи

- Коммуникация ценности — одна из ключевых точек роста конверсии в продажу. Задача: донести до человека ценность ДО оплаты. (источник → стр.1)
- Ценность надо коммуницировать через **более эффективное выполнение Core Jobs и Big Jobs**, а не через описание фич. (источник → стр.1)
- Человек должен **узнать себя в точке А** (текущая ситуация/боль) и **представить себя в точке Б** (результат) в первой точке контакта (лендинг / КП / DEMO). (источник → стр.1)
- Первая точка контакта должна **снижать барьеры** (страхи и тревоги) и **увольнять конкурентов** (демонстрировать превосходство над альтернативами). (источник → стр.1)
- Aha-момент желательно давать ДО оплаты — через лендинг / мобильное приложение с минимальной инвестицией времени пользователя. (источник → стр.1)
- Диагностический инструмент — скоринговая таблица по 6 критериям с оценками 0, 1, 2. Разные критерии имеют разные веса (X2, X3). (источник → стр.1)

## 2. Точные определения

- **Точка А** — текущая ситуация клиента: контекст, триггер, эмоции и боли ДО использования продукта. (источник → стр.1)
- **Точка Б** — желаемый результат: эмоции, результат Core Job (CJ) / Big Goal (BG) ПОСЛЕ использования продукта. (источник → стр.1)
- **Aha-момент** — момент, когда клиент впервые переживает/осознаёт ценность продукта. Должен быть доступен с минимальной инвестицией и до оплаты. (источник → стр.1)
- **Увольнение конкурентов** — демонстрация в первой точке контакта, почему именно ваш продукт лучше альтернатив, которые рассматривал клиент. (источник → стр.1)
- **AB-клиенты** — клиенты, прошедшие путь от точки А к точке Б (купили и получили ценность). Основной источник для AJTBD-интервью. (источник → стр.1)

## 3. Формулы

- **Формула ценностного предложения**: `CJ + ценность + фичи` (в порядке приоритета, не фичи отдельно). (источник → стр.1)
- **Весовая шкала диагностики**: отдельные критерии имеют вес X2, один критерий — вес X3. Оценка каждого критерия: 0 / 1 / 2. (источник → стр.1)

## 10. Термины в глоссарий

- **Aha-момент** — первый опыт ценности продукта, который должен быть доступен до оплаты.
- **Точка А** — текущая ситуация клиента (контекст, триггер, эмоции, боли).
- **Точка Б** — желаемый результат (эмоции + результат Core Job / Big Goal).
- **Core Job (CJ)** — основная работа, которую клиент нанимает продукт выполнять.
- **Big Job (BJ/BG)** — более крупная цель/работа клиента, в рамках которой существует Core Job.
- **AB-клиенты** — клиенты, прошедшие от точки А к точке Б; источник качественных интервью.
- **TOD (Things to Do)** — перечень действий для улучшения по конкретному критерию.
- **Увольнение конкурентов** — коммуникация, объясняющая, почему клиент должен выбрать именно ваш продукт среди рассматриваемых альтернатив.
- **CJ+ценность+фичи** — канонический формат ценностного предложения по Замесину.

## 11. Типичные ошибки / антипаттерны

- **Рассказывать только про фичи** вместо ценности через Jobs — оценка 0 или 1 по критерию №2. (источник → стр.1)
- **Отсутствие коммуникации точки А** — человек не узнаёт себя в первой точке контакта. (источник → стр.1)
- **Отсутствие коммуникации точки Б** — человек не может представить желаемый результат. (источник → стр.1)
- **Не снижать барьеры** (страхи/тревоги) в первой точке контакта. (источник → стр.1)
- **Не увольнять конкурентов** — не объяснять, почему ваш продукт лучше альтернатив. (источник → стр.1)
- **Иметь aha-момент, но не подтверждать его метриками** — состояние «есть, но не измеряем» (оценка 1, не 2). (источник → стр.1)
- **Работать над коммуникацией ценности ДО выбора фокусного сегмента** — все TOD-задачи выполняются только после сегментации. (источник → стр.1)
