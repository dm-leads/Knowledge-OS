## 1. Концепции и идеи

- Тренинг «Как делать продукт» вырос из тренинга по CustDev. Цель автора — дать фундаментальное понимание, как делать продукт, и конкретные алгоритмы для типичных продуктовых задач. (источник → весь текст, вводная часть)
- Фреймворк JTBD (Jobs To Be Done) — не искусственная конструкция, а описание реальной структуры целей, которые мозг человека автоматически формулирует для удовлетворения глубинных потребностей. (источник → раздел «Почему Jobs To Be Done не искусственная фигня»)
- Ключевое открытие автора: JTBD «женится» с психологией потребностей (9 базовых потребностей из нескольких моделей) и с базовым алгоритмом работы мозга (предсказание + дофаминовая система) — из этого соединения вытекают применимые алгоритмы. (источник → раздел об истории создания методологии)
- Единицей анализа в JTBD является переход человека из состояния «цель не выполнена» в состояние «цель выполнена» — с учётом контекста, решений-альтернатив и всех возможных исходов. (источник → «Самые-самые основы фреймворка Jobs To Be Done»)
- Первый воркшоп (обзорный) формирует единый язык и интерес; полное понимание JTBD приходит только после проведения минимум 3–4 реальных интервью — «контринтуитивная штука, требует перепрошивки мозга». (источник → раздел «О тренинге и формате»)
- Продакт-менеджеры — «агенты эволюции»: они предлагают мозгу клиента всё более эффективный способ выполнить важную для него работу за меньшие инвестиции. (источник → раздел «Ценность и оптимизационный алгоритм мозга»)
- JTBD superior относительно CJM: из CJM можно извлечь ~3 вида продуктовых решений, из графа работ — 13+ механик создания ценности и 30+ механик продуктовой стратегии. (источник → ответы на вопросы в финале)

## 2. Точные определения

- **Job (работа/цель)** — цель или задача, которую человек хочет выполнить; единица анализа JTBD. Дословный перевод: «работы, которые человек хочет, чтобы они были выполнены». (источник → «Терминология»)
- **Нанять решение на работу** — выбрать конкретное решение (продукт/действие) для выполнения работы. (источник → пример с Netflix)
- **Граф работ** — иерархическая структура (граф) целей-работ: работы выше уровня, работы ниже уровня, последовательные работы, частотные работы, налоговые работы; описывает полную структуру целей сегмента. (источник → «Граф работ»)
- **Мегаграф** — полный граф работ, включающий глубинные потребности на верхнем уровне и все конкретные подработы; на его основе, например, Сбербанк принимал решение создать Домклик. (источник → «Стратегия и мегаграф»)
- **Сегмент** — полное совпадение «когда + хочу + чтобы» (полное описание работы). (источник → «B2C и B2B работы»)
- **Налоговые работы** — работы, которых мозг клиента изначально не планировал выполнять; возникают как следствие того, что нанятое решение «облажалось». (источник → пример с заправкой и топливом)
- **Ценность** — консенсусная экономическая формула: польза (бенефиты) минус инвестиции (косты). Автор считает её неполной (скорее нелинейная функция), но лучшего пока нет. (источник → «Ценность»)
- **Косты** — все суммарные расходы человека: время, деньги, нервы, мыслительный процесс для выполнения работы. (источник → ответы на вопросы)
- **Бенефиты** — все ощущения, ресурсы, эмоциональные состояния, время, деньги, ощущения безопасности, нейромедиаторы, которые человек получает от результата выполнения работы. (источник → ответы на вопросы)
- **Удобство / «проще»** — всегда означает убийство работ (ниже уровня): тот же результат при меньшем количестве подработ. (источник → «Убийство работы»)
- **LPR (лицо, принимающее решение)** — в B2B: человек, за которым финальное слово о покупке; нанимает продукт на бизнес-работу + личную работу. (источник → «B2B специфика»)

## 3. Формулы

**Формула ценности (экономический консенсус):**
```
Ценность = Польза (бенефиты) − Инвестиции (косты)
```
Клиент покупает, пока польза > инвестиции; перестаёт, когда инвестиции > пользы.
Автор: «Я считаю, что эта формула bullshit — ценность считается по какой-то нелинейной формуле. Пока за неимением лучшего обращаюсь к мировому экономическому консенсусу.»
(источник → «Ценность»)

**Алгоритм принятия решения мозгом (fMRI-исследование 2007 года):**
1. Показывают офер → активируются зоны удовольствия/предвкушения (ожидание будущего вознаграждения).
2. Показывают цену → активируется инсула (отдел боли).
3. Принятие решения → Middle Prefrontal Area взвешивает: стоит ли будущий результат текущих страданий.
(источник → «Нейронаука принятия решений»)

**Формула «сделать значимо ценнее решение»:**
```
Ценность решения = Бенефиты − Косты
Мы предлагаем: больше бенефитов за те же косты, ИЛИ те же бенефиты за меньшие косты
```
(источник → «Ценность и граф работ»)

### Как из графа работ принимать стратегические решения (базовый алгоритм):
1. Провести JTBD-исследование → построить граф работ сегмента.
2. Найти работы ниже уровня: какие подработы возникают при текущем решении.
3. Выявить налоговые работы (лишние шаги, проблемы).
4. Найти последовательные работы (предыдущие и следующие).
5. Принять решение: устранить проблему / убить работу / объединить две работы / выйти на предыдущую работу.
(источник → «Три механики создания ценности»)

## 5. Фреймворки / модели

### Фреймворк JTBD (базовая модель):
```
[Контекст + Триггерное событие]
     ↓
[Цель не выполнена: человек представляет результат]
     ↓
[Набор альтернативных решений в голове человека]
     ↓
[Выбор решения → «наём» на работу]
     ↓
[Исходы: работа выполнена / не выполнена / частично]
```
Внутри этого перехода — вся информация для продуктовых решений.
(источник → «Основы JTBD»)

### Граф работ (иерархия):
```
Глубинные потребности (неосознаваемые, 9 штук)
     ↓
Высокоуровневые работы (цели, которые мозг формулирует для потребностей)
     ↓
Работы среднего уровня (под что нанимается продукт)
     ↓
Работы ниже уровня / подработы (возникают из-за решения, которым выполняется верхняя работа)
```
Пример: Съездить в отпуск → Добраться до места → Заехать на заправку → Найти другую заправку (налоговая).
(источник → «Граф работ»)

### 9 базовых потребностей (консенсус по моделям: Self-Determination Theory, Маслоу, Альдерфер, МакКлелланд, Скар, Дэвид Рок и др.):
1. Базовые физиологические: еда, вода, укрытие, отдых.
2. Безопасность: физическая, финансовая, защита от вреда (физического и эмоционального).
3. Социальные / принадлежность (Attachment): глубина эмоционального контакта с партнёром, друзьями, семьёй, стаей.
4. Уважение: признание, статус, уважение.
5. Самореализация и рост: автономия, компетентность, согласованность, когнитивный баланс.
(источник → «9 потребностей — консенсус моделей»)

### Модель «Мозг как инвестор» (по Лизе Фельдман Барретт, «7.5 уроков о мозге»):
- Главная задача мозга — управлять аллостазисом (баланс ресурсов: соль, жиры, глюкоза, инсулин, дофамин, серотонин и пр.).
- Мозг действует как инвестор: инвестирует ресурсы сейчас, предсказывая получение большего в будущем.
- Дофамин: если предсказание верно — небольшой подъём; если ошибка — штраф (снижение), мотивирует скорректировать модель.
- Ценность = более эффективное инвестиционное решение для оптимизационного алгоритма мозга.
(источник → «Мозг как инвестор»)

### B2B-специфика (пара работ):
```
LPR = Бизнес-работа (выполнить бизнес-цель) + Личная работа (карьера, статус, job security)
```
80% мотивации принять решение о покупке B2B — личная мотивация (по гугловскому исследованию).
Бизнес-работа описывается в терминах бизнес-целей и результата. Личная работа — как B2C.
(источник → «B2B специфика»)

## 6. Разобранные примеры / кейсы / цифры

### Кейс: маркетолог + Netflix
- Сегмент: маркетолог сети фитнес-центров, 10-часовые рабочие дни, 6-дневные недели + фриланс.
- Работа: «Когда вечером понедельника после тяжёлого дня хочу отдохнуть и расслабиться, чтобы восстановить силы для более важных задач».
- Альтернативы: прогулка, книга, TikTok, друзья, LOL.
- Решение: Netflix → смотрит серию → расслабляется → засыпает. Работа выполнена.
(источник → «Пример работы B2C»)

### Кейс: рекламное агентство (B2B)
- Бизнес-работа LPR: «Когда есть выделенный бюджет на тесты и фокус на выручке, хотим увеличить объёмы закупки рекламы, чтобы быть на острие инноваций».
- Личная работа LPR: «При высоких требованиях к качеству коммуникации хочу перевыполнить операционные цели, чтобы моя карьера была в безопасности».
(источник → «B2B работы»)

### Кейс: Заправка (проблема и налоговые работы)
- Работа: заправиться по пути Москва–Питер.
- Проблема: на заправке нет топлива.
- Три уровня «почему проблема — это проблема»:
  1. Мозг штрафует сам себя дофамином (ошибка предсказания).
  2. Негативные эмоции (злость, раздражение) — обратная связь о невыполнении важной цели.
  3. Налоговые работы: выехать, найти другую заправку, доехать, тратить нервы о запасе топлива.
(источник → «Почему проблема — это проблема»)

### Кейс: Заправки с едой и кофе (две работы одним решением)
- Механика: вместо двух отдельных заездов (заправка + фастфуд) — один заезд.
- Почему ценно: общие подработы «заехать / заказать / выехать» делятся между двумя работами → суммарные косты ниже, суммарные бенефиты выше.
(источник → «Механика: две работы в одном решении»)

### Кейс: Заправщик подходит к машине (убийство работы)
- Механика: клиенту не нужно выходить из машины.
- Почему ценно: тот же результат (заправиться + кофе) при меньшем количестве подработ → косты снижаются, бенефиты сохраняются.
(источник → «Убийство работы»)

### Кейс: MoveHub — выход на предыдущую работу
- Высокоуровневая работа: перевезти вещи из страны А в страну Б.
- Последовательность работ: понять, как можно → понять стоимость/сроки → найти перевозчика → выбрать/оплатить → передать вещи → получить вещи.
- Решение: MoveHub создал контент-продукт для работ «понять / сравнить / выбрать», конвертируя в заявку на расчёт стоимости.
- Механика: выйти на предыдущую работу.
(источник → «Механика: выход на предыдущую работу»)

### Кейс: Сбербанк Домклик — выход на предыдущие работы
- Исходная работа конкурентов: продажа ипотеки.
- Граф работ до покупки: понять, могу ли позволить → понять, где лучше купить → выбрать квартиру → выбрать банк → подать документы → получить ипотеку.
- Решение Сбербанка: Домклик закрывает все работы до ипотеки (поиск, калькулятор, заявка) → доминирует в воронке на ранних стадиях.
(источник → «Кейс Домклик»)

### Кейс: SkySmart (средний чек ×3)
- Результат: Фёдор Киреев вырастил средний чек премиум-репетиторов в 3 раза и долю премиум-продаж в 2 раза.
- Метод: узнал граф работ клиентов ПОСЛЕ покупки (как они пользуются), переупаковал продукт по джобам и переупаковал скрипты продаж под работы/ценность.
(источник → ответы на вопросы)

### Цифры:
- Тренинг прошли 8 000+ человек (приближается к 9 000) на момент воркшопа (январь 2024).
- Яндекс Картинки: рост доли с 55% до 72% (2012–2015) — кейс автора как PM.
- За 6 лет консультировал 80+ компаний, для 40+ сделал исследования или помог принять стратегические решения.
- Для максимального сертификата: 16 B2C-интервью или 10 B2B.
- Перерывы на воркшопе: каждые 50–55 минут работы + 8 минут перерыв.
(источник → вводная часть)

## 8. Схемы / диаграммы

*(В источнике упоминаются визуальные материалы, показывавшиеся на экране в ходе воркшопа; в транскрипте они описаны словесно)*

**Схема 1: Мегаграф работ (словесное описание)**
- На самом верху: глубинные потребности.
- Уровень ниже: высокоуровневые работы (то, что мозг формулирует для удовлетворения потребностей).
- Далее: работы конкретного сегмента (под которые нанимается решение).
- Работы ниже уровня: подработы, возникающие из-за выбранного решения.
- Налоговые работы: незапланированные, возникающие из-за сбоя решения.
(источник → «Мегаграф»)

**Схема 2: Граф работ «Съездить в отпуск» (пример)**
- Цель верхнего уровня: съездить в отпуск на море с женой.
- Решение: всё самостоятельно.
- Работы среднего уровня: добраться до места, жить в отеле, кататься на серфе, тусить, купить сувениры, улететь.
- Работы ниже уровня (для «добраться»): заправиться, выпить кофе, проехать расстояние.
(источник → «Граф работ — пример»)

**Схема 3: Граф работ «Купить квартиру» (упоминание большого графа)**
- Цель верхнего уровня: иметь дом (мотивировано потребностями: безопасность, принадлежность, статус, самореализация).
- Работа уровня ниже: купить квартиру.
- Подработы при решении «сам»: понять, могу ли позволить → понять, где лучше → накопить первый взнос → выбрать новостройку → купить → заехать → выплачивать взносы.
- На этой базе построен Домклик (Сбербанк).
(источник → «Кейс Домклик»)

**Схема 4: Граф работ «Забеременеть» (упомянут кейс из реального исследования)**
- Реальный граф с работами выше уровня, ниже уровня, последовательными, частотными, налоговыми.
- Девушки → попытки самостоятельно → гинеколог (не эксперт по фертильности) → много лишних анализов → гинеколог-репродуктолог (+ партнёр).
- Много налоговых работ на пути.
(источник → «Граф работ — кейс девелопера / исследование фертильности»)

## 9. Важные цитаты

- «Цели, которые человек формирует в течение своей жизни, в конечном счёте служат удовлетворению базовых потребностей.» — цитата из статьи, описывающей Self-Determination Theory (найдена автором как «недостающее звено»). (источник → «Почему JTBD не искусственная фигня»)

- «Главная задача мозга — это не думать, а управлять аллостазисом.» — Лиза Фельдман Барретт, «7.5 уроков о мозге». (источник → «Мозг как инвестор»)

- «Мы, люди, которые строим продукты, мы агенты эволюции, мы рубимся за внимание оптимизационного алгоритма мозга наших клиентов.» — Иван Замесин. (источник → «Ценность»)

## 10. Термины в глоссарий

| Термин | Краткое определение |
|---|---|
| Job / Работа | Цель/задача человека, которую он хочет выполнить; единица анализа JTBD |
| Нанять решение | Выбрать продукт/действие для выполнения работы |
| Граф работ | Иерархическая структура всех работ сегмента (выше/ниже уровня, последовательные) |
| Мегаграф | Полный граф от глубинных потребностей до мельчайших подработ |
| Налоговые работы | Незапланированные подработы, возникающие из-за сбоя решения |
| Убийство работы | Механика ценности: тот же результат при меньшем количестве подработ |
| Аллостазис | Баланс всех ресурсов организма (мозг управляет им как инвестор) |
| Сегмент | Полное совпадение «когда + хочу + чтобы» (полное описание работы) |
| LPR | Лицо, принимающее решение (в B2B) |
| Пара работ B2B | Бизнес-работа + Личная работа LPR |
| Self-Determination Theory | Психологическая модель базовых потребностей (одна из 9 рассматриваемых) |
| Middle Prefrontal Area | Отдел мозга, взвешивающий будущий результат vs текущие усилия (решение о покупке) |
| Инсула | Отдел мозга, активирующийся при боли (в т.ч. при виде цены продукта) |

## 11. Типичные ошибки / антипаттерны

- **«Ценность — это то, что люди покупают»** — бессмысленный цикл, не даёт алгоритма создания ценности. (источник → «Ценность»)
- **Использовать CJM вместо графа работ** — CJM даёт только 3 вида решений (устранить проблему, убить шаг, скопировать конкурента) против 13+ из графа работ. (источник → финал)
- **Изучать только продукт, а не граф работ** — без знания предыдущих и последующих работ невозможно принять стратегическое решение о позиционировании (кейс Домклик vs просто «делаем ипотеку дешевле»). (источник → «Стратегия»)
- **Спрашивать людей о потребностях напрямую** — люди не осознают глубинных потребностей, левое полушарие придумывает «убедительную ложь». До эмоций — можно, до потребностей — нет. (источник → «Потребности и цели»)
- **Пытаться применить JTBD без проведения интервью** — без хотя бы 3 интервью перепрошивки мозга не происходит; в записи это не усваивается так же. (источник → «Формат и рекомендации»)
- **JTBD не работает для неосознаваемых решений** — жениться, стать врачом, родить ребёнка, алкоголь/наркотики: процесс настолько неосознан, что интервью даст только рационализацию. (источник → ответы на вопросы в финале)
- **Пихать слишком много работ в один продукт** — суперапп начинает вредить, когда объём работ превышает то, что клиент может переварить (ограничение экранного пространства и внимания). (источник → ответы на вопросы)
- **Линейное применение формулы ценности «польза − инвестиции»** — автор считает, что функция нелинейная; формула используется как приближение, но не как точная модель. (источник → «Ценность»)
