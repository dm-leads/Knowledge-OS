## 1. Концепции и идеи

- **Два разрыва шаблона про ценность:** большинство команд думают о ценности неправильно по двум причинам. (источник → стр. 3–6)
  1. Конкурируют только ценой, хотя существуют десятки способов конкурировать эффективнее. (стр. 4–5)
  2. Думают, что ценность = «починить боли клиентов», тогда как механик создания ценности десятки, и починить боли — лишь одна из них. (стр. 6)

- **Думать фичами — вредно:** фича субъективна («фича в глазах смотрящего»), а попытка придумывать фичи и защищать их у стейкхолдеров ведёт к «проклятому циклу пиления фич». (стр. 7–11)

- **Фича — это то, что клиент считает ценным** (не то, что придумала команда). (стр. 10)

- **Ценность для клиентов → Бизнес-ценность**, но не всегда: ценность для клиентов не автоматически конвертируется в бизнес-ценность. (стр. 14)

- **Работы есть не только у клиентов** — тезис, раскрывающий, что у бизнеса тоже есть свои «работы» (JTBD-логика применима к обеим сторонам). (стр. 16)

- **Агенда декка (6 тем):** (стр. 2)
  1. Два разрыва шаблона про ценность
  2. Почему вредно думать фичами
  3. Бизнес-ценность: ето что, зачем и как
  4. Что такое ценность для клиентов
  5. Активация в ценность
  6. Механики создания ценности для клиентов

## 2. Точные определения

- **Фича** — то, что клиент считает ценным. «Фича в глазах смотрящего» (т.е. определяется восприятием клиента, а не решением команды). (источник → стр. 9–10)

- **Бизнес-ценность** — производная от ценности для клиентов, но «не всегда» напрямую из неё вытекает. (источник → стр. 14)

## 4. Пошаговые процедуры / алгоритмы

**«Проклятый цикл пиления фич»** — 7 шагов антипаттерна (источник → стр. 11):
1. Озариться фичёй
2. «Защитить её у стейкхолдеров»
3. Придумать метрики, по которым её можно будет принять
4. С упоением полгода пилить
5. Выкатить и принять по крооохотному изменению одной из метрик
6. Пару лет чинить в ней баги и сливать на это деньги
7. Тихо выпилить и с облегчением вздохнуть

## 6. Разобранные примеры / кейсы / цифры

**Пример с рынком яблок — два разрыва шаблона** (источник → стр. 4–6):
- Разрыв 1: Три торговца яблоками на рынке — двое по 200 р., один демпингует до 150 р. Ошибочная стратегия = конкурировать только ценой. Правильно: существует десятки способов конкурировать эффективнее (на картинке торговец окружён пузырями с формулами/графиками — символ разных стратегий).
- Разрыв 2: Те же три торговца, но их таблички меняются с «200 р.» / «150 р.» на «СЛАДКИЕ» / «БЕЗ ГМО» / «ОРГАНИК» — т.е. конкуренция переходит в ценностное измерение. Тезис: «Механик создания ценности десятки, починить боли — одна из них».

**Пример с флаконом** (источник → стр. 17):
- Фото: белый флакон (баночка с добавками) с защитной бумажной пломбой «Sealed for your protection» (Запечатано для вашей защиты)

**Пример со Сбером и Лавкой** (источник → стр. 18):

## 8. Схемы / диаграммы

**Схема 1: «Два разрыва шаблона про ценность»** (стр. 4–6)
- Иллюстративная серия: три торговца яблоками с ценниками (200р / 200р / 150р) → добавляется четвёртый, думающий в пузырях формул и графиков.
- Нижняя подпись: «1. Конкурируем только ценой» → раскрытие «Существует десятки способов эффективнее конкурировать»
- На следующем слайде ценники меняются на «СЛАДКИЕ / БЕЗ ГМО / ОРГАНИК»: «2. Ценность — починить боли клиентов» → «Механик создания ценности десятки, починить боли — одна из них»

**Схема 2: «Проклятый цикл пиления фич»** (стр. 11)
- Круговая схема из 7 блоков с иконками и стрелками:
  - 1 (старт) → 2 → 3 → 4 → 5 → 6 → 7 → (конец/смерть фичи)
  - 1. Озариться фичёй (человек с пузырём «ФИЧА»)
  - 2. «Защитить её у стейкхолдеров» (три человека в костюмах)
  - 3. Придумать метрики, по которым её можно будет принять (график)
  - 4. С упоением полгода пилить (человек с пилой пилит табличку «ФИЧА»)
  - 5. Выкатить и принять по крооохотному изменению одной из метрик (человек с лупой смотрит на мизерный рост)
  - 6. Пару лет чинить в ней баги и сливать на это деньги (гаечный ключ + отвёртка)
  - 7. Тихо выпилить и с облегчением вздохнуть (надгробие «ЗДЕСЬ ПОКОИТСЯ ФИЧА»)
- Внизу слева: «логика скрыта» (кнопка, намекающая на дополнительный контент/логику)

**Схема 3: «Где обычно тусим»** (стр. 12)
- Три вертикально расположенных блока:
  - «Работа» (верхний, голубой/бледный) — недостижимый уровень
  - «Решение» (зелёный) — здесь обычно работают
  - «Проблемы» (красный/розовый) — здесь обычно работают
- Справа от нижних двух блоков: «потому что мы обычно тусим здесь»
- Слева: иллюстрация — один человек наблюдает за другим

**Схема 4: «Ценность для клиентов → Бизнес-ценность»** (стр. 14–15)
- Два текстовых блока, соединённых стрелкой вниз (↓):
  - «Ценность для клиентов» (верхний)
  - «Бизнес-ценность» (нижний)
- Оговорка «не всегда» слева внизу слайда (мелким шрифтом)

## 10. Термины в глоссарий

- **Фича** — то, что клиент считает ценным (субъективно)
- **Бизнес-ценность** — ценность, которую продукт создаёт для бизнеса (не тождественна ценности для клиентов)
- **Проклятый цикл пиления фич** — антипаттерн: 7-шаговый цикл от «озарения фичёй» до «тихого выпиливания»
- **Уровни работы** — три уровня: Работа / Решение / Проблемы (команды обычно застревают на нижних двух)

---

## 11. Типичные ошибки / антипаттерны

1. **Конкурировать только ценой** — вместо поиска десятков других способов создания ценности. (стр. 4–5)
2. **Думать, что ценность = починить боли** — слишком узкое понимание. (стр. 6)
3. **Думать фичами** — фича субъективна, «в глазах смотрящего». (стр. 9–10)
4. **Проклятый цикл пиления фич** — озариться → защитить → придумать метрики → пилить → выкатить по мизерному росту → чинить баги годами → тихо выпилить. (стр. 11)
5. **Тусить только на уровне Решений и Проблем**, не поднимаясь до уровня Работы (JTBD). (стр. 12)
