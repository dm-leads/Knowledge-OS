## 1. Ключевые утверждения / тезисы

- Выбор сегмента — самое рискованное предположение в создании продукта: 90%+ стартапов проваливаются именно из-за неправильного сегмента. [src2]
- PMF — это когда продукт выполняет работу выбранного сегмента лучше всех конкурирующих решений, и это масштабируемо и предсказуемо монетизируется. [src2]
- Знание создаётся только через проверку гипотез (ссылка на Дэвида Дойча): без фальсификации нет знания — есть только вера. [src2]
- Конверсия = КПД продукта: люди_выполнившие_работу / люди_поданные_на_входе_воронки. [src3]
- Привычка — это физическое изменение структуры мозга. Мозг сопротивляется изменениям и сильно недооценивается нами при оценке барьеров клиента. [src3]
- Спящая работа — это новая версия работы ниже уровня, которую человек ещё не выполняет, но при определённых условиях может начать. [src3]
- Пробуждение спящей работы (тип 1 — уже известное человечеству) достигается через загрузку тройки активирующего знания в голову нужного сегмента. [src3]

## 2. Определения / понятия

| Термин | Определение | Источник |
|---|---|---|
| **Сегмент** | Группа людей с одинаковыми работами (JTBD), одинаковыми квалифицирующими факторами и одинаковым текущим решением | [src1] |
| **Job / Работа** | То, что человек хочет достигнуть или избежать в определённом контексте | [src1] |
| **PMF (Product-Market Fit)** | Продукт выполняет работу сегмента лучше всех конкурентов; это масштабируемо монетизируется | [src2] |
| **RAT (Riskiest Assumption Test)** | Метод приоритизации гипотез для проверки: сначала — самое рискованное, что может убить продукт | [src2] |
| **Пивот** | Кардинальная смена сегмента, работы или ценностного предложения на основании данных исследований | [src2] |
| **Super Discovery** | Экспертные интервью (15–20 шт.) с людьми, уже работавшими в изучаемой отрасли — для быстрого изучения неизвестного рынка | [src1] |
| **Широкая гипотеза** | Первоначальное «размытое» описание сегмента, который можно было бы обслуживать | [src1] |
| **Switch-интервью** | Интервью с людьми, сменившими решение: изучаем 3 зоны — начало поиска, активный поиск, момент покупки | [src3] |
| **4 силы** | Фреймворк: 2 силы вперёд (ценность + проблемы со старым решением) и 2 назад (барьеры + привычка) — действуют в момент выбора нового решения | [src3] |
| **Спящая работа** | Работа, которую человек ещё не выполняет, но способен начать при достижении определённых условий (новых знаний, нового решения) | [src3] |
| **Активирующее знание** | Информация, загрузка которой в голову человека пробуждает новую работу или меняет текущую | [src3] |
| **Aha-moment** | Момент, когда клиент впервые понимает и ощущает ценность продукта | [src3] |
| **Барьеры** | Страхи, тревоги, сомнения клиента в том, что новое решение оптимально выполнит его работу; «пожиратели ценности» | [src3] |

## 3. Фреймворки / модели

### 3.1 Алгоритм поиска и выбора сегмента (5 этапов) [src1]

**Этап 1. Super Discovery (если рынок незнаком)**
- 15–20 экспертных интервью с людьми, работавшими в отрасли
- Цель: понять, кто игроки, какие сегменты существуют, какие работы выполняются
- Применяется только при работе с незнакомым рынком

**Этап 2. Формулировка широкой гипотезы**
- Описание сегмента: кто это, какая у них работа, какое сейчас решение
- Пример: «предприниматели малого бизнеса, которым нужно вести бухгалтерию, сейчас делают это вручную»

**Этап 3. Оценка размера рынка**
- TAM / SAM / SOM под широкую гипотезу
- Отсев сегментов с рынком ниже порогового значения

**Этап 4. Job-driven исследование (итерационное)**
- 6–8 качественных интервью за итерацию (для B2C — 30+, для B2B — 20+ суммарно до навигации)
- Цель: найти настоящую работу, граф работ, квалифицирующие факторы
- Каждые 6–8 интервью — стоп, анализ, корректировка гипотезы, следующая итерация

**Этап 5. Ранжирование и выбор сегмента**

Формула приоритизации сегментов:
```
Приоритет = Размер × Частота × Важность работы × Неудовлетворённость текущим решением
```

Дополнительные критерии выбора сегмента:
- Стартап: нужен сегмент с наибольшей неудовлетворённостью (сначала достигаем PMF в нише)
- Корпорация: нужен сегмент с наибольшим размером × частотой

---

### 3.2 Алгоритм поиска PMF (от нуля) [src2, pdf6]

1. Сформулировать широкую гипотезу сегмента
2. Провести quality-исследование: 30+ интервью (B2C) / 20+ (B2B) для навигации по сегментам
3. Выбрать сегмент (приоритизация по формуле выше)
4. Изучить граф работ: 8+ JTBD-интервью по выбранному сегменту
5. Сформулировать гипотезы ценности
6. Провести Decision-интервью (решенческие): батчи по 10 штук, цель — 2–4 покупки на батч
7. Если <2 покупок — анализ причин, пивот или смена гипотезы ценности
8. Если 2–4 покупки — масштабировать, проверить повторяемость

### 3.3 RAT — Riskiest Assumption Test [src2, pdf6]

**Формула:**
```
Risk Score = Вероятность провала × Последствия для бизнеса / Стоимость проверки
```

**5 категорий рискованных предположений (по убыванию приоритета проверки):**
1. Рынок, тренды, регуляция (существует ли рынок?)
2. Сегмент (правильно ли выбраны люди?)
3. Продукт (выполняет ли работу лучше конкурентов?)
4. Бизнес-модель (можно ли монетизировать?)
5. Каналы масштабирования (можно ли масштабировать привлечение?)

**Принцип:** проверяй самое рискованное, что может убить проект, за минимальные деньги и время. Не строй MVP, если можно проверить гипотезу звонком или лендингом.

---

### 3.4 Top-down vs Bottom-up подходы [src2]

| Подход | Суть | Когда применять |
|---|---|---|
| **Top-down** | Начинаем с видения рынка → выбираем сегмент → строим продукт | Опытный основатель с глубоким знанием отрасли |
| **Bottom-up** | Начинаем с конкретного пользователя и его боли → расширяем | Стартап без отраслевой экспертизы |

### 3.5 Фреймворк 4 сил (4 Forces) [src3]

Действуют в уникальный момент, когда человек с работой смотрит на новое решение при наличии текущего:

**Силы ВПЕРЁД (к новому решению):**
- Воспринимаемая ценность нового решения (субъективно выше текущего)
- Проблемы с текущим решением (выталкивают)

**Силы НАЗАД (к старому решению):**
- Барьеры к новому решению (страхи, тревоги, сомнения)
- Привычка к текущему решению (мощнейшая сила)

**Ограничения модели:**
- На привычку крайне сложно влиять (особенно в mass B2C)
- На проблемы с текущим решением в B2C почти нет рычагов
- Эффективные стратегии: снижение барьеров + лучшая коммуникация ценности + поиск сегментов с наименьшей удовлетворённостью

### 3.6 Switch-интервью (3 зоны) [src3]

Цель: понять, как реально происходит смена решения.

**Зона 1 — Начало поиска:**
- Что произошло, что человек начал искать альтернативу?
- Какое было первое событие, которое запустило поиск?

**Зона 2 — Активный поиск:**
- Какие решения рассматривались?
- Что нравилось/не нравилось в каждом?
- Что останавливало?

**Зона 3 — Момент покупки:**
- Что стало последней каплей для выбора?
- Что могло остановить?
- Была ли цена барьером?

---

### 3.7 Конверсия и 7 условий [src3]

**Формула конверсии:**
```
Конверсия = люди, выполнившие работу с нашим решением / люди, поданные на вход воронки
```

**7 условий, при которых человек конвертируется:**
1. У человека есть работа (JTBD)
2. Работа важна и частотна
3. Человек знает, что может выполнить эту работу по-новому (активирующее знание)
4. Человек воспринимает ценность нашего решения выше текущего
5. Барьеры к нашему решению достаточно низки
6. Человек активировал ценность (aha-moment случился)
7. Не сломалось ничего технически на пути

## 4. Алгоритмы / последовательности действий

### 4.1 Полный алгоритм создания продукта с нуля [src2, pdf6]

```
ШАГ 0. Есть ли у основателя экспертиза в отрасли?
  → Нет: проводим Super Discovery (15-20 экспертных интервью)
  → Да: переходим к шагу 1

ШАГ 1. Формулируем широкую гипотезу сегмента

ШАГ 2. Оцениваем размер рынка (TAM/SAM/SOM)
  → Рынок слишком мал: ищем другую гипотезу
  → Рынок достаточен: продолжаем

ШАГ 3. Quality-исследование (навигация по сегментам)
  - B2C: 30+ интервью; B2B: 20+ интервью
  - Итерации по 6-8 интервью, корректируем гипотезу после каждой

ШАГ 4. Выбор сегмента
  - Ранжируем по: размер × частота × важность × неудовлетворённость
  - Выбираем наиболее перспективный

ШАГ 5. Изучение графа работ сегмента
  - 8+ JTBD-интервью
  - Строим граф работ (верхний уровень → нижний уровень)

ШАГ 6. Генерируем гипотезы ценности

ШАГ 7. Decision-интервью (решенческие интервью)
  - Батчи по 10 интервью
  - Цель: 2-4 покупки на батч
  - Если 0 покупок: ошибка в сегменте, работе или ценности → пивот
  - Если 2-4: масштабируем, проверяем повторяемость

ШАГ 8. Масштабирование и проверка каналов
```

---

### 4.2 Алгоритм пробуждения спящей работы [src3]

```
ШАГ 1. Находим людей, у которых эта работа уже проснулась
  → Изучаем их джобы, особенности сегмента, квалифицирующие факторы

ШАГ 2. Узнаём тройку активирующего знания у этих людей:
  → Знание 1: что эту работу можно выполнять (само существование альтернативы)
  → Знание 2: что наше решение ценнее и удобнее прежнего
  → Знание 3: что с нашим решением это сделать просто прямо сейчас

ШАГ 3. Находим похожих людей на более ранних этапах
  → Среди тех, у кого есть проблемы с текущим решением
  → Среди тех, кто «почти» пытался выполнить эту работу, но не начал

ШАГ 4. Загружаем тройку активирующего знания в голову нужного сегмента
  → Каналы: контент-маркетинг, видео, вебинары, продавцы, партнёры

ШАГ 5. Усиливаем мотивацию
  → Показываем, какие работы выше уровнем клиент сможет выполнять лучше
  → Работаем с барьерами к выполнению работы и к нашему решению
```

**Кейс Янго/Денис Кучин (облигации):** [src3]
- Продукт: мобильное приложение для инвестиций в облигации
- Проблема: при маркетинговом привлечении конверсия в пополнение = 10%, средний чек упал с 1,4 млн до 400 тыс. руб.
- Решение: партнёрство с Home Credit Bank и Совкомбанком → продавцы в отделениях лично загружали тройку активирующего знания
- Результат: конверсия выросла с 10% до ~65%, средний чек остался ~400 тыс. руб., активы под управлением выросли многократно
- Вывод: живая коммуникация с персональной загрузкой активирующего знания в нужном контексте (человек уже в банке, депозит заканчивается) в разы эффективнее digital-воронки

### 5.3 Кейсы из лекции по спящим работам [src3]

**PitchMe (HR-tech, UK/US):**
- Проблема: продавали инструмент сорсинга кандидатов как «лучший», но не покупали
- Причина: HR-ы привыкли к старой CRM (стандарт на рынке, статусный, «как за SAP не увольняют»)
- Решение: встроились в интерфейс старой CRM как источник данных + удавняшки поверх
- Урок: не ломай привычку — оседлай её, встройся в существующий паттерн

**Яндекс.Браузер:**
- Задача: масштабируемо перетаскивать пользователей Chrome в России
- Главный барьер (найден исследованием): «потеряю пароли, вкладки, закладки»
- Решение: фичи переноса в 1 клик + коммуникация об этом во всех каналах
- Урок: барьеры можно узнавать через интервью и количественные исследования, потом системно снижать

**Motion (SaaS-тудушка + календарь):**
- Пример коммуникации ценности на каждом шаге воронки (от креатива до онбординга)
- На каждом экране одновременно: загрузка ценности («сэкономишь 30 дней в году») + снижение барьеров (7-day free trial, отмена в клик) + напоминание о цели
- Урок: не просто «дай деньги», а постоянно напоминай, к какой ценности ты ведёшь клиента

**Яндекс.Острова (редизайн 2013–2014):**
- Выкатили большой редизайн разом → клики и выручка -8–10%
- Несколько месяцев откатывали элемент за элементом
- Урок: редизайн — только поэкранно, атомарно, иначе не поймёшь, что сломалось

**CityMobile (такси, Москва, 2019–2020):**
- Качество продукта сравнимо с Яндекс.Такси, но большинство попробовавших не остались
- Причина: сила привычки к Яндекс.Такси (привычный маятник — открывают привычное приложение)
- Урок: даже при сравнимом качестве привычка побеждает

**Янго (Yango) / облигации — Денис Кучин:** (подробнее в разделе 4.2)

**Refill (напитки, мача):** [src3]
- Задача: найти гипотезу роста возвращаемости клиентов
- Сегмент AB: девушки, у которых кофе «перестал работать» (тревожность/сон/ЖКТ), но ритуал и привычка есть
- Работа при первой покупке: найти замену кофе с сохранением ритуала
- Мотиваторы к первой покупке: коммуникация здоровья + эстетика бренда + рекомендации (снимают тревогу) + идентичность
- Барьеры: высокая цена, нет пробников, доставка через DЭК
- Мотиваторы к повторной покупке: вижу влияние на здоровье (aha-moment), нравится вкус, идентичность с брендом, встраивается в ритуал

## 6. Формулы / числа / пороги

| Формула / число | Источник |
|---|---|
| `Risk Score = Вероятность провала × Последствия / Стоимость проверки` | [src2, pdf6] |

## 7. Противоречия / предостережения

- **Опасность «выживших»:** нельзя изучать только тех, кто уже выполняет работу — можно упустить барьеры. Но изучение «отвалившихся» тоже рискованно: среди них много людей без настоящей работы. [src3]
- **Привычка недооценивается:** основатели и PM-ы систематически недооценивают силу привычки клиента к текущему решению. [src3]
- **Теория спящих работ — сырая:** Замесин прямо предупреждает, что алгоритм пробуждения работ типа 2 (новые категории, которые человечество ещё не умеет пробуждать) у него пока отсутствует. [src3]
- **Большой редизайн = всегда риск:** нельзя выкатывать большой редизайн разом — нет возможности атомарно откатить. [src3]
- **RAT не означает «делай дёшево»:** смысл в том, чтобы проверить именно рискованное, а не вообще всё делать дёшево. [src2]

## 8. Связи с другими концепциями

- **JTBD / AJTBD (Замесин):** весь алгоритм строится на JTBD-методологии; граф работ — центральный инструмент. [src1, src2, src3]
- **Crossing the Chasm (Джеффри Мур):** пропихивание спящей работы по популяции — инноваторы → ранние последователи → раннее большинство → позднее большинство — это и есть Crossing the Chasm. [src3]
- **Innovator's Solution (Клейтон Кристенсен):** теория подрывных инноваций описывает явление спящих работ типа 2, но не даёт алгоритма. [src3]
- **Thinking Fast and Slow (Канеман):** мозг недооценивает потенциальные потери vs будущие выгоды — объясняет силу привычки. [src3]
- **David Deutsch (The Beginning of Infinity):** знание создаётся только через фальсифицируемые гипотезы. [src2]
- **Доп. лекция «Как развивать существующий продукт»:** алгоритм исследования ценности и aha-moment для существующих клиентов — не в данном модуле. [src3]

## 9. Практические инструменты / шаблоны

### Decision-интервью (решенческое интервью) — структура вопросов [src3]

1. Дать человеку коммуникацию/интерфейс/лендинг/скрипт продажи
2. Решает ли это твою потребность / выполняет ли твою работу?
3. Какие сильные стороны? Какие слабые?
4. Сравни с конкурентами: в чём выигрываем, в чём проигрываем?
5. Соответствует ли ценообразование ценности?
6. Готов ли ты купить прямо сейчас? (B2C) / Готов ли назначить созвон с командой? (B2B)
7. Если нет — что останавливало?

**Ключевой принцип:** цель не «продать», а смоделировать, готов ли человек заплатить хоть чем-то (деньги, время, репутация, следующий шаг).

---

### Скрипт поиска барьеров [src3]

- В ходе исследования сегмента: «Было ли что-то, что заставляло остановить использование решения или перейти на новое?»
- В decision-интервью: «Было ли что-то, что вас останавливало от использования нашего решения?»
- После отказа купить: «В любом случае, что вас остановило?»

---

### Тройка активирующего знания для спящих работ [src3]

При коммуникации с целевым сегментом загружать 3 блока:
1. **Знание о возможности:** «Это можно делать по-другому / такая работа существует»
2. **Знание о ценности решения:** «Наше решение лучше/удобнее/ценнее прежнего, потому что...»
3. **Знание о доступности:** «Ты можешь это сделать прямо сейчас, вот так просто»
