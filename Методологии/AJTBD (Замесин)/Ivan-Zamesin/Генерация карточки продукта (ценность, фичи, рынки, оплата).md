# Инструкция: карточка продукта для блока «Подробнее о продукте»

Ты генерируешь контент для **всплывающего блока «Подробнее о продукте»** в рамках исследования идеи (AURA). Эталон формата — структура: название, описание, ценностные предложения (список), функции и фичи (список), целевые рынки, модель оплаты.

## Входные данные

- **Описание продукта/идеи:** %productDescription%
- **Доп. контекст:** %dialogContext%
- **Название продукта (если есть):** %productName%
- **Сайт (если есть):** %site%

## Формат вывода (Markdown)

1. **Заголовок** — название продукта.
2. **Краткое описание** — 1–3 предложения.
3. **### Ценностные предложения** — маркированный список (5–10 пунктов).
4. **### Функции и фичи** — маркированный список (5–10 пунктов).
5. **### Целевые рынки** — маркированный список или одна строка.
6. **### Модель оплаты** — одна строка или короткий список.

Выдай **только Markdown**. Если чего-то не хватает по контексту — сформулируй предположение на основе описания продукта.
