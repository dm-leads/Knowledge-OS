# AI Photo Studio

Приложение для создания профессиональных фотосессий с помощью AI. Пользователи загружают свои фотографии, выбирают стили и получают готовые изображения высокого качества для социальных сетей и других платформ.

### Ценностные предложения

- Получить запас качественных фотографий для постов и историй без фотографа, студии или организации съемок.
- Создавать профессиональные бизнес-портреты для LinkedIn.
- Получать контент для образа жизни (кофейня, дом, город).
- Создавать фотографии для путешествий (Париж, Нью-Йорк, пляжный закат).
- Экспериментировать со стилями без риска и затрат на полноценную фотосессию.
- Быстро получать контент для социальных сетей (недельный запас контента за 2 минуты).
- Получать профессиональное качество фотографий, обученных на стандартах Vogue.
- Сохранять свое реальное лицо на фотографиях, а не 'кого-то похожего'.

### Функции и фичи

- Генерация фотосессии за 2 минуты
- 20 стилей фотосессии
- 4 вариации на каждый стиль
- Разрешение фотографий 2048px
- Загрузка 3 фотографий для обучения AI
- Выбор стилей (Fashion, Lifestyle, Travel, Creative)
- Скачивание готовых фотографий
- Использование AI, обученного на стандартах Vogue
- Натуральная текстура кожи на фотографиях
