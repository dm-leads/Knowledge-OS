# CHANGELOG — Ядро данных

## 2026-09-28 — Уроки этапов 2–6 и сервера первого инстанса
- Стандарт: `raw` — минимизированная копия (белый список до записи); платёж без обязательной сделки, возврат
  отрицательной суммой, себестоимость на отгрузке (`shipment_cogs`); раздел «3а. Деньги» (связь через
  документы-посредники, двойной счёт по основанию, возвраты, падение доли связанных оплат — стоп); статус и
  пояснение числа; раздел «4а. Покрытие» (журнал окон, объединение окон, окно на вид данных); ПДн — белый
  список ключей, К6 в двух режимах, технические адреса частью; история — дата съёма по отстающей системе,
  производные даты с запуска писателя, снимки своих чисел; раздел «7а. Отбор и модели метрик» (любой отбор —
  параметр, Я12); известные ответы — точно для своих, допуск для чужих; К11.
- Гайд: ворота этапов 2–6 по опыту; этап 8 зависит от 5, этап 7 — от 5, 6, 8; разделы «Загрузчик —
  обязательные свойства», «Сервер и ночное обновление», «Резервные копии и защита истории»; переносимый код —
  пакетом канона с выпуском (ADR-0003 движка), загрузчики — в инстансе.
- Приняты [ADR-0002](<ADR-log/0002-numbers-as-of-date-own-snapshots-and-published-file.md>) (числа на дату и
  публикация файлом), [ADR-0003](<ADR-log/0003-operations-before-gate.md>) (эксплуатация раньше гейта,
  исключение для чисел наружу до этапа 7) и
  [ADR-0004](<ADR-log/0004-company-total-over-all-facts-any-selection-is-a-parameter.md>) (изменение Я4 и Я12).
- Источник: планы этапов 2–5 и 8, спецификация сборки v1, справочник правила контура, коммиты инстанса
  15–27.09.2026; сбор — агентом с чистым контекстом, выборочная сверка с кодом инстанса.
- Независимое ревью агентом с чистым контекстом: 12 находок, все приняты. В канон: снимок хранит статус и дату
  съёма самого числа, снимки — отдельным шагом прогона, «намеренно красный» эталон только объявленно, защита
  денег — по неполученным документам связи, гайд не выдаёт пакет в работе за готовый, `serve` — переносимые
  команды отдельно от прикладных расчётов. Шесть мест, где инстанс отстаёт от канона, переданы в стартер
  переноса кода.

## 2026-09-14 — Стандарт и гайд активированы после ворот этапа 1 первого инстанса
- Ворота этапа 1 инстанса Бризекс пройдены: схема фактов создаётся на файловой и серверной СУБД
  одним кодом, тест границы зелёный, красные случаи К1–К7 и К9 отвергнуты кодом с номером
  правила; 75 контрактных тестов на двух СУБД.
- Уточнения стандарта по итогам исполнения: имена таблиц `phone_call` и `load_log` (ключевые
  слова движков); связь строки с журналом загрузок проверяет писатель, не внешний ключ базы
  (файловые СУБД не поддерживают ключи между схемами); К6 дополнен пределом длины свободного
  текста и белым списком номеров линий компании для `callee_line`.
- Урок в гайд: локальная серверная СУБД для тестов — в пути только из ASCII-символов, вне репозитория.

## 2026-09-14 — Контур создан; принят ADR-0001
- Создан канон отдельной системы «Ядро данных»: манифест, черновик стандарта (тринадцать
  требований Я1–Я13, схема фактов, контракт происхождения, политика ПДн, пять уровней
  самопроверки, красные случаи К1–К10, интерфейс потребителей), черновик гайда установки.

  хранилище фактов, независимое от поставщика, как система-источник (подтверждён Дмитрием
  14.09.2026 в чате сквозной аналитики; текст — из спецификации сборки v1 первого инстанса).
- Место среди систем зафиксировано: речевая аналитика — «почему», Движок роста — «что делать»,

  содержит.
- Первый инстанс — Бризекс, контур «Сквозная аналитика» в `Breezeks-Git`; стартер нового чата —
  в `hub/Промпты-стартеры чатов/`.
