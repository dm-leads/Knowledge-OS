# ADR-0004 — Итог компании по всем фактам; любой отбор — параметр модели

- **Статус:** Accepted (решение владельца Р7 от 17.09.2026 в первом инстансе — «управляем весь отбор, не только
  фильтры маркетинга»; правило Я4 — по данным этапов 4–5; перенесено в канон 28.09.2026)
- **Дата:** 2026-09-28

## Контекст

**Я4.** Стандарт от 14.09 проверял дедуп так: «сумма зачётной метрики по брендам равна счёту по контактам».
Практика показала, что у части фактов бренда нет (оплата заказа без поля бренда, сделка без него). Итог
компании, собранный суммой брендов, терял их дважды: деньги на этапе 4, сделки на этапе 5.

**Я12.** Стандарт говорил: «фильтры контура — параметры модели». Зачётная метрика первого инстанса имела ещё и
зашитые базовые условия («только первые квалифицированные», удалённые, технические) — они отсекали сущности
молча, и одна модель не давала числа всех нужных наборов: у зачётной метрики оказалось пять правдоподобных
значений в зависимости от отбора.

## Решение

1. **Я4:** итог компании считается по всем фактам; проверка — «бренды + „без бренда“ = компания».
2. **Я12:** любой отбор — параметр модели (набор отбора из конфигурации: база + исключения), включая базовые
   условия. Отбор, который остался зашитым, назван в пояснении числа с числом отсечённого.

## Рассмотренные альтернативы

- **Требовать бренд у каждого факта.** Отклонено: источник его не всегда знает; «без бренда» — честный разрез.
- **Оставить базовые условия зашитыми.** Отклонено: одна метрика с пятью значениями без объявленного отбора —
  класс K «своя метрика вместо принятой».

## Последствия

- Пояснение числа перечисляет зашитые отборы и сколько каждый отсёк; команда разбора печатает лестницу отбора.
- Поле отбора — только из белого списка ядра: конфигурация не становится способом писать SQL.
