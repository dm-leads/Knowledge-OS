# Справочник — Карта маркетинга (что чем закрыто)

## Краткая суть

- В каноне маркетинг собран из нескольких методологий разных авторов. Они не конфликтуют, пока у каждого
  вопроса один хозяин. Этот справочник назначает хозяина каждому вопросу.
- Порядок работы один: **кому и что → сколько можно платить → где и когда → настроить → продать →
  посчитать факт → улучшить**. Каждый шаг отдаёт следующему конкретный результат.
- У части поля есть хозяин, часть закрыта наполовину, у части хозяина нет. Пробел называется вслух и не
  заполняется сочинением: либо берём из первоисточника по стандарту извлечения, либо говорим «в базе нет».

Навыки `nmt-*` и `impeccable` — не из исходников канона: первые ставятся в проект, второй сторонний. На них
нельзя опираться как на хозяина; хозяин — документ.

**Правила стыковки.**

1. Сегмент и сообщение задаёт Замесин. Навык площадки не придумывает, кому и что говорить, — он берёт это.
2. Деньги считает Красинский. Медиаплан не заводит своих формул прибыли — он продолжает его строку влево.
3. Пороги вывода — из справочника порогов. Навык площадки может знать механику кабинета, но не меняет порог.
4. Закон — фильтр до всего остального. Запрещённая площадка не оценивается.
5. Цифра из курса или чужого кейса — бенчмарк, а не факт и не цель.
6. Два источника расходятся — расхождение называется владельцу; молча не выбираем.

## Порядок работы — один для любого проекта

```
1. Цель и экономика      цель в деньгах → строка Красинского → допустимая цена
2. Рынок и сегмент       спрос, конкуренты → сегмент, работа, триггер, ценность → сообщение
3. Медиаплан             обратный счёт → выбор площадок → аналитика площадки → строки → приёмка
4. Запуск                кабинеты, тексты, метки, маркировка
5. Обработка             заявка → разговор → оплата; причины отказа
6. Факт                  учёт, сверка кабинета с учётной системой, недельная строка
7. Улучшение             диагноз → гипотеза → тест → решение → карта знаний
```

Ворота между шагами — по стандарту порядка работ: следующий шаг не начинается, пока предыдущий не отдал
свой результат. Вернуться назад дешевле, чем исправлять запущенную рекламу.

## Что закрыто, что частично, чего нет

**Статусы.** «Есть хозяин» — в каноне есть действующий документ или навык на эту тему; его полнота при
сверке не проверялась. «Частично» — хозяин есть, но названной части не покрывает или устарел. «Нет» —
хозяина нет.

Рубрикатор — модули курса MAED; номер модуля в скобках показывает, где лежит первоисточник для пробела.
Курс изучен только по медиапланированию; остальное в нём — библиотека, из которой пробел закрывается
по [стандарту извлечения знаний](<../_Движок/Канон/Стандарт — Извлечение знаний из обучающих материалов.md>).

## Как закрывается пробел

1. Назвать пробел владельцу: тема, зачем она нужна задаче сейчас.
2. Проверить, не закрывает ли его проектный документ: в проектах часто лежит то, чего нет в каноне.
3. Взять первоисточник: модуль курса MAED из таблицы выше или источник, который назовёт владелец.
4. Пройти стандарт извлечения знаний: полное чтение, реестр покрытия, сверка с имеющимся, дельта.
5. Переносимое — в методобазу отдельным документом; сюда — одна строка со статусом и ссылкой.
6. Навык `marketing` не правится: он читает эту карту.

Пробел, который задаче не нужен, не закрывается «на будущее».
