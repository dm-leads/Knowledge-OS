# CHANGELOG — Движок роста

## 2026-09-28 — Навыки шагов: исходник в каноне, в проектах — ссылки
- Исходник шести навыков шагов (`growth-step0-sources`, `growth-step1-goal`, `growth-route`, `growth-diagnose`,
  `growth-hypotheses`, `growth-close-cycle`) перенесён из репозитория первого инстанса в
  `_Движок/Исходники скиллов/`. В `~/.claude/skills` и в папке навыков проекта — ссылки (junction), копий нет.
- Установщик движка (`growth_engine.install_skills`) ставит ссылки, а не копии: копия на месте ссылки уходит
  в резерв рядом с папкой навыков (не внутрь — иначе навык виден дважды), чужая ссылка не трогается; корень канона —
  переменная `KNOWLEDGE_OS`. Тест навыков читает тексты из канона и следит, чтобы второй копии в коде не появилось.
- Причина: навыки ставились копией, и другой проект получал их снимком на день копирования — как и канон до
  исправления гайда установки. Открытый вопрос — где жить ядру кода `growth_engine/core`: пока оно внутри
  репозитория первого инстанса, новый проект получает его только копией.

## 2026-09-28 — Класс E: поиск делится по системам, базы выдачи — оценка
- [Стандарт — Протокол обнаружения источников](<../Стандарт — Протокол обнаружения источников и глубина погружения.md>):
  класс E дополнен панелями вебмастеров и базами выдачи с данными о конкурентах; лестница E начинается
  с поисковой системы; два правила — поиск до диагноза делится по системам, трафик и бюджеты баз выдачи —
  `оценка`, а не факт своего сайта.
- Основание — первый инстанс (Бризекс): «поиск −33 % год к году» оказался целиком спадом Google при ровном
  Яндексе; оценка трафика базы выдачи росла, когда факт падал. Правило для конкретного сервиса (Keys.so) —
  в навыке `keysso`, раздел «Keys.so в работе с гипотезами».
