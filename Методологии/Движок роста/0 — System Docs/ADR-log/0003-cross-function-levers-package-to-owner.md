# ADR-0003 — Рычаги вне маркетинга: диагностировать всё, исполнять своё, чужое — пакетом владельцу

- **Статус:** Accepted
- **Дата:** 2026-09-13

## Контекст

Точки роста прячутся на стыках функций (Красинский: гэпы маркетинг ↔ продажи), а порядок рычагов
начинается с маржи и чека — вне маркетинга. Ограничить систему маркетингом — заранее отказаться
от самых сильных рычагов. Дать ей ставить задачи всем функциям — требует мандата, которого нет.

## Решение

Система смотрит всю цепь до прибыли и формулирует гипотезы для любой функции. У каждой гипотезы —
владелец и зона. Своя зона — в исполнение и замер. Чужая — **пакет рекомендации**: данные с
статусами, эффект в единицах цели и в ₽, RAT-допущения, самая дешёвая проверка. Реестр держит
статус `ждёт владельца`. В чужую зону система не вторгается.

## Рассмотренные альтернативы

- Только маркетинг; остальное как «ограничение» — отвергнуто: противоречит порядку рычагов.
- Полный кросс-функциональный контур с задачами всем функциям — отложено до мандата от
  руководства компании.

## Последствия

- (+) гэпы на стыках видны и оцифрованы; владелец получает готовое обоснование.
- (+) нет политического риска вторжения в чужую зону.
- (−) пакет может лежать без ответа; статус `ждёт владельца` делает это видимым, но не решает.
