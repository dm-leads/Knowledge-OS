# ADR-0001 — Поэтапно: сначала «мозг», потом сервер

- **Статус:** Accepted
- **Дата:** 2026-09-13

## Контекст

Нужна самодостаточная система, которая ведёт бизнес к цели через цикл гипотез, и которую можно
перенести в другую компанию как продукт. Образец «механики на сервере» уже есть — речевая
аналитика Бризекс (агентный доступ, стражи в коде, гейт). Соблазн — повторить её сразу.
Но переносимая ценность — методология и протокол данных, а не деплой; серверная часть до
первого доказанного цикла — недели инфраструктуры без проверенной пользы.

## Решение

v1 = переносимый пакет: канон + скиллы агента + скрипты-адаптеры + контракты канонических
схем. Данные — снапшоты и хранилище реестра по адаптеру. Контракт данных с первого дня
проектируется под будущее серверное ядро. Сервер (расписание, агент-API, бот) — v2, после
того как первый инстанс пройдёт цикл с результатом.

## Рассмотренные альтернативы

- Сразу серверное ядро по образцу речевой аналитики — отвергнуто: цена до первого цикла
  измеряется неделями; переносимость = деплой у клиента.
- Только пакет методологии и скиллов без серверной части вовсе — отложено: нет расписания,
  накопления истории и общего доступа команды; годится как v1, но не как предел.

## Последствия

- (+) первый цикл гипотез начинается в днях, а не неделях; переносимость проверяется сразу.
- (+) смена решения о сервере не трогает канон и контракты.
- (−) до v2 нет расписания и командного доступа; всё через агента владельца.
