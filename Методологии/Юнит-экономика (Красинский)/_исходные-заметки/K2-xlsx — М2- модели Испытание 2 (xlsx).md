## 5. Фреймворки / модели

### Главная модель: воронка юнит-экономики (4 блока)

```
[Блок 1: Воронка продаж]
Users → (×Conv. to regs) → Regs → (×С1) → Buyers → (×Av. Payment Count) → Payments

[Блок 2: Доход на 1-го платящего]
AMPPU = Av. Price × Margin × Av. Payment Count
CAC = Acq. Costs / Buyers
CPO = Acq. Costs / Payments

[Блок 3: На 1-го привлечённого]
AMPU = С1 × AMPPU
CPUser = Acq. Costs / Users
AMPU − CPUser = прибыль на пользователя

[Блок 4: Финансовые метрики с потока]
Revenue = Av. Price × Payments
Gross Profit = AMPPU × Buyers
COGS total = (1 − Margin) × Av. Price × Payments
Acq. Costs = CPUser × Users
Profit = Users × (AMPU − CPUser)
Profit Net = Profit − Fix Costs
```
(источник → Файл ведущего, лист «Юнит-экономика FlowWow», строки 1–3; Юнит-экономика и гипотезы, листы «подвиг 2» и «подвиг 3», строки 1–3)

### Модель двустороннего маркетплейса (FlowWow)

- Сторона 1 (B2C): покупатели цветов — organic + paid
- Сторона 2 (B2B): продавцы цветов-партнёры
- Каждая сторона имеет свою строку в модели, свои Margin/COGS/AMPPU
- Для маркетплейса: у продавцов Margin = 0,8 (комиссия, забираемая продавцом), у покупателей Margin = 0,2 (комиссия маркетплейса)
(источник → Файл ведущего, лист «Юнит-экономика FlowWow», A6–A9, r6, r9)

### Механика работы маркетплейса (направления влияния)

Из подписей «↑↑↑↑↑» / «↓↓↓»:
- Рост Users (B) → рост всего
- Конверсия (E): «↓↓ ↑» — сложно растить, но рычаг двунаправленный
- AMPPU (I) и Av. Price (J): «↓↓↓» — давление рынка вниз
- CPUser (S): «↓↓↓↓ ↑↑↑» — стоимость привлечения растёт с масштабом
- AMPU (T): «↓↓↓» — давление вниз
(источник → Файл ведущего, лист «Юнит-экономика FlowWow», r13)

### Модель гипотез

- Формат: «если [действие], то [метрика вырастет/упадёт], [финансовый результат]»
- Оценка: часы реализации (трудозатраты) + целевая метрика
- Выбор: гипотеза с наибольшим вероятным выходом на цель
(источник → Файл ведущего, лист «Гипотезы FlowWow», C9–C10; Юнит-экономика и гипотезы, лист «подвиг 1», C9–C10)

## 10. Термины в глоссарий

| Термин | Расшифровка |
|---|---|
| AMPPU / CLTV | Average Margin Per Paying User / Customer LifeTime Value — маржа на 1-го платящего |
| AMPU / LTV | Average Margin Per User / LifeTime Value — маржа на 1-го привлечённого |
| CAC | Customer Acquisition Costs — стоимость платящего |
| CPO / SPS | Cost per Order / Cost per Sale — стоимость заказа |
| CPUser / CPLead | Cost per User / Cost per Lead — стоимость привлечения пользователя |
| С1 | конверсия в первую покупку (conv to buyer) |
| COGS | Cost of Goods Sold — себестоимость / издержки на продажу |
| Gross Profit | валовая прибыль с потока пользователей |
| Profit | прибыль до вычета Fix Costs |
| Profit Net | чистая прибыль (после Fix Costs) |
| Av. Payment Count / LifeTime | среднее число оплат на 1-го платящего |
| Fix Costs | постоянные расходы в месяц |
| Acq. Costs | расходы на привлечение пользователей |
| Кросс-чек | верификация модели: два способа расчёта одного показателя должны давать разницу = 0 |
| Точка роста | метрика, при изменении которой достигается финансовая цель |
| Потолок бизнеса | оценка сверху: максимальные реалистичные значения ключевых метрик |

(источник → оба файла, строки заголовков листов)

## 11. Типичные ошибки / антипаттерны

- **Рост трафика ×10 не спасает убыточную модель.** Если AMPU − CPUser отрицателен, масштаб только увеличивает убыток.
  [факт из материала]: при Users ×10 Profit Net = −4 252 360 р. (источник → Файл ведущего, r25)

- **Не брать округлённые цифры из презентаций «как есть» без проверки.** Нужно понять: считать по формулам или использовать заявленное число.
  (источник → Юнит-экономика и гипотезы, лист «подвиг 2», B15)

- **Красный кросс-чек = ошибка в модели.** Если два способа расчёта не совпадают — значит, что-то не учтено.
  (источник → Юнит-экономика и гипотезы, лист «подвиг 2», B16)

- **Не менять зависимые (жёлтые) ячейки вручную** — только ключевые (голубые). Иначе модель ломается.
  (источник → Юнит-экономика и гипотезы, лист «подвиг 3», B8–B9)

- **Потолок бизнеса считать в рамках текущей бизнес-модели.** Смена модели — отдельная гипотеза.
  (источник → Юнит-экономика и гипотезы, лист «подвиг 3», B26)
