## 1. Концепции и идеи

- **MAU через ретеншн:** Monthly Active Users считается не напрямую, а через когортное накопление — каждый месяц к активным добавляется доля ранее привлечённых пользователей, определяемая retention-кривой. (источник → лист «Рассчет MAU по ретеншену»)
- **Степенной закон ретеншна:** Retention убывает по степенному закону (`a * t^b`), где `a` — начальное значение, `b` — показатель степени (обычно отрицательный). Это базовый паттерн для медиа и SaaS. (источник → лист «Рассчет MAU по ретеншену», ячейки E1/E2, строка 7)
- **Две модели ретеншна:** (1) Из реальных данных GA за 3 месяца → фитируется в параметры `a` и `b`. (2) Альтернативная: `Ret(t) = 0.33 * t^(-0.1)` — более медленное убывание, для зрелого продукта. (источник → лист «Рассчет MAU по ретеншену», строки 4–7 и 33–53)
- **Три секции в модели MAU:** Три независимых блока расчёта MAU — каждый со своей retention-кривой и набором метрик (блок 1: рекламная модель ARPMAU; блок 2: SaaS/транзакционная LTV+CLTV; блок 3: churn-аналитика). (источник → лист «Рассчет MAU по ретеншену»)
- **Когортный прогноз LTV в SaaS:** В NDA-модели SaaS — полноценный когортный анализ с разбивкой gross profit и buyers по когортам (по месяцам привлечения). Retention внутри когорты считается как отношение платящих в Nm к платящим в N(m-1). (источник → лист «Когорты прогноз. LTV»)
- **Churn пользователей и Churn total:** Различаются «потерянные пользователи в месяце» (Churn users = разница между активными в предыдущем и сохранившимися в текущем из той когорты) и суммарный «накопленный Churn total». (источник → лист «Рассчет MAU по ретеншену», столбцы Q, R, строки 53–65)
- **AvPC LifeTime:** Средняя выручка с покупателя за весь жизненный цикл; считается как SUM(gross profit когорты) / max(buyers новых в когорте). (источник → лист «Когорты прогноз. LTV», столбец L, строки 36–43)
- **Сегментация цен «дешёвые/дорогие»:** В NDA SaaS-модели есть раздел с двумя ценовыми сегментами (строки 137–138: «дешевый», «дорого»), для каждого считаются отдельные revenue дешёвые (строки 143–144). (источник → лист «Когорты прогноз. LTV»)
- **Сырая выгрузка из БД:** Лист «выгрузка из БД» содержит реальные транзакционные данные (16 673 строки): дата первого платежа, месяц/год регистрации, дата транзакции, ga_clientID, userID, transactionID, revenue (руб.). (источник → лист «выгрузка из БД»)

## 2. Точные определения

- **MAU (Monthly Active Users):** В контексте модели — сумма всех когортных «хвостов» за месяц: `MAU_месяц = SUM(C:N по строке месяца)`. (источник → лист «Рассчет MAU по ретеншену», формула O10: `=SUM(C10:N10)`)
- **ARPMAU (Average Revenue Per MAU):** Выручка с одного MAU в месяц; в рекламной модели = AvPrice × Imps Per User. (источник → лист «Рассчет MAU по ретеншену», ячейка M25: `ARPMAU (AMPPU)`, O25: `=O26*O27`)
- **AvPrice = CPM / 1000:** Цена одного показа = CPM / 1000. (источник → лист «Рассчет MAU по ретеншену», ячейка M26)
- **AMPU:** Average Monetization Per User — средняя монетизация на пользователя. (источник → лист «Рассчет MAU по ретеншену», ячейка R29)
- **C1:** Конверсия первого платежа. (источник → лист «Рассчет MAU по ретеншену», ячейки S29, S33)
- **AMPPU 30:** Average Monetization Per Paying User за 30 дней — средняя монетизация на платящего пользователя за первые 30 дней. (источник → лист «Рассчет MAU по ретеншену», ячейки T29, T33)
- **LTV:** Lifetime Value — сумма gross profit с одного нового покупателя за весь период; в модели `LTV = C1 × AMPPU 30` (отдельно вычисляется сумма по когорте). (источник → лист «Рассчет MAU по ретеншену», ячейка R33)
- **CLTV:** Customer LTV = C1 × AMPPU 30 (произведение конверсии и среднего чека). (источник → лист «Рассчет MAU по ретеншену», ячейки T33, R30: `=S30*T30`)
- **Acq Costs:** Расходы на привлечение (acquisition costs). (источник → лист «Рассчет MAU по ретеншену», ячейка M29)
- **CPUser:** Стоимость привлечения одного пользователя (Cost Per User). (источник → лист «Рассчет MAU по ретеншену», ячейка M30)
- **gross profit cohort:** Суммарный gross profit когорты за все периоды наблюдения. (источник → лист «Когорты прогноз. LTV», A24)
- **buyers cohort:** Количество уникальных покупателей в когорте (по месяцу первого платежа). (источник → лист «Когорты прогноз. LTV», A35)
- **ARPPU CLTV:** ARPPU за полный жизненный цикл = gross profit cohort / buyers cohort (AvPC LifeTime). (источник → лист «Когорты прогноз. LTV», A102)
- **churn, %:** Доля потерянных пользователей/выручки относительно базы предыдущего периода. (источник → лист «Когорты прогноз. LTV», A8, A14, A20)
- **C 2m, C 3m … C 9m:** Удержание когорты на 2-й, 3-й … 9-й месяц относительно первого месяца (retention ratio by cohort). (источник → лист «Когорты прогноз. LTV», заголовки N23–S23, N34–U34)
- **AMPPU:** Average Monetization Per Paying User (общий). (источник → лист «Когорты прогноз. LTV», ячейка J90)
- **осталось инвестиций:** Runway — остаток инвестиций после учёта burn rate и gross profit. (источник → лист «Когорты прогноз. LTV», A96)
- **fix costs burn rate:** Фиксированные операционные расходы в месяц. (источник → лист «Когорты прогноз. LTV», A97)

## 3. ФОРМУЛЫ

### Модель MAU по ретеншну (лист «Рассчет MAU по ретеншену»)

**Параметры степенного закона:**
- `E1 = D4` — параметр `a` (начальный уровень ретеншна, берётся из GA-данных за 3 месяца)
- `E2 = -1.0` — параметр `b` (показатель степени, задаётся вручную)

**Retention на шаге t:**
- `D7 = $E$1 * D6^$E$2` — Ret(t) = a × t^b
- Аналогично: `E7 = $E$1*E6^$E$2`, `F7 = $E$1*F6^$E$2`, … `N7 = $E$1*N6^$E$2`

**Когортное накопление MAU (блок 1):**
- `C11 = C10` — начальная когорта копируется
- `D11 = $C10 * D$7` — число пользователей когорты янв., доживших до февр. = исходная когорта × Ret(1)
- `E12 = $C10 * E$7` — доживших до марта = исходная × Ret(2)
- … (паттерн: `колонка_мес = $C_когорта * ret_col$7`)
- `O10 = SUM(C10:N10)` — итоговый MAU месяца (сумма всех когортных хвостов)
- `P10 = O10/C10` — MAU / начальная когорта (мультипликатор)

**Альтернативная кривая ретеншна (блок 2, строки 33–53):**
- `D33 = 0.33 * D32^(-0.1)` — Ret(t) = 0.33 × t^(-0.1)
- Аналогично для E33…N33 (паттерн одинаковый)

**Рекламная монетизация:**
- `O25 = O26 * O27` — ARPMAU = AvPrice × Imps Per User
- `O26 = 5/1000` — AvPrice = CPM/1000 = 0.005
- `O29 = C10 * O30` — Acq Costs = начальная когорта × CPUser

**CLTV / LTV:**
- `R30 = S30 * T30` — LTV/CLTV = C1 × AMPPU 30

**Churn users и Churn total (блок 3, строки 55–65):**
- `Q56 = SUM(C55:N55) - SUM(D56:N56)` — Churn users месяца
- `Q55 = C54 - D55` — первый месяц churn
- `R56 = SUM(C$54:C55) - SUM(D56:N56)` — Churn total (накопленный)
- `R55 = C54 - D55` — первый месяц churn total

**Стоимость привлечения блок 3:**
- `C67 = C54 * 0.2` — Acq Costs блок 3 = начальная когорта × 0.2
- `O70 = O71 * C54` — Acq Costs = CPUser × начальная когорта
- `O49 = C34 * 0.2` — Acq Costs блок 2 = начальная когорта × 0.2

### NDA SaaS-модель (лист «Когорты прогноз. LTV»)

**Retention в когорте (C 2m = покупатели 2-го мес / покупатели 1-го мес):**
- `N31 = E31/D31`, `O31 = F31/E31`, `P31 = G31/F31`, …, `S31 = J31/I31`
- Для gross profit когорты — аналогично

**Средний C Nm по когортам (усреднение):**
- `N24 = AVERAGE(N26:N31)` — средний retention 2-го мес по всем когортам (аналогично O24…S24)

**AvPC LifeTime (CLTV когорты):**
- `M36 = L25/L36` — gross profit когорты / buyers когорты = средний LTV на покупателя

**Прогноз buyers (блок forecast):**
- `E70 = D70 * N70` — buyers в след. мес = buyers в тек. мес × retention C2m
- `F70 = E70 * O70`, `G70 = F70 * P70`, … `J70 = I70 * S70`
- `D71 = C71 * N71` (паттерн для каждой новой когорты: стартуют с числа новых, затем × Cm)

**Прогноз revenue:**
- Аналогичный паттерн: `J80 = J64 * J$74` (revenue = buyers × AMPPU 30 для соответствующего периода)

**Устаревшие когорты (before jan 2018):**
- `D88 = C88*(1-$N$88)`, `E88 = D88*(1-$N$88)` — экспоненциальное затухание с постоянным churn rate `$N$88`
- `N72 = AVERAGE(E20:J20)` — средний churn для устаревших когорт

**AMPPU:**
- `L90 = L85/E69` — суммарный gross profit / начальная когорта = AMPPU LifeTime

**Runway:**
- `E96 = D96 + D99` — остаток инвестиций = предыдущий остаток + (gross profit - fix costs)
- `D100 = D96/abs(D99)` — месяцев до нуля

**Нормализация ARPPU по когортам (индексирование к размеру когорты):**
- `J123 = J25 / max($C36:$J36)` — ARPPU когорты = gross profit / max buyers по когорте
- Аналогично для других когорт

**Выгрузка из БД (лист «выгрузка из БД»):**
- `B2 = MONTH(A2)` — месяц первого платежа
- `C2 = YEAR(A2)` — год первого платежа
- `E2 = MONTH(D2)` — месяц транзакции
- `F2 = YEAR(D2)` — год транзакции
- (паттерн повторяется 16 673 раза)

## 4. Пошаговые процедуры / алгоритмы

### Алгоритм расчёта MAU по ретеншну (модель 1)

1. Получить из GA retention за 3 месяца: значения Ret(1), Ret(2), Ret(3) — занести в строку 4.
2. Подобрать параметры `a` и `b` степенного закона: `E1=a`, `E2=b` (автоматически из D4; `b` задаётся вручную, обычно `-1.0`).
3. Рассчитать retention-кривую на 11 месяцев: `D7:N7 = a * t^b`.
4. Задать размер начальной когорты каждого месяца в столбце C (C10:C21).
5. Заполнить матрицу когортного накопления: для каждой строки-месяца × столбца-месяца = `$C_когорта * Ret(t)`.
6. Суммировать строку → получить MAU месяца (столбец O).
7. При необходимости — рассчитать ARPMAU, Gross Profit, Acq Costs, CPUser.
(источник → лист «Рассчет MAU по ретеншену»)

### Алгоритм когортного прогноза (NDA SaaS)

1. Выгрузить из БД транзакции: userID, дата первого платежа, дата транзакции, revenue.
2. Сгруппировать по когортам (месяц первого платежа) → получить gross profit и buyers по когортам.
3. Рассчитать retention в когортах: C2m = buyers(m2)/buyers(m1), C3m = buyers(m3)/buyers(m2), и т.д.
4. Усреднить retention по когортам: `AVERAGE(C_2m по всем когортам)`.
5. Применить усреднённый retention к прогнозным когортам для построения forecast buyers и forecast revenue.
6. Для устаревших когорт применить постоянный churn rate (`$N$88`).
7. Рассчитать AMPPU, CLTV, runway.
(источник → лист «Когорты прогноз. LTV»)

## 5. Фреймворки / модели

### Модель «Расчёт MAU по ретеншну» (1 лист, 3 блока)

**Блок 1 — Рекламная модель (строки 7–30):**
- Входы: размер когорты (C10:C21), параметры a, b (E1, E2), CPM (O26), Imps Per User (O27), CPUser (O30)
- Расчёты: Retention-кривая → матрица когорт → MAU → ARPMAU → Gross Profit → Acq Costs → CPUser
- Выходы: MAU по месяцам, Gross Profit, Acq Costs, AMPU, C1, AMPPU 30

**Блок 2 — SaaS/транзакционная (строки 33–50):**
- Входы: размер когорты, альтернативная кривая `0.33 * t^(-0.1)`, AMPPU 30 (T33), C1 (S33)
- Расчёты: то же накопление → MAU → LTV = C1 × AMPPU 30 → CLTV
- Выходы: MAU, Gross Profit, Acq Costs, CPUser, LTV, CLTV

**Блок 3 — Churn-аналитика (строки 53–71):**
- Входы: размер когорты, кривая (та же или своя), churn users/total
- Расчёты: Churn users = MAU(prev) − удержанные; Churn total = накопленный
- Выходы: Churn users, Churn total, Acq Costs, CPUser

## 10. Термины в глоссарий

- **MAU** — Monthly Active Users; считается когортным накоплением через retention-кривую
- **Retention-кривая** — функция убывания доли активных пользователей по времени; степенной закон `a * t^b`
- **a, b** — параметры степенного закона ретеншна (a — уровень, b — скорость убывания, b < 0)
- **ARPMAU / AMPPU** — Average Revenue Per MAU / Average Monetization Per Paying User
- **AvPrice** — CPM / 1000; цена одного рекламного показа
- **Imps Per User** — показов рекламы на одного пользователя в месяц
- **AMPU** — Average Monetization Per User (все пользователи, не только платящие)
- **C1** — конверсия первого платежа
- **AMPPU 30** — средняя монетизация на платящего за 30 дней = средний чек первой покупки
- **CLTV** — Customer LTV = C1 × AMPPU 30
- **LTV** — Lifetime Value (когортная сумма gross profit на покупателя за весь период)
- **AvPC LifeTime** — Average Payment per Customer LifeTime = gross profit когорты / buyers когорты
- **Churn users** — потерянные пользователи за месяц (из данной когорты)
- **Churn total** — накопленные потери пользователей
- **C 2m, C 3m …** — retention-коэффициенты когорты на 2-й, 3-й … месяц
- **Acq Costs** — расходы на привлечение (acquisition costs)
- **CPUser** — стоимость привлечения одного пользователя
- **fix costs burn rate** — фиксированные расходы / месяц
- **Runway** — остаток инвестиций / месяц до исчерпания
- **ARPPU CLTV** — ARPPU за жизненный цикл = AvPC LifeTime
