# Справочник — Каталог фреймворков SMM: контент, реклама, прогрев, воронки

## Краткая суть

- **Фреймворк — рамка для одной задачи**, а не стратегия. Сначала шаг и его хозяин по
  [карте маркетинга](<Справочник — Карта маркетинга (что чем закрыто).md>): кому говорим, на какой ступени
  человек, где он бывает. Потом из каталога берётся 1–2 рамки под задачу шага.
- **15 рамок из 72 канон уже закрывает глубже** (AARRR, ступени, матрица тем, стратегия в семи вопросах,
  разбор блогера, комбинаторика объявлений). По ним работаем по канону: каталог даёт только название, которое
  знают подрядчики и модели.
- **Дельта — 44 рамки: 15 берём как есть, 29 — с поправкой.** Главное новое: цепочки прогрева (Teaching
  Warm-Up, Curiosity Ladder, Before–After–Bridge, рефрейминг), нарезка одного большого материала (GaryVee
  Pyramid), Hero–Hub–Help, ретаргетинг по возражениям, цикл выгорания креативов, аудит выгоревших смыслов,
  архитектура выбора тарифов, бриф блогеру, лестница мелких шагов. 13 рамок — не сейчас.
- **Шесть опасных мест:** срочность, дефицит, «враг», обещание новой жизни, гарантии и списки блогеров
  «от модели». Поправки — «Правила применения», раздел 4.
- **Источник даёт названия, описания и примеры промтов, но ни одной нормы конверсии, бюджета, срока теста и
  ни одного кейса.** Результат любой рамки — гипотеза до замера.

> Для быстрого знакомства хватит блока выше. Для агентов, правок и разрешения расхождений обязателен полный текст.

## Правила применения

### 1. Порядок

1. **Шаг и хозяин.** Найти шаг в карте маркетинга. Стратегия контента — «Методология — Свои площадки»;
   площадки и бюджет — [медиапланирование](<Платный трафик/Методология — Медиапланирование.md>); что сказать сегменту — Замесин и лестница Ханта. Каталог работает
   внутри этого шага.
2. **Выбор рамки — по задаче**, колонка «Для чего» [факт: И, п. 3]. Одна рамка на задачу, две — если одна
   задаёт структуру (например, PAS), а вторая порядок серии (Curiosity Ladder). Три и больше — каша.
3. **Входы.** Чем больше на входе, тем конкретнее результат [факт: И, «Входные данные»]. Обязательный минимум
   канона [вывод]:
   - сегмент и его работа — исследование проекта, не «женщины 25–45»;
   - ступень Ханта, на которой человек сейчас;
   - факты продукта — документ тона или справочник проекта: цена, сроки, состав, условия, документы;
   - запреты проекта — паспорт проекта;
   - площадка и её ограничения — навык площадки `ads-*`;
   - реальный материал: записи разговоров, возражения, истории клиентов с их согласием.
4. **Первый результат большой задачи — промежуточный.** Каждый ключевой раздел детализируется отдельно
   («Детализируй: …») [факт: И, п. 4].
5. **Проверка до выпуска** — раздел 4 ниже, все пункты.
6. **Результат меняет что-то в работе** (новая цепочка, новые объявления, подача тарифов) — это гипотеза:
   метрика, защитная метрика, порог шума, по
   [стандарту гипотез](<Стандарт — Работа с гипотезами (формирование и приоритизация).md>).

### 2. Как дать модели вводные

Четыре способа источника [факт: И, «Входные данные»] и что с ними делает канон [вывод]:

| Способ | Канон |
|---|---|
| Описать в промте | годится; факты — блоком, копией из документа проекта, не пересказом по памяти |
| Приложить файл | годится; персональные данные во внешнюю модель — только по [политике](<Политика — Персональные данные, секреты и доступ к внешним системам.md>) |
| Интервью: «задай не больше 10 вопросов, по одному» | лучший способ, когда вводных нет; так же устроен навык `questions` |
| Ссылка на сайт: «изучи сайт» | брать живую страницу; макеты описывают замысел, а не то, что видит человек |

### 3. Усилители и правки — что оставить

| Источник предлагает | Что делаем | Почему |
|---|---|---|
| «Будь максимально конкретен, без общих фраз» [И, п. 3] | оставить | — |
| «Проанализируй аудиторию [описание]» [И, п. 3] | заменить: «аудитория — [сегмент, работа, ступень из исследования]» | описание аудитории «своими словами» даёт демографию вместо работы |
| «Убери интро и аутро» [И, п. 3] | оставить | — |
| «В конце — конкретные шаги внедрения» [И, п. 3] | оставить; шаги — с исполнителем и сроком | — |
| «Адаптируй под российскую специфику» [И, п. 3] | заменить: «площадки и закон — по канону: [площадки проекта]; Instagram и Facebook — не предлагать» | модель знает Россию по старым данным; реклама на площадках с ограниченным доступом запрещена |
| «Будь оригинальнее», «Представь таблицей», «Добавь блок с трудозатратами» [И, п. 5] | оставить | — |
| «Добавь конкретные цифры» [И, п. 5] | **заменить:** «числа — только из вводных; где числа нет — пометка [нужен факт]» | модель дописывает правдоподобные числа; это нарушение правила достоверности |

### 4. Шесть опасных мест и поправки

| Где | Риск | Поправка канона |
|---|---|---|
| Limited Time Offer, Product Launch Formula, Чалдини (дефицит), Time-Bound Ritual | ложная срочность и ложный дефицит | только реальные сроки и ограничения: старт потока, закрытие набора, число мест. Ложная срочность — недостоверная реклама (ч. 3 ст. 5 ФЗ-38), см. [Разговор с покупателем](<Продажи/Методология — Разговор с покупателем (SPIN, Challenger, GPCT).md>) |
| Enemy / Tension, PAS (агитация), Proof of Struggle | давление страхом; «враг» — конкурент | враг — обстоятельство или старый способ, не люди и не конкуренты (некорректное сравнение — недобросовестная реклама, ч. 2 ст. 5 ФЗ-38); агитация — показать последствия фактами, без запугивания |
| Transformation Funnel, Identity Shift, Identity Shift Story, VSL | обещание результата, которого продукт не гарантирует | обещать только то, что подтверждено фактом продукта; остальное — «[нужен факт]». Проектные запреты (например, трудоустройство) — из паспорта проекта |
| Risk Reversal Funnel | выдуманные гарантии: возврат денег, бесплатный тест | только условия, которые есть в договоре и оферте |
| Influencer Pyramid, 3 R's of Influence | «приведи конкретных блогеров» — модель выдумает имена и цифры | список — из TGStat, поиска площадки, конкурентов; каждый — через [разбор площадки блогера](<Платный трафик/Справочник — Разбор площадки блогера перед интеграцией.md>) |
| UGC Flywheel, Hero's Journey, Proof of Struggle, отзывы в любой рамке | выдуманные истории и отзывы | только реальные люди с согласием на публикацию; отзыв за плату или «по просьбе знакомых» — накрутка (см. «Свои площадки», раздел 7) |

Опасные места самих офферов и денежных моделей (условия после оплаты, «бесплатно» при платном исходе, розыгрыши,
выдуманные сборы и ценность бонусов) — [Методология — Офферы и денежные модели](<Методология — Офферы и денежные модели (Хормози, Агарков).md>), раздел 6.

### 5. Каркас промта

Источник даёт пример промта у каждой рамки: «Построй [рамку] для [бизнес]» [факт: Ф, все разделы]. Канон
дописывает вводные и ограничения [вывод]:

```text
Задача: [что нужно получить] по модели [название рамки] — [суть рамки одной строкой из каталога].
Для кого: [сегмент] — [работа клиента]; сейчас на ступени [N по Ханту]: [что уже знает].
Площадка: [где увидят] — ограничения: [лимиты и запреты площадки].
Факты продукта (использовать только их): [блок фактов из документа проекта].
Нельзя: [запреты проекта]; ложная срочность и дефицит; выдуманные люди, кейсы, отзывы, числа.
Чего не хватает в фактах — пометь [нужен факт], не придумывай.
Формат ответа: [таблица / серия N единиц: тема, тезисы, цель — какой реакции ждём, метрика перехода].
Будь конкретен, без интро и аутро. В конце — шаги внедрения с исполнителем.
```

Нет вводных — сначала интервью: «Задай мне не больше 10 вопросов, по одному».

## Каталог

Колонки: **Для чего** — задача рамки; **Суть** — как устроена; **Вердикт** — итог сверки с каноном;
**Вход и поправка** — что подставить у нас и где канон глубже.

Вердикты: **берём** — дельта, работает как описано; **с оговоркой** — берём с поправкой из графы справа;
**есть в каноне** — канон закрывает глубже, работаем по нему; **не сейчас** — задача редкая для малого
проекта или нужна база, которой ещё нет.

### Воронки продаж — 12 [факт: Ф, «Фреймворки для воронок продаж»]

| Рамка | Для чего | Суть | Вердикт | Вход и поправка |
|---|---|---|---|---|
| AARRR | найти, где течёт воронка | привлечение → активация → удержание → рекомендации → доход | есть в каноне | [Классические фреймворки](<Справочник — Классические фреймворки маркетинга и роста.md>), раздел AARRR; узкое место — Движок роста |
| TOFU–MOFU–BOFU | контент под готовность | три стадии: внимание, прогрев, покупка | есть в каноне | лестница Ханта точнее: шесть ступеней вместо трёх |
| Flywheel | рост за счёт довольных клиентов | цикл вместо воронки: рекомендации, повторные покупки и лояльность разгоняют рост; силы — маркетинг, продажи, обслуживание | с оговоркой | у разовой покупки нет повторных — колесо держится только на отзывах и рекомендациях; экономика удержания — Красинский |
| Cold–Warm–Hot | цепочка прогрева по готовности | холодные, тёплые, горячие — свой контент и оффер каждым | есть в каноне | ступени Ханта; полосы балла — [ловец лидов](<Методология — Подбор лидов в открытых сообществах (ловец лидов).md>) |
| StoryBrand Funnel | воронка через историю | клиент — герой, компания — проводник: заинтересовать → показать, что понимаешь проблему → решение → доверие → план → призыв → последствия | с оговоркой | «последствия» — фактами, без запугивания; герой — сегмент из исследования |
| Transformation Funnel | путь «точка А → точка Б» | осознание → интерес → вовлечение → внедрение → результат | с оговоркой | точка Б — только подтверждённый результат продукта; «точка А / точка Б» есть у Замесина |
| Lead Magnet Funnel | контакт за бесплатную пользу | лид-магнит → автоцепочка → продажа | берём | лид-магнит — от работы и барьера сегмента; оценить «усилие ↔ награда» (Effort–Reward); сборка воронки — [Воронки и автоворонки](<Методология — Воронки и автоворонки.md>) |
| VSL Funnel | одно продающее видео | крючок → проблема → решение → доказательства → призыв | с оговоркой | кейсы и результаты — только реальные; иначе «[нужен кейс]»; шаблон VSL и каркас из 10 вопросов — [Воронки и автоворонки](<Методология — Воронки и автоворонки.md>), раздел 5 |
| Content Funnel | контент по уровням воронки | верх — информировать, середина — доверие, низ — возражения и покупка | есть в каноне | матрица тем «работа × ступень» — «Свои площадки», раздел 3 |
| Risk Reversal Funnel | снять страх перед покупкой | гарантия, пробный шаг, оплата частями, кейсы | с оговоркой | только условия из договора и оферты |
| Limited Time Offer Funnel | ускорить решение сроком | дедлайн → ценность оффера → напоминания → закрытие | с оговоркой | только реальный срок; ложная срочность запрещена; нормы — [Воронки и автоворонки](<Методология — Воронки и автоворонки.md>), раздел 11 |
| Cancellation Funnel | удержать уходящего | причины отказа → альтернатива → обратная связь → возврат | не сейчас | для подписок; у разовой покупки аналог — причины отказа в учёте продаж |

### Сторителлинг — 9 [факт: Ф, «Фреймворки для сторителлинга»]

| Рамка | Для чего | Суть | Вердикт | Вход и поправка |
|---|---|---|---|---|
| Hero's Journey | история преодоления | обычный мир → вызов → наставник → испытания → прорыв → награда → возвращение | с оговоркой | реальный герой с согласием: основатель, преподаватель, выпускник |
| Brand Archetype Storytelling | узнаваемый образ бренда | архетип по Юнгу → ценности → легенда | не сейчас | бренд-стратегии в каноне нет; архетип — упражнение, не основание решений |
| Enemy / Tension | напряжение в сообщении | «враг» мешает аудитории; продукт его побеждает | с оговоркой | враг — обстоятельство или старый способ, не конкурент; без запугивания |
| Hook–Story–Offer | цепляющее продающее сообщение | крючок → история → предложение | берём | крючки — `text-editor`, `references/ad-combinatorics.md` |
| Brand World | целостный мир бренда | стиль, голос, ценности, герои, среда на всех точках касания | не сейчас | голос — `brand-voice`; остальное — после бренд-стратегии |
| Identity Shift Story | история внутренней перемены | старая идентичность → вызов → перемена → новая | с оговоркой | реальная история; не обещать перемену как результат продукта |
| In Medias Res | внимание с первых секунд | начать с самого острого момента, потом объяснить | берём | совпадает с «завязкой за 2 секунды» — «Свои площадки», раздел 6 |
| Serial Storytelling | интерес на серию | эпизоды с общей сюжетной линией | берём | в «Своих площадках» «серия» — другое: партия роликов, чтобы найти сработавшие; здесь — сюжет на несколько выпусков |
| Proof of Struggle | вовлечь через трудности | сомнения, провалы и путь к результату | с оговоркой | только реальные события |

### Прогрев — 11 [факт: Ф, «Фреймворки для прогревов»]

| Рамка | Для чего | Суть | Вердикт | Вход и поправка |
|---|---|---|---|---|
| Product Launch Formula (Дж. Уокер) | запуск продукта или потока | предзапуск → серия ценного контента → дефицит и социальное доказательство → открытие продаж с ограниченным окном | с оговоркой | окно и дефицит — только реальные: старт потока, число мест |
| PAS | первые касания прогрева (в источнике поле «Для чего» испорчено — задача взята из описания) | проблема → усиление → решение | с оговоркой | усиление — последствиями-фактами, без давления |
| Before–After–Bridge | подвести к офферу | как сейчас → как может быть → мост (продукт) | с оговоркой | «как может быть» — подтверждённое продуктом |
| Teaching Warm-Up | продажа через пользу | сначала короткий урок, лайфхак или наблюдение, потом предложение | берём | тема урока — из работы сегмента; лучшая рамка для образовательного продукта [вывод] |
| Прогрев через рефрейминг | сменить взгляд на проблему | новая рамка восприятия → решение | берём | рамка — из исследования: как сегмент думает о задаче сейчас |
| Прогрев по Чалдини | доверие через шесть принципов влияния | авторитет, дефицит, социальное доказательство, симпатия, обязательство, взаимность | с оговоркой | дефицит и доказательства — только реальные |
| Curiosity Ladder | вовлекать нарастающим интересом | лёгкий крючок → интригующие факты → обещание инсайта → призыв | с оговоркой | каждую открытую петлю закрыть; кликбейт без ответа — недостоверность |
| Identity Shift | продукт как мост к новому «я» | кем станет человек после продукта | с оговоркой | не обещать того, чего продукт не гарантирует |
| Choice Architecture | упростить выбор | порядок, число и подача вариантов, вариант по умолчанию | с оговоркой | для тарифов и форм; предвыбранная платная опция — риск навязывания услуги (ст. 16 закона о защите прав потребителей; пункт проверить по первоисточнику на дату работы) |
| The Hook Model | привычка к продукту | триггер → действие → переменная награда → вклад | не сейчас | для продукта, не для прогрева; ближе — [CJM продакта и игровые циклы](<Юнит-экономика (Красинский)/Справочник — CJM продакта и игровые циклы.md>) |
| Trust Accumulation Model | доверие до первой продажи | внимание и польза → экспертиза → регулярность → предложение | есть в каноне | ступени Ханта; доказательства — на ступени 4, а не в холодной рекламе |
