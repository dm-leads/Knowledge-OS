# Справочник — Карта методобазы: задача, документ, навык

## Краткая суть

- Одна задача бизнеса — один документ-хозяин. Навык — способ пройти документ по шагам; если навыка в проекте нет,
  агент читает документ напрямую.
- Подробные карты по областям остаются там, где были: маркетинг — [карта маркетинга](<Справочник — Карта маркетинга (что чем закрыто).md>),
  всё, чего нет, — [справочник пробелов](<Справочник — Пробелы методобазы и источники.md>). Здесь — общий вход.
- **Зрелость:** «основа» — проверено применением в проектах; «черновик» — собрано из источников с адресами и
  проверено второй моделью, в проекте ещё не применялось — первое применение даёт правки.
- Пути — от `D:\Knowledge-OS\Методологии\`. Навыки стоят на устройстве в `~/.claude/skills` ссылками на
  `D:\Knowledge-OS\_Движок\Исходники скиллов\`.

## Как читать

1. Найди строку задачи в таблице ниже.
2. Возьми документ-хозяин; начни с его «Краткой сути» и «Порядка работы».
3. Есть навык — вызови его: он ведёт по шагам и знает соседние документы.
4. Колонка «Чего нет» — пробел называется вслух, методика не сочиняется.
5. Деньги любого решения — строкой `unit-economics`; число без источника и статуса — не число
   ([Достоверность](<Стандарт — Достоверность выводов и проверка.md>)).

## Блок для запроса из проекта

Вставить в запрос агенту проекта, заменив две строки в угловых скобках:

```text
Методобаза — D:\Knowledge-OS\Методологии\. Начни с «Справочник — Карта методобазы- задача, документ, навык.md»:
найди строки под задачу <задача одной фразой> и возьми только их документы-хозяева и навыки. Документы канона
не копируй в проект — ссылайся; в проект пиши только применение: наши числа, ограничения, решения.
Черновики канона применяются впервые — где документ не подошёл к проекту, запиши, что и почему (это правка канона).
Пробел из колонки «Чего нет» назови вслух, методику не сочиняй. Деньги каждого решения — строкой unit-economics,
числа — со статусом (факт / оценка / proxy / нет данных). Площадки, цены и законы — на дату, по первоисточнику.
Результат — <что считать готовым>.
```
