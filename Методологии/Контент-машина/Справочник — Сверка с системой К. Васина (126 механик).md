## Свои механики, которых у К. Васина нет (29)

1. Книга ставок: тема → гипотеза → итог по каждой статье.
2. Тема из гипотезы Движка роста — с ожиданием и порогом провала.
3. Замер на 90-й и 180-й день от дня выкладки.
4. Деньги страницы по CRM через Ядро данных.
5. Лесенка ценности страницы: деньги → заявки → цена клика → нет данных.
6. Направления (корзины) с квотами слотов на квартал.
7. Закрытие направления данными: статьи есть — заявок нет.
8. Вопросы клиентов из звонков и переписок как источник спроса.
9. Проверка выборки по подстроке чтением 10–15 примеров.
10. «Поле шире освоенного» — регулярная проверка новых направлений.
11. Поиск по полным текстам статей не меньше чем тремя формулировками.
12. Поиск по разделам статей, разделы старых статей восстанавливаются по оглавлению.
13. «Наша страница уже в топе» — стоп, только если она зарабатывает.
14. Судья спорного: эмбеддинги ищут пять ближайших, модель выбирает из них, человек решает.
15. Чтение статьи-риска целиком — при пополнении запаса, а не в день выпуска.
16. Норма запаса тем и пополнение по порогу.
17. Заложенный отсев: на норму запаса гейт гонит кандидатов с запасом.
18. Запрет в коде взять тему без пройденного гейта.
19. Журнал отсева с возможностью вернуть тему.
20. Независимая вычитка фактов — отдельный агент без контекста автора.
21. Граница честности в мосте к продукту.
22. Каждая норма — ссылкой на первоисточник.
23. Критик тона и правил проекта.
24. Проход под ИИ-ответы на этапе производства, а не только после публикации.
25. Скелет статьи против корпуса и замер самоплагиата.
26. Автопроверки сборки страницы.
27. День выкладки отдельно от дня сборки, запись в день действия.
28. Запись во внешние таблицы: план → применение → сверка чтением.
29. Известные ответы — прогон проверочных случаев при каждой смене кода и порогов.
