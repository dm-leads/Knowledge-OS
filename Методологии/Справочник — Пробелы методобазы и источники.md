# Справочник — Пробелы методобазы и источники

## Краткая суть

- Карта маркетинга отвечает за маркетинг. Этот справочник — за всё, что вокруг: продажи как система, деньги
  компании, управление, закон.
- Пробел из этого списка агент называет вслух и не заполняет сочинением. Пока методики нет — опора из колонки
  «Чем пользоваться сейчас».
- Источник выбирает владелец. Книги с устройства читаются по [стандарту извлечения знаний](<../_Движок/Канон/Стандарт — Извлечение знаний из обучающих материалов.md>);
  библиотека — `D:\Курсы\Книги\` (копия на F:). Опись библиотеки на 09.11.2026 обрывается на разделе «Память» —
  разделов с «П» по «Я» в ней нет.

## Порядок закрытия

1. Владелец выбирает источник или подтверждает книгу из колонки «на устройстве».
2. Чтение целиком, реестр покрытия, выжимка с адресами — по стандарту извлечения.
3. Сверка с каноном; переносимое — методологией или справочником; сюда — новый статус и ссылка.
4. Пробел, который не нужен задаче, не закрывается «на будущее».
