## 4. Где в моделях лежит механика поиска точек роста

Механика есть, и она везде устроена одинаково: **строка базовой экономики копируется вниз,
в копии меняется ровно одна метрика, а рядом стоит формула отношения — во сколько раз вырос
результат.** Ниже — где именно, с адресами.

### 4.1. М1 / М4, лист `Шаблон`, строки 21–39 — самый полный стенд [Факт]

`A21` = «гипотезы роста метрик». Ниже семь именованных направлений, каждое — отдельная строка
с полным пересчётом. **Ключевая ячейка — столбец `Y`, подписанный `Y3` = «эффект»:**

```
Y32 = =AA32/AA$15     эффект гипотезы = Profit гипотезы / Profit базовой строки 15
Y33 = =AA33/AA$15
Y34 = =AA34/AA$15
Y36 = =AA36/AA$15
Y39 = =AA39/AA$15
```

Что дают эти строки в числах (посчитано из кэша файла):

| Строка | Гипотеза | `AA` (Profit) | `Y` (во сколько раз) |
|---|---|---|---|
| 22 | привлечь больше пользователей (`B22` = `=B$16*6`) | −504 000 | — (убыток масштабируется) |
| 23 | снизить CPUser | −84 000 | — |
| 28 | апселы, кросс-селы | 80 000 | — |
| 32 | повысить конверсию (`E32` = `=E$15+10%`) | 260 000 | **3,25×** |
| 33 | рост среднего чека (`J33` = 1200) | 260 000 | **3,25×** |
| 34 | рост числа повторных покупок (`P34` = 2,4) | 260 000 | **3,25×** |
| 36 | рост маржи + чека (`K36` = 0,15, `J36` = 1200) | 980 000 | **12,25×** |
| 39 | то же + конверсия (`E39` = `=E$15+10%`) | 2 060 000 | **25,75×** |

**Строка 37 — отдельная ценность.** Это нормировка каждой метрики к базе, то есть готовая
таблица чувствительности:

```
E37 = =E36/E$15   →  1     конверсия не менялась
I37 = =I36/I$15   →  6     AMPPU вырос в 6 раз
J37 = =J36/J$15   →  2     чек вырос вдвое
K37 = =K36/K$15   →  3     маржа выросла втрое
P37 = =P36/P$15   →  1     число покупок не менялось
W37 = =W36/W$15   →  12,25 маржа на пользователя
AA37= =AA36/AA$15 →  12,25 прибыль
```

**Диапазон для работы: `Модуль 1 — 1 [PHs14] Испытание 1. Юнит-экономика. Ведущий.xlsx`,
лист `Шаблон`, `A21:AB39`, столбец эффекта — `Y`, строка нормировки — `37`.**

### 4.2. М3, лист `Экономика` ведущего — блок «Плечи метрик» [Факт]

`Модуль 3 — 5 [PHs14] Испытание 3. Ведущий..xlsx`, лист `Экономика`, `A11:U23`.
`A11` = «Плечи метрик». Устройство:

| Строка | Что двигают | Формула сдвига | Формула эффекта |
|---|---|---|---|
| 12 | конверсия +0,5 п.п. | `E12` = `=E5+0.5%` | `U12` = 808 640 ₽ |
| 14 | — | | `U14` = `=U12/U5` → **9,62×**; `F14` = `=F12/F5` → 2,91× |
| 16 | средний чек 551 → 2000 ₽ | `J16` = 2000 | `U16`, при `A15` = «аналогичный эффект» |
| 17 | — | `J17` = `=J16/J5` → 3,62× | `U17` = `=U16/U5` → **12,87×** |
| 19 | **обратный ход**: сколько нужно пользователей ради того же результата | `B19` = `=U19/(R19-Q19)` → 2 296 687 | `B20` = `=B19/B5` → **9,62×** |
| 23 | чек поднят, но конверсия упала | `J23` = 1500, `E23` = 0,0015 | видно, что рост чека съедается падением C1 |

**Строка 19 — самая важная во всей папке для вашей задачи.** Это не «что будет, если» —
это **«сколько трафика нужно купить, чтобы получить тот же эффект, что даёт +0,5 п.п. конверсии»**.
Ответ модели: в 9,62 раза больше пользователей. Ровно тот способ рассуждения, который вам нужен:
не «поднять конверсию», а «конверсия +0,5 п.п. эквивалентна десятикратному росту трафика,
и что из этого дешевле».

### 4.3. М8, лист `Юнит-экономика Freedom24` / `Экономика` — тот же приём под KPI [Факт]

`Модуль 8 — [PHs14] Испытание 8. Выгода и налог..xlsx`, строки 13–20:

```
строка 13  база
строка 16  D16 = =$D$13+1.45%      рост конверсии на 1,45 п.п.
строка 18  C18 = =$C$13+200000     +200 000 пользователей
строка 20  C20 = =$C$13+1000000    +1 000 000 пользователей
```
и в каждой строке полный пересчёт: `W16`/`W18`/`W20` = `=C*(S-R)` — Profit.
`B16` = «рост конверсии в покупку», `B17` = «аналогичный эффект», `B18` = «привлечь новых
пользователей», `B20` = «привлечь 1 млн новых пользователей».

В файле ведущего (`Модуль 8 — [PHs14] Испытание 8. Юнит-экономика. Ведущий.xlsx`, лист
`Экономика`) есть обратный ход, как в М3: `B13` = `=D13/C13` — сколько пользователей нужно,
чтобы выдать заданное число покупателей. Плюс строки 16–25: воронка за месяц и **за неделю**
(`B23` = `=B17*7/31`) с доверительным интервалом `D20` = `=2*SQRT(C20*(1-C20)/B17)` — то есть
проверка «а измерим ли мы вообще это улучшение за неделю».

**Это лучший файл в папке под ваш вопрос**, потому что задача в нём сформулирована как у вас:
дан KPI (1 000 покупателей в месяц) — найди, каким рычагом его брать. И справочник его не описывает.

### 4.4. М2, лист `подвиг 3. точки роста` — тренажёр перебора [Факт]

`Модуль 2 — [PHs14] Испытание 2. Юнит-экономика и гипотезы.xlsx`, `подвиг 3. точки роста`,
диапазон `B12:AT35`. Строка 12 — база. Дальше по одной метрике за раз:

| Строка | Метрика | Формула |
|---|---|---|
| 20 | Users ×1,8 | `C20` = `=36812*1.8` |
| 23 | C1 +1,3 п.п. | `F23` = `=1.70324894056286%+1.3%` |
| 27 | «потолок бизнеса» — всё сразу по максимуму | `C27` = `=36812*1.8` |
| 31 | средний чек ×1,8 | `K31` = `=3000*1.8` |
| 33 | маржа +16 п.п. | `L33` = `=20%+16%` |
| 35 | число покупок +0,8 | `P35` = `=1.20893141945774+0.8` |

Готового столбца «эффект» здесь нет — сравнивать надо `X` (Profit) вручную. Зато есть
цветовая разметка входов (`FFE5F3FF` — менять, `FFFFF2CC` — не трогать) и правило условного
форматирования `D34:AT34` `between [-1e-7, 1e-7]` — автоматический кросс-чек.

### 4.5. Таблицы приоритизации гипотез — где считается «эффект в деньгах» [Факт]

| Файл | Лист | Диапазон | Столбец эффекта |
|---|---|---|---|
| Модуль 3 — 5 Ведущий | `Гипотезы` | `A1:R55` | `H` = «эффект»; `H28` = `=N28`, `H33` = `=N33-N32` |
| Модуль 9 — Файл ведущего | `Гипотезы` | `A1:L110` | `G` = «эффект» |
| Модуль 2 — Ведущий | `Гипотезы FlowWow` | `C9:E20` | только часы (`D`) и целевая метрика (`E`), денег нет |

Шапка листа `Гипотезы` у М3-ведущего (строка 1) — это готовый формат оценки:
`B` идея · `D` метрика на которую влияет · `E` сложность (1—5) · `F` вера в успех 1—100 % ·
`H` эффект · `I` пользователи · `J` С1 · `K` ± (доверительный интервал) · `L` buyers ·
`M` AMPPU · `N` Gross Profit · `O` AMPU · `P` CPUser · `Q` Acq. Costs.

Строка 2 — «текущая экономика», подтянутая с листа модели: `I2` = `='Экономика'!B5`,
`M2` = `='Экономика'!I5`. Строка 3 — та же экономика **за неделю**: `I3` = `=I2/4.5`,
`K3` = `=2*SQRT(J3*(1-J3)/I3)` — недельный доверительный интервал, порог измеримости гипотезы.

**Предупреждение:** в аналогичном листе `Гипотезы` файла «Модуль 9 — Файл ведущего.xlsx» строка
«текущая экономика» сломана: `H2`, `I2`, `K2` = `=#REF!`. Эффекты всех гипотез этого листа
считаются от несуществующей базы. Брать этот лист как образец нельзя. [Факт]

### Инструмент, который я поставил и проверил в ходе этой работы

**`formulas`** (PyPI, чистый Python) — разбирает книгу Excel в граф зависимостей и **считает
формулы**. Поставлен, проверен на корневом шаблоне. Результат:

```
Загрузка модели, пересчёт всех 145 формул:
   B5 = 110000.0        D5 = 0.015454545      G5 = 2100.0
   T5 = 2170000.0       V5 = 3570000.0        Z5 = -830000.0
   ↑ сошлось с кэшем файла до знака
```

И — главное — **what-if работает**:

```
Вход: E5 (Buyers) 1700 → 2200,  то есть C1 1,545 % → 2,0 %
   D5 (C1)          = 0.02
   T5 (Profit)      = 3 220 000 ₽   (было 2 170 000)
   V5 (Gross Profit)= 4 620 000 ₽   (было 3 570 000)
   Z5 (после фикс.) = +220 000 ₽    (было −830 000)
```

Полпроцентный пункт конверсии переворачивает модель из минуса в плюс — и это посчитано
программно, без открытия Excel.

**Что это меняет для вашей задачи.** Раздел 4.6 говорит: автоматического поиска рычага в
моделях нет. С `formulas` его можно построить: взять любую модель, найти голубые входные
ячейки по цвету заливки (раздел 1, п. 6), сдвинуть каждую на +10 % по очереди, пересчитать
Profit и отсортировать метрики по силе отклика. Это и есть «плечи метрик», посчитанные
машиной вместо копирования строк руками.
