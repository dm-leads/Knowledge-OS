# Комбинаторика объявлений — как собрать много разных вариантов

Зачем: один угол в тридцати пересказах проверяет одно и то же. Разные углы достают разных людей из одной
аудитории — так тест чему-то учит. Справочник — пересказ открытых навыков (источники в конце), переложенный на
русский язык и наши правила: без выдуманных фактов, без давления, без обещаний сверх продукта.

## 1. Матрица — сначала она, потом слова

Порядок: **сегмент → мотивация → формат → крючок**.

1. **Сегмент** — узкий срез с общей ситуацией, а не вся аудитория: «выбирает профессию после декрета»,
   «водитель, думает сменить работу», «после колледжа, без опыта».
2. **Мотивация** — одна задача, желание или возражение этого сегмента **его словами**: из интервью, отзывов,
   комментариев, анкет. Слова корпуса сильнее маркетингового пересказа.
3. **Формат** — картинка с фразой, карусель, видео с лицом, запись экрана, диалог.
4. **Крючок** — заголовок и картинка под эту клетку.

Таблица результата:

| № | Сегмент | Мотивация (источник) | Формат | Картинка | Заголовок | Текст | Ход |
|---|---|---|---|---|---|---|---|

Десять крючков на десять разных клеток лучше тридцати вариантов одной.

**Правило без повторов:** картинка и заголовок делят работу. Заголовок не подписывает картинку, а говорит то,
чего на ней нет. Картинке — образ и чувство, тексту — факт (методология, раздел 4).

## 2. Ходы для начала объявления

Перебирать по кругу, не застревать на любимых.

| Ход | Форма | Осторожно |
|---|---|---|
| Вопрос читателя | его вопрос дословно — как он ищет или спрашивает | только формулировки из корпуса и поиска |
| Ситуация из жизни | узнаваемый момент: «Третий месяц смотрите вакансии…» | общая ситуация невидима; не навязывать контекст |
| Результат за срок | «Новая профессия за 2 месяца» | срок и результат — из фактов продукта |
| Было → стало | два состояния в одной фразе | переход честный, без «из нищеты в богатство» |
| Доказательство первым | число, документ, реестр, демонстрация | доказательство само себя хвалит, без эпитетов |
| Любопытство | что-то недоговорено: «Кто решает, по какой цене поедет фура» | ответ — в тексте объявления, иначе обман |
| Выбор | два варианта, которые читатель реально взвешивает | оба варианта настоящие |
| Против общего мнения | «Чтобы стать логистом, не нужен профильный вуз» | только про то, во что аудитория действительно верит; ответ — в тексте |
| Признание | «Мы тоже думали, что…» | без живых деталей звучит фальшиво; не выдумывать историю |

Ходы «выбор», «было → стало», «против общего мнения» — одна семья, **сравнение**: человек понимает вещь через
другую. Хорошее сравнение — двух вещей, которые читатель взвешивает. Плохое — отрицание того, чего никто не
говорил («Это не просто курс — это…»): так пишет модель.

## 3. Пять типов крючков — по два на тип

Источник — hook-battery (RMBC), переложено:

| Тип | Что делает | Граница |
|---|---|---|
| Любопытство | открывает пробел в знании | конкретное обещание, а не туман |
| Цена бездействия | показывает реальную цену, о которой человек не думал | только реальная цена; запугивание — нельзя |
| Желание | рисует результат так, что человек узнаёт себя | хотя бы одна конкретика: число, срок, предмет |
| Доказательство | опирается на реальный факт, реестр, данные | только реальное; отзывы и истории не выдумываются |
| Против общего мнения | спорит с советом, который аудитория слышала | совет должен быть реальным |

## 4. Формулы заголовков

Отправная точка, не шаблон: каждую ячейку заполнить фактом и прогнать через проверки раздела 5.

| Фокус | Формула | Пример (курс профессии) |
|---|---|---|
| Результат | {результат} за {срок} | Новая профессия за 2 месяца |
| Результат | {результат} без {помехи} | Профессия логиста без профильного вуза |
| Результат | {результат} через {механизм} | Опыт логиста — на реальных перевозках |
| Задача | {вопрос о главной трудности}? | Везде просят опыт — где его взять? |
| Аудитория | {продукт} для {кого} | Курс логиста для начинающих с нуля |
| Аудитория | Чтобы {результат}, не нужно {навык} | Чтобы начать в логистике, не нужен опыт |
| Доказательство | {факт, который проверит читатель} | Сведения о дипломе — в госреестре |
| Отличие | {категория}, в которой {отличие} | Курс, где практика — в транспортной компании |

Не брать: «Больше никогда не…» (обещание), «Наконец-то…», «Откройте для себя», «Представьте…».

## 5. Проверки каждого крючка

1. **Конкретика:** есть число, срок, предмет или название. «Улучшите жизнь» — нет.
2. **Чужой продукт:** подошёл бы конкуренту — переписать.
3. **Где читатель сейчас:** крючок про его положение (что пробовал, что не получается), а не про продукт.
4. **Ощущения:** хотя бы треть вариантов — то, что человек видит или делает руками (экран с заказом, звонок
   перевозчику), а не абстракция («карьерный рост»).
5. **Телефон:** читается в 1–2 строки на экране телефона.
6. **Мост:** следующая фраза продолжает обещание крючка, а не уходит в рассказ о компании. Сменил крючок —
   перепиши и текст под ним.
7. **Скрипт:** `scripts/stopwords_check.py --text … --limit …`.

## 6. Признаки текста от модели — не писать

| Признак | Пример | Вместо |
|---|---|---|
| Ложное противопоставление | «Это не просто курс — это новая жизнь» | сказать, что именно получит человек |
| Перечень отрицаний | «Без воды, без скуки, без теории» | что есть, а не чего нет |
| Вопрос — сразу ответ | «Результат? Работа мечты» | утверждение с фактом |
| Двоеточие-разгадка | «Секрет прост: практика» | обычная фраза |
| Тройки по привычке | «быстро, удобно, надёжно» | одно точное слово с доказательством |
| Зачин эпохи | «В современном мире…» | начать с задачи читателя |
| «Представьте…» | «Представьте, что вы…» | показать реальное «было → стало» |
| Расчистка горла | «Давайте честно», «Вот в чём дело» | убрать |
| Псевдоглубокая концовка | «Ведь будущее начинается сегодня» | закончить конкретикой или призывом |
| Восклицания и эмодзи как структура | «Готовы?!», ✅ в начале пунктов | точка; список без значков |

В русском тексте тире — норма пунктуации, а не признак модели (в отличие от английского).

## 7. После запуска

Воронка: показ → остановка → клик → заявка → оплата. Каждый провал чинят на своём шаге:

| Слабое место | Что чинить |
|---|---|
| не останавливаются, низкий CTR | картинку и крючок |
| кликают, но не оставляют заявку | мост к странице: обещание объявления не совпало со страницей или формой |
| заявки есть, оплат нет | оффер и разговор менеджера, не объявление |

Одна переменная за цикл. Дешёвый вариант (картинка с фразой) — для проверки угла; дорогое производство (съёмка,
видео) — только для угла, который уже дал сигнал.
