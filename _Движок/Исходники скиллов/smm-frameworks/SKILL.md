# smm-frameworks — рамка под задачу

Навык — маршрут. Сами рамки, вердикты и поправки — в каноне, их читать на ходу:

| Файл | Зачем | Когда |
|---|---|---|
| `D:\Knowledge-OS\Методологии\Справочник — Каталог фреймворков SMM- контент, реклама, прогрев, воронки.md` | 72 рамки: для чего, суть, вердикт, вход; правила применения; каркас промта | всегда, целиком |
| `D:\Knowledge-OS\Методологии\Справочник — Карта маркетинга (что чем закрыто).md` | чей это шаг и кто хозяин | если задача шире одной единицы контента |
| паспорт проекта `CLAUDE.md` | факты продукта, запреты, документ тона | всегда, до первого слова |

## Порядок

### 0. Задача и шаг

Одной-двумя строками: что нужно получить, для кого, где человек это увидит, что он должен сделать после.
Задача — стратегия, выбор площадок, бюджет — сначала хозяин из карты (`marketing`, «Свои площадки»,
`Методологии\Платный трафик\Методология — Медиапланирование.md`). Каталог работает внутри шага, а не вместо него. Не ясно — допущение первой строкой.

### 1. Выбор рамки

- По графе «Для чего» каталога. Одна рамка на задачу; вторая — только если одна задаёт структуру единицы
  (PAS, Before–After–Bridge), а другая — порядок серии (Curiosity Ladder, Product Launch Formula).
- Вердикт **есть в каноне** — работать по документу канона, не по рамке (все пути — от `D:\Knowledge-OS\Методологии\`):

  | Рамки | Документ канона |
  |---|---|
  | AARRR | `Справочник — Классические фреймворки маркетинга и роста.md`, раздел AARRR |
  | TOFU–MOFU–BOFU, Cold–Warm–Hot, Trust Accumulation, One Message — One Audience | `Методология — Лестница Ханта (лестница узнавания).md` |
  | Content Strategy Triangle, Orbit Media 7 steps | `Методология — Свои площадки- соцсети, короткое видео, репутация.md`, разделы 1–2 |
  | Content Funnel, Smart Content, Toptal 4-step, Content Pillars | там же, раздел 3 «Матрица тем» |
  | Creative Matrix | `D:\Knowledge-OS\_Движок\Исходники скиллов\text-editor\references\ad-combinatorics.md` |
  | Intent-Based Marketing | навыки `ads-vk` (ключевые фразы), `ads-direct` (поиск) |
  | 3 R's of Influence | `Платный трафик\Справочник — Разбор площадки блогера перед интеграцией.md` |
  | Content Feedback Loop | `Движок роста\_manifest.md` — цикл улучшений |
- Вердикт **с оговоркой** — поправку из каталога выписать в вводные до работы.
- Вердикт **не сейчас** — сказать человеку, почему, и предложить рамку из «берём».
- Назвать выбор одной строкой: рамка, почему она, что отброшено.

Частые задачи:

| Задача | Рамки |
|---|---|
| серия постов или писем перед эфиром, запуском, покупкой | Teaching Warm-Up, Curiosity Ladder, Before–After–Bridge; запуск потока — Product Launch Formula |
| рубрики и план канала | Hero–Hub–Help; столпы — матрица тем «Своих площадок» |
| из одного эфира — много материалов | GaryVee Pyramid |
| много разных объявлений для теста | `text-editor`, ad-combinatorics; плюс Thumbstopper для первого кадра |
| проверить готовые объявления | Message–Market–Match |
| ретаргетинг тех, кто не оставил заявку | Retargeting by Objection |
| креативы перестали работать | Creative Fatigue Cycle |
| лид-магнит, форма, конкурс — сколько просить | Effort–Reward Balance, Micro-Commitment Ladder |
| история основателя, преподавателя, клиента | Hook–Story–Offer, In Medias Res, Hero's Journey, Proof of Struggle |
| подача тарифов | Choice Architecture |
| интеграция у блогера | Expectation Alignment (бриф), Context–Credibility–Conversion (структура) |
| проверить, не выгорели ли смыслы | Meaning Decay Audit |

### 2. Вводные — из проекта, не из головы

Собрать блоком до работы:

1. **Сегмент и его работа** — исследование проекта. «Женщины 25–45» — не сегмент.
2. **Ступень** — что человек уже знает (лестница Ханта).
3. **Факты продукта** — документ тона или справочник продукта из паспорта: цена, сроки, состав, документы,
   условия. Копией, не пересказом.
4. **Запреты проекта** — паспорт проекта и правила кода его сборщиков.
5. **Площадка** — лимиты и запреты из навыка `ads-*` или «Своих площадок».
6. **Реальный материал** — возражения из записей разговоров, истории людей с их согласием, живая страница.

Чего нет и нельзя найти — интервью: не больше 10 вопросов, по одному. Нельзя спросить — пометка
«[нужен факт]» в результате.

### 3. Работа

- Пройти шаги рамки по графе «Суть» каталога, по одной единице на шаг.
- Форма результата — таблица. Для серии: № · ступень · тема · тезисы · цель (какой реакции ждём) · метрика
  перехода · факт-источник. Для креативов: сегмент · ситуация · угол · формат · текст · первый кадр.
- Первый результат большой задачи — промежуточный: каждый раздел детализировать отдельно.

### 4. Проверка — все пункты до показа

1. **Факты.** Каждое число, срок, условие, документ и обещание — с источником из вводных. Нет источника —
   убрать или «[нужен факт]».
2. **Выдумка.** Нет выдуманных людей, отзывов, кейсов, блогеров, цифр охвата.
3. **Закон.** Срочность и дефицит — только реальные. Нет превосходных степеней без подтверждения. Сравнение
   с конкурентами — только корректное: проверяемые критерии, без порочащих оценок (на ступени 3 Ханта
   сравнение и нужно). Блогер или посев — маркировка.
4. **Поправки каталога** для выбранной рамки соблюдены.
5. **Запреты проекта** соблюдены. Если у проекта есть проверка кодом (стоп-слова, запретные офферы) —
   прогнать её.
6. **Текст для людей** — через `text-editor` и его скрипт стоп-слов.
7. **Результат меняет работу** (новая цепочка, объявления, подача тарифов) — оформить гипотезой: метрика,
   защитная метрика, порог шума (`growth-hypotheses` или стандарт гипотез).

### 5. Куда положить

В действующий документ проекта, где эта работа уже живёт: спецификация теста, контент-план, файл объявлений.
Новый документ — только если результату негде жить.

## Промт для другой модели

Когда человек хочет запустить рамку сам в другом чате — отдать каркас из каталога («Правила применения»,
пункт 5) с заполненными вводными. Персональные данные в промт не класть. Предупредить: ответ другой модели
проходит ту же проверку, раздел 4.

## Чего навык не делает

- Не выбирает площадки и бюджет — `marketing`, «Методология — Медиапланирование».
- Не публикует, не запускает рекламу и не тратит деньги — после «да» владельца.
- Не выносит вердикт по блогеру — разбор площадки блогера.
- Не правит каталог и свой файл молча: наблюдение → предложение → решение владельца.
