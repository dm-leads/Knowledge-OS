# Topvisor — история позиций (только чтение)

Topvisor хранит позицию каждого запроса проекта за все даты, когда запускалась проверка. Чтение истории бесплатно и
не зависит от подписки; запуск проверки платный. Клиент — `scripts/topvisor.py`; ключи `Topvisor_API_KEY`,
`Topvisor_User_Id`, `Topvisor_ID_Project` — в мастер-.env, значения не печатаются. Оценка инструмента — в каноне:
`Экосистема инструментов/03 — Ресурсы/Оценки инструментов/Справочник — Оценка Topvisor.md`.

```
python scripts/topvisor.py project                                        # сайт, поисковики и регионы с номерами
python scripts/topvisor.py history --queries запросы.csv --out <папка>     # ряд позиций: строка на запрос и дату съёма
python scripts/topvisor.py history --queries пилот.csv --queries контроль.csv --from 2025-07-01 --to 2026-10-04 --region-index 1 --out <папка>
```

`запросы.csv` — колонка «запрос», разделитель «;». Каждый вызов кладёт сырой ответ и плоский csv в
`<папка>/<дата>/` и строку в `<папка>/manifest.jsonl`.

## Правила

1. **Только чтение.** Клиент ходит в методы `get/…`; всё остальное отсекается в коде. Проверку позиций и расписание
   запускает человек в интерфейсе Topvisor — там видна цена. Не предлагать «запущу проверку сам».
2. **Только проект сайта.** В аккаунте могут лежать чужие проекты: клиент работает с проектом из
   `Topvisor_ID_Project` и остальные не показывает.
3. **Три состояния.** В плоском csv: `found=1` и число — позиция; `found=0` — проверка была, сайт не найден; строки
   нет — проверки в эту дату не было. Пустое и «не найден» в ноль не сводить.
4. **Ряд нерегулярный.** Сначала смотреть даты съёмов (клиент печатает первую, последнюю и число дат) и сколько
   запросов проверено в каждую: в дату могли проверять одну группу.
5. **Контроль — тем же прибором и в те же даты.** Если контрольных запросов в съёмах нет, честный ответ — «контроля
   этим прибором нет», а не сравнение с другим трекером.
6. **Уровни разных трекеров не сшиваются** (Topvisor, Keys.so, кабинеты сервисов): сравнивать изменения внутри
   одного прибора.
7. **«До» — это дата.** Подпись «перед запуском» проверять по дате съёма: последняя проверка могла быть за недели
   до события.

## Что сказать в ответе

- За какие даты есть съёмы и по скольким запросам; каких запросов в проекте нет.
- Позицию «до» и «после» с датами съёмов, изменение и число запросов, по которым оно посчитано.
- Есть ли контроль тем же прибором; если нет — так и сказать.
