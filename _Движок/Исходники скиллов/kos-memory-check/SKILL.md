# kos-memory-check — брифинг по памяти контура

Дёшево → дорого. Переходить к следующему тиру, только если предыдущий показал необходимость.

## Тиры

- **Tier 0:** `git log --oneline -10` (если контур в git).
- **Tier 1:** `_manifest.md` + последние записи `CHANGELOG.md`.
- **Tier 2:** + релевантные ADR (`0 — System Docs\ADR-log\`) + `BACKLOG.md`.
- **Tier 3:** + соседние контуры (Glob → Grep → Read).

## Шаги

1. Найти контур и `0 — System Docs\`. **Нет System Docs → memory-check завершён** (контур новый).
2. Прочитать по нужному тиру.
3. Краткий брифинг (~10–15 строк): суть манифеста, последние изменения, релевантный backlog, ограничения
   из ADR. **Не пересказывать файлы целиком** — только влияние на текущую задачу. В файл не сохранять.
