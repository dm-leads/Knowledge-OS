# Keys.so API — сжатый справочник методов

Источник: openapi.json v1.0.17 (сервер https://api.keys.so). Собран автоматически; полное описание — в openapi.json рядом.


## Дашборд

### `GET /report/simple/domain_dashboard`
Пример запроса: `https://api.keys.so/report/simple/domain_dashboard?base=msk&domain=wildberries.ru`
Параметры: `base` [msk, gru, zen, gkv, rnd, ekb, ufa, sar…]; `domain`*
Ответ: id, name, dr, iconUrl, parentid, parentName, childsCount, it1, it3, it5, it10, it50, restop5, topvis

### `GET /report/simple/domain_dashboard/ai-answers`
Пример запроса: `https://api.keys.so/report/simple/domain_dashboard/ai-answers?base=msk&domain=wildberries.ru&limit=10` **Важно:** Отчёт доступен только для базы данных `msk` (Яндекс). Метод возвращает первые ИИ-ответы домена для отображения на дашборде.
Параметры: `base` [msk, gru, zen, gkv, rnd, ekb, ufa, sar…]; `domain`*; `limit`
Ответ: query_text, query_answer

### `GET /report/simple/domain_dashboard/ai-concurents`
Пример запроса: `https://api.keys.so/report/simple/domain_dashboard/ai-concurents?base=msk&domain=wildberries.ru&limit=10` **Важно:** Отчёт доступен только для базы данных `msk` (Яндекс). Перед построением дэшборда нужно вызвать метод построения отчёта по конкурентам. Метод возвращает первых конкурентов по ИИ-ответам домена для отображения на дашборде.
Параметры: `base` [msk, gru, zen, gkv, rnd, ekb, ufa, sar…]; `domain`*; `limit`
Ответ: id, name, cnt, queries_in_ai_answers

### `GET /report/simple/keyword_dashboard`
Пример запроса: `https://api.keys.so/report/simple/keyword_dashboard?keyword=%D0%9F%D0%BB%D0%B0%D1%81%D1%82%D0%B8%D0%BA%D0%BE%D0%B2%D1%8B%D0%B5%20%D0%BE%D0%BA%D0%BD%D0%B0&base=msk`
