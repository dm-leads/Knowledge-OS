# Проверки перед сдачей

## Карточка и KPI

- [ ] Есть задача, ценный конечный продукт, главный показатель с формулой и источником.
- [ ] Результаты — с числом и датой, ответ «сделал / не сделал»; обязательные и амбициозные разделены; у объёма есть
      парный показатель качества.
- [ ] Результаты испытательного срока записаны до выхода и стоят в оффере.
- [ ] Числа результатов — из данных проекта с периодом и источником; тезисы источников помечены (методология, 14).
- [ ] Карточка сверена с карточками руководителя и соседей.

## Закон (вопросы к юристу на дату, не разрешения)

- [ ] В требованиях, вакансии, заметках и бланках нет возраста, пола, внешности, фото, семьи, детей, прописки
      (методология, 4.1; сверка, п. 1).
- [ ] Рабочая проба — учебная, результат не используется; стажировка и всё, похожее на работу, — оформлены и
      оплачены с первого дня (сверка, п. 3).
- [ ] Испытательный срок — не больше разрешённого для роли; РОПу и HR 6 месяцев автоматически не положены
      (сверка, п. 4).
- [ ] Рекомендации — с согласием кандидата; без звонков «в обход» (сверка, п. 6).
- [ ] Тесты — только дополнительный сигнал; нет проективных тестов и «диагнозов» (сверка, п. 7).
- [ ] Премия — виды, размер, условия, сроки определены; нет вычетов и штрафов (сверка, п. 9).
- [ ] Данные кандидатов — основание, срок, место хранения; наружу только агрегат (методология, 11).
- [ ] Отказ кандидату — честной формулировкой по деловым причинам, без выдуманных требований.
- [ ] Испытание записано в договоре до начала работы; есть контрольная дата решения до его окончания с запасом на
      предупреждение за три дня; учтены те, кому испытание не устанавливают (с 01.09.2026 — в том числе женщины с
      детьми до трёх лет) (методология, 8.2, 9.1; сверка, п. 4).
- [ ] Стажировка оплачена; оклад из-за испытания не снижен (методология, 9.1; сверка, п. 4, 9).
- [ ] Запись интервью, тесты, резерв — отдельные цели с основанием; автоматический отказ по баллу — только с
      письменным согласием (методология, 11; сверка, п. 5, 7).
- [ ] Сообщения кандидатам — личные, не массовая рассылка; хантинг — без чужих баз и коммерческих тайн
      (сверка, п. 11).
- [ ] Оффер не обещает того, что компания не выполнит; отзыв оффера не прикрывает дискриминацию (сверка, п. 8).
- [ ] Сведения о вакансии в службу занятости и квота — вопрос юристу задан (методология, 5.3; сверка, п. 10).
- [ ] В чате и сводках — «кандидат А / Б», без имён; резюме и заметки — только в проекте.

## Канон и источники

- [ ] Нет ложной срочности, выдуманных чисел воронки и обещаний дохода, которого нет на деле.
- [ ] Качества записаны как поведение, у каждого — способ проверки.
- [ ] Глубина отбора соответствует роли (методология, 4.4).
- [ ] Противоречия источников решены по таблице раздела 13.

## Сдача

- [ ] Заполнен шаблон `role-card.md` в нужных режиму разделах.
- [ ] Список «[нужен факт]» и вопросы к юристу — отдельно.
- [ ] Тексты (вакансия, оффер, письма) помечены черновиком для `text-editor`.
- [ ] Три даты (контрольная дата испытания, сотый день, год) записаны в `TASKS.md` или журнал действий проекта;
      указан путь к учёту найма проекта.
- [ ] В журнал навыка — только обезличенный урок и агрегат.
