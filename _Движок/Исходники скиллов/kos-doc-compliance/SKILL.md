# kos-doc-compliance — привести документ/папку к канону Knowledge-OS

Канон: `D:\Knowledge-OS\_Движок\Канон\`.

## Что проверяем

- **Frontmatter:** все обязательные поля ([Стандарт — Конвенция метаданных]); значения `status` и
  `review_cycle`; **пустая строка** перед закрывающим `---`.
- **Имя файла:** `<Префикс типа> — <Название>.md` по словарю префиксов.
- **Ссылки:** `[[wiki]]` → markdown; битые относительные ссылки; запрет якорей `#L42` и `cursor://`.
- **Футер** «Связанные документы» (3–7) для содержательных типов (policy/standard/workflow/methodology/
  guide/reference/runbook/playbook).
- **Краткая суть** в длинных содержательных документах.

## Режим

1. Область: файл / папка / весь проект.
2. Прогнать проверки; починить детерминированное (имена, frontmatter, wiki-ссылки, футер).
3. Доложить, что осталось ручного (битые ссылки без явной цели, спорный тип/placement).
