# Шаблон выхода finance-check

Заполняется в проекте; цифры компании — только там. Каждое число: значение — период — источник — статус (факт /
оценка / нет данных).

## Общая шапка

- Компания (код проекта), форма и режим налогообложения, плательщик ли НДС; кто бухгалтер.
- Период и дата отчётов; база выручки (отгрузка) и поступлений (оплата).
- Сходимость: баланс сходится / расхождение N и где найдено; проверки ДДС пройдены.

## А. Разбор

1. **Вывод одной фразой** — «стабильно / риски: …».
2. **Где деньги** — таблица: прибыль периода → приросты активов (запасы, дебиторка, оборудование) и уменьшения
   обязательств → прирост денег.
3. **Шесть шагов разбора** — коротко по каждому.
4. **Коэффициенты** — таблица: показатель — формула — значение по периодам — целевой уровень компании — порог курса
   (тезис).
5. **Проблемы → решения** — проблема — о чём сигнализирует — решение — число — срок — ответственный.

## Б. Учёт с нуля

1. Порядок внедрения с датами (ДДС → взаиморасчёты → ОПиУ → баланс).
2. Справочник статей ДДС и ОПиУ с описанием; кошельки.
3. Учёты взаиморасчётов: какой учёт питает какую строку.
4. Вступительный баланс на дату.
5. Регламенты: кто ведёт, кто заполняет, срок, проверка, резервная копия.

## В. Модель и бюджет

1. Вводные и их источники; интервью собственника.
2. Модель по месяцам: выручка, ОПиУ, оборотный капитал, ДДС, баланс; строка проверки = 0.
3. Сценарии (минимум, реалистичный, максимум); чувствительность.
4. Кассовые разрывы — даты и решения.
5. План-факт и хозяева статей; бюджетный процесс (если внедряем).

## Г. Проверка выплаты

| Проверка | Значение | Итог |
|---|---|---|
| накопленная чистая прибыль | | |
| капитал больше нуля | | |
| прогноз ДДС на дату выплаты после обязательных платежей и резерва | | |
| запреты ст. 29 закона об ООО (вопрос бухгалтеру и юристу) | | |
| **Можно выплатить** | сумма, дата | да / нет — почему |

## Хвост

- «[нужен факт: …]» — список.
- Вопросы бухгалтеру и юристу.
- Следующая дата разбора (не реже квартала — тезис курса).
