# image-edit — бесшовное редактирование картинок через Gemini

Для правок растровых изображений (поменять цифру/текст в плашке, убрать/добавить объект, поправить деталь)
**используй генеративный редактор Gemini**, а НЕ ручную заплатку в Pillow. Ручной путь (вырезать текст →
залить градиент → нарисовать новый) оставляет видимый шов и выглядит плохо — проверено, тупик.

## Когда что

- **Есть исходник макета** (Figma/Canva/PSD) → правь ИСХОДНИК, это пиксель-идеально. Спроси у Дмитрия.
- **Только готовый JPG/PNG** → Gemini image edit (ниже). Бесшовно.

Ещё фразы: «edit this image/banner», «change the number in this image», «seamless image edit».

## Перед запуском (обязательно)

- Это **платный внешний вызов** (~$0.067 за картинку 1K, тарифы Google на 28.09.2026; перед крупной партией
  цену снять со страницы тарифов заново) и **картинка уходит в Google** → сказать стоимость и получить «да» (особенно для чувствительного/ПДн — тогда нельзя).
- Это **полный ре-рендер**: модель перерисовывает всю картинку, не вырезает кусочек. После — **сверить**, не «поплыло» ли что-то ещё; и **размер может измениться** (модель отдаёт крупнее / чуть иную пропорцию) — при необходимости подогнать под исходные размеры.
- Ключ: `GOOGLE_AI_STUDIO_API_KEY` — «Секретные ключи/.env» проекта, иначе файл секретов устройства (путь — `~/.claude/kos/secrets-env.txt`); в чат не печатать. Предпочитать его, не OpenRouter (личные деньги).

## Рабочий рецепт (проверен 2026-08-12, модель сменена 2026-09-28)

Модель `gemini-3.1-flash-image` (Nano Banana 2), endpoint `:generateContent`. Прежняя `gemini-2.5-flash-image`
отключается Google 02.10.2026. Проба 28.09: правка «до 20%» → «до 15%» на плашке с градиентом — бесшовно, шрифт и
фон не поплыли; разрешение 1024×512 → 1440×720 (пропорция сохранилась). Дешевле — `gemini-3.1-flash-lite-image`
(~$0.034), но бесшовная правка текста на ней не проверена. Промпт: точечно опиши что менять и добавь
«keep everything else identical, same font/size/position, same resolution/aspect». Явно перечисли, что НЕ трогать.

```python
import base64, json, urllib.request, re
from pathlib import Path
import os
cands=[Path(p) for p in [os.environ.get('KOS_ENV','')] if p]
cands+=[d/'Секретные ключи'/'.env' for d in (Path.cwd(),*Path.cwd().parents)]  # ключ проекта
ptr=Path.home()/'.claude'/'kos'/'secrets-env.txt'                                 # файл устройства
if ptr.is_file(): cands+=[Path(os.path.expanduser(l.strip())) for l in ptr.read_text(encoding='utf-8').splitlines() if l.strip() and not l.startswith('#')][:1]
key=None
for env in cands:
    if not env.is_file(): continue
    for line in open(env,encoding='utf-8',errors='ignore'):
        m=re.match(r'\s*GOOGLE_AI_STUDIO_API_KEY\s*=\s*(.+)\s*$',line)
        if m: key=m.group(1).strip().strip('"').strip("'"); break
    if key: break
b64=base64.b64encode(open(SRC,'rb').read()).decode()
prompt=("Edit this image. <ЧТО ИМЕННО поменять и где>. Keep the exact same font, weight, color, size, "
"position, background/gradient, and absolutely everything else identical. Do NOT change <ЧТО НЕ ТРОГАТЬ>. "
"Return the full edited image at the same resolution and aspect ratio.")
payload={"contents":[{"parts":[{"inline_data":{"mime_type":"image/jpeg","data":b64}},{"text":prompt}]}],
         "generationConfig":{"responseModalities":["IMAGE"]}}
url=f"https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-image:generateContent?key={key}"
req=urllib.request.Request(url,data=json.dumps(payload).encode(),headers={"Content-Type":"application/json"})
resp=json.load(urllib.request.urlopen(req,timeout=180))
for p in resp.get('candidates',[{}])[0].get('content',{}).get('parts',[]):
    d=p.get('inlineData') or p.get('inline_data')
    if d and d.get('data'): open(OUT,'wb').write(base64.b64decode(d['data']))
```

- На ошибку `urllib.error.HTTPError` — распечатать `e.code` и тело (без ключа) для диагностики.
- Несколько картинок — делать по одной, первую проверить глазами, потом остальные.
- Сохранять в НОВЫЙ файл (`*__ai.jpg`), оригинал не перезаписывать без спроса.

## Уроки генерации и правки (обобщено из работы с обложками статей, 08.2026)

- **Одна правка за проход,** каждый проход — в новый файл. Две просьбы в одном промпте: часть модель игнорирует.
- **Модель рисует самый частый в обучении класс объекта:** узкий прибор словами не описать — выйдет похожий
  массовый (вместо приточного прибора — кондиционер). Геометрия монтажа (толщина стены, отверстие, оснастка)
  тоже врёт. Где кадр служит **доказательством** («так выглядит у вас дома», «так монтируют»), нужно только
  реальное фото; генерация — для иллюстрации.
- **Расширение кадра (например, вертикаль → 16:9):** просьба «дорисуй только пустое поле» не соблюдается —
  всегда полный ре-рендер. Генерация — только источник фона: реальный кадр вставить в холст нужных пропорций
  (реальная часть ≈ 60 % ширины), дорисовать поле, затем **вернуть реальные пиксели поверх** один в один и
  выровнять тон вдоль шва (генерация обычно светлее), растушевать полосу. Если расширяемая зона — ровная стена,
  нейросеть не нужна: достроить поле синтезом из статистики краевой полосы, без зеркалирования.
- **Уборка лишнего — на полном кадре, кроп — потом.** Кроп — по координатам нужного объекта, с проверкой в
  коде, что объект внутри кадра.
- **Проверка качества склейки меряет то, от чего зависит результат** (совпадение фона в полосе шва), а не
  «всё подряд», иначе она останавливает исправную работу.
- Технически чистая достройка ещё не хорошая картинка: пустое поле в треть кадра читается как недоделка.
