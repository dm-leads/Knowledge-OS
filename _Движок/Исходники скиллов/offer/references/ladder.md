# Лестница предложений — как выбрать и посчитать следующую ступень

Механизмы, условия и опасные места — методология офферов, раздел 3.2 (таблица). Перевод в строку — раздел 4. Здесь —
порядок.

## 1. Что уже есть

Выписать текущие офферы проекта по четырём типам: привлекающий, допродажа, понижающий, подписка. Пустой тип — не
повод его строить: сначала узкое место.

## 2. Узкое место

Из Движка роста (шаг 2), если он стоит; иначе — строка `unit-economics` по сегментам. Развилка:

| Что видно в строке | Тип ступени |
|---|---|
| CPUser высокий, AMPU не дотягивает при нормальной конверсии | привлекающий вход, сегмент выше по рынку |
| много заявок, мало покупателей | понижающий (рассрочка, урезанный набор), доказательства, работа продаж |
| покупатели есть, AMPPU мал | допродажа, якорь, цена — но сначала маржа |
| покупка разовая, работа клиента продолжается | подписка или перенос |
| деньги приходят поздно | условия оплаты, предоплата — посчитанная |

## 3. Кандидат

Ступень решает проблему, которую вскрыла предыдущая покупка. Кандидаты — из графа работ клиента (следующая работа) и
из звонков: что клиенты спрашивают после покупки. «Сто способов предложить один продукт» — сначала оси имеющегося
(объём, частота, «сами / вместе / за вас», срок, оплата), потом партнёрский продукт за комиссию (кто отвечает перед
клиентом, качество исполнения), потом новый свой продукт.

## 4. Строка

Строка гипотезы в листе `unit-economics`:

- допродажа — ΔAMPPU = AMPPU после − AMPPU до; «доля × цена × маржа» — только без замещения и зачётов;
- понижающий — ветви «основное / понижение / не купили» на общей базе Users, итог против базовой строки;
- привлекающий — C1 и COGS_1st входа, затем доля перешедших в основное;
- рассрочка — недоплаты; проверка: доля полной оплаты не упала;
- подписка — повторы когорты напрямую, без формулы оттока.

Проверки: AMPU₃₀ > CPUser (экономика окна), AMPU ≥ 3 × CPUser по когорте; деньги во времени — от месяца расхода, с
циклом сделки, рассрочкой и возвратами (методология, раздел 4). Эффект меньше шума — не тестируем, ищем ступень крупнее.

## 5. Запуск

Одна ступень; срок замера — квартал или цикл сделки; что считаем успехом — заранее, числом. Следующая ступень — после
того, как эта работает надёжно.
