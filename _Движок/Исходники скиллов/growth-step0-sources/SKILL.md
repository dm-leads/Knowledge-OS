# Шаг 0 — обнаружение источников и готовность инстанса

Цикл не начинается без карты источников и зелёного гейта. Этот шаг ничего не считает сам: он запускает команды движка и
пересказывает их строки.

## Правила шага

- **Число берётся только из строки команды.** У строки есть период, знаменатель, источник, дата съёма и статус
  (`факт` / `оценка` / `proxy` / `нет данных`). Своих чисел не добавлять, чужие не пересчитывать.
- **Деньги не считаются в ответе.** Денежные величины приходят только из модели — командами движка.
- **Персональные данные не печатаются**, секреты — только именами переменных окружения.
- **`нет данных` — это не ноль.** Так и говорить: данных нет.
- **Перечисление переносится перечислением.** Считать его элементы своим числом нельзя: «классы A, B,
  C, D, E, F» остаётся перечислением, а не превращается в «шесть классов». Не пересчитывать и не обобщать чужие строки.
- **Код возврата подтверждается строкой журнала.** Команды его не печатают, поэтому он сохраняется вместе с выводом
  (в оболочке — дописать к команде вывод строки `КОД ВОЗВРАТА: <код>`); без такой строки код возврата — слово агента,
  а не факт.
- **Строку числа переносить в ответ целиком и дословно**, как её напечатала команда.
- Шаг только читает. Записи в источники и в хранилище на этом шаге нет.

## Что запускать

Из папки `Скрипты/` инстанса. Путь к конфигурации и файлу секретов — из конфигурации проекта; имена переменных секретов
описаны в карте источников.

1. **Гейт инстанса** — одна команда со всеми проверками:
   `py -3 -m growth_engine.health --config <конфигурация> --secrets <файл секретов>`
   Код 0 — можно начинать цикл. Любая строка 🟥 или 🟧 — сначала разобрать её, потом цикл: у каждой строки есть
   раздел и номер стража, и чинится она по своему разделу, а не одним универсальным средством.
2. **Пробы источников** (если нужен разбор отдельного источника):
   `py -3 -m growth_engine.probes --config <конфигурация> --secrets <файл секретов>`
   Пропущенная платная проба — нормальный итог шага, а не помеха. Перед ключом платных проб назвать владельцу бюджета
   стоимость вызова и дождаться явного «да»; без ответа оставить пробу пропущенной.
3. **Карта источников на лист** — сухой прогон, без записи:
   `py -3 -m growth_engine.sources_sheet --config <конфигурация> --source-map <карта источников> --secrets <файл секретов> --dry-run`

## Что сказать в ответе

- Итог гейта: код возврата строкой журнала и каждая строка 🟥 или 🟧 — дословно, с номером стража.
- Классы источников — перечислением из строки карты источников, без счёта их числа.
- Если гейт не пройден — что именно мешает начать цикл и какая команда это чинит. Не «почти готово», а перечень строк.

## Чего не делать

- Не объявлять инстанс готовым без зелёного гейта.
- Не запускать платные пробы без явного согласия.
- Не записывать карту источников на лист на этом шаге: запись — отдельным решением владельца.
