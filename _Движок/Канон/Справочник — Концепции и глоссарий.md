# Справочник — Концепции и глоссарий

## Краткая суть

Один словарь терминов на весь Knowledge-OS. Если термин встречается в проекте — он значит то, что здесь.
Новые проектные термины-дельты фиксируются в `CLAUDE.md` проекта.

## Глоссарий

- **Knowledge-OS** — переносимый движок знаний (этот репозиторий механики) + проекты, которые им ведутся.
- **Движок (`_Движок`)** — переиспользуемое ядро: канон, шаблоны, сценарии, исходники скиллов. SSOT правил.
- **Канон** — свод правил (типы, имена, метаданные, ссылки, память, SSOT/DRY), по которому живут документы.
- **Контур** — логически цельная единица знаний со своим `_manifest.md`: проект, область, ресурс, инструмент.
- **PARA** — каркас раскладки: Проекты / Области / Ресурсы / (Чувствительные) / Инструменты.
  - **Проект** — временная инициатива с концом.
  - **Область** — постоянное направление, операционка функции.
  - **Ресурс** — переиспользуемый справочник/шаблон/библиотека/бренд.
- **Манифест (`_manifest.md`)** — навигация контура: что здесь, что не здесь, каталог документов.
- **System Docs (`0 — System Docs/`)** — память контура: CHANGELOG, BACKLOG, ADR-log.
- **ADR (decision)** — запись одного решения с контекстом, альтернативами, последствиями.
- **Тип документа** — функция документа из закрытого списка; задаёт префикс имени и `type:` в метаданных.
- **Слаг** — латинский kebab-case-идентификатор контура (для GitLab/URL), неизменяемый; ≠ человекочитаемое имя.
- **Штамповка (`stamp`)** — разворачивание нового проекта из пустого PARA-каркаса (`Каркас`).
- **Канонизация (`canonize` / `migrate-to-canon`)** — приведение чужой/хаотичной папки к канону без потери данных.
- **Бутстрап** — разовая настройка движка/окружения (установка скиллов, проверка CLAUDE.md).
- **CLAUDE.md** — «мозг» для агента: корневой (как устроен OS) и проектный (паспорт проекта).
