# Стандарт — Конвенция именования

## Краткая суть

Одно правило имени на весь Knowledge-OS, применяется одинаково во всех проектах: имя файла =
`<Префикс типа> — <Короткое название>.md`. Префиксы — по **одному русскому словарю** (без разнобоя
EN/RU), машинный `type:` в метаданных — стабильный английский id. Папки именуются по предмету; латиница —
для слагов и корня OS. **Этот документ — SSOT по именам.**

## 1. Имя знаниевого документа

Формула: **`<Префикс типа> — <Короткое название>.md`**

- Разделитель — пробел, длинное тире «—», пробел.
- Название — 2–6 слов, по-русски, понятно без открытия файла.
- Запрещено: `v2`, `финал`, `(2)`, технические суффиксы. Даты — только в снапшотах (`Аналитика — … — 2026-06-28.md`).
- Имя файла — **единственный носитель типа** в файловой системе. Папки тип НЕ обозначают.

## 2. Словарь префиксов (единый, SSOT)

| `type` (id в метаданных) | Префикс файла |
|---|---|
| policy | Политика |
| standard | Стандарт |
| workflow | Процесс |
| runbook | Ранбук |
| playbook | Плейбук |
| instruction | Инструкция |
| methodology | Методология |
| reference | Справочник |
| guide | Гайд |
| bootstrap | Бутстрап |
| template | Шаблон |
| analytics | Аналитика |
| retrospective | Ретроспектива |
| postmortem | Постмортем |
| audit | Аудит |
| research | Исследование |
| specification | Спецификация |
| charter | Устав |
| requirements | Требования |
| log | Журнал |
| artifact | Артефакт |
| decision | — (в `ADR-log/`: `NNNN-kebab.md`, без префикса) |

> Транслитерации **Ранбук / Плейбук / Бутстрап** приняты как канон (решение 2026-06-28). При желании
> заменяются разом здесь (это SSOT).

## 3. Папки

- **По предмету, не по типу.** Папка отвечает «о чём это», а не «какого типа файлы». Запрещены группировки
  `policies/`, `шаблоны/`, `инструкции/`.
- Имя — 2–5 слов, по-русски, самодостаточно.
- **Числовой префикс `NN — Имя`** — только где порядок несёт смысл: top-level PARA
  (`01 — Проекты` … `06 — Инструменты`) и `0 — System Docs/`. Внутри контуров — без номеров.
- В `ADR-log/` файлы нумеруются `NNNN-kebab.md` (номер = max+1, zero-pad 4).

## 4. Слаги и человекочитаемые имена

- Корень OS (`Knowledge-OS`) и слаги контуров — латиница (для GitLab/URL и устойчивости).
- Папки движка и контента — человекочитаемые русские имена (`_Движок`, `Канон`, `Шаблоны`, `Каркас`,
  `Сценарии`, `Исходники скиллов`).
- **Слаг** контура/проекта (для GitLab/URL) — kebab-case, латиница, **неизменяемый**.
- **Человекочитаемое имя** папки — русское, меняется свободно, на слаг не влияет.

## 5. Системные имена (фиксированы)

`_manifest.md` · `0 — System Docs/` · `CHANGELOG.md` · `BACKLOG.md` · `ADR-log/` · `CLAUDE.md` ·
`README.md` (только для кода/инструмента, не для навигации знаний — там `_manifest.md`).
