# Справочник — Карта Knowledge-OS

## Краткая суть

Реестр всех проектов под `D:\Knowledge-OS\`. Заполняется при штамповке/канонизации каждого нового проекта.
Имя локальной папки берётся **отсюда** (а не из произвольных названий).
