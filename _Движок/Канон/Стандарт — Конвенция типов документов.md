# Стандарт — Конвенция типов документов

## Краткая суть

Тип документа берётся из **закрытого списка**. Один документ = один тип = один смысл. Тип определяется
**функцией** документа, а не словом, которым его назвал человек. Новый тип добавляется **только через ADR
движка**.

## Закрытый список

- **Знаниевые (17):** `policy`, `standard`, `workflow`, `runbook`, `playbook`, `instruction`,
  `methodology`, `reference`, `guide`, `bootstrap`, `template`, `analytics`, `retrospective`,
  `postmortem`, `audit`, `research`, `decision`.
- **Системные (3):** `manifest`, `changelog`, `backlog`.
- **Project-extra:** `charter`, `requirements`, `specification`, `log`, `artifact`.
- **Resource-extra:** `course`, `article`, `book`, `video`.

## Что есть что (коротко)

| Тип | Когда |
|---|---|
| policy | Правило «как должно быть», границы дозволенного. |
| standard | Норматив с критериями качества и способом проверки. |
| workflow | Процесс: роли, шаги, передачи, DoD. |
| runbook | Операционка реагирования «если X → делай Y». |
| playbook | Отыгранный сценарий достижения результата. |
| instruction | Пошаговое how-to (сюда же бывшие «чек-листы»). |
| methodology | Принципы и подход «почему так». |
| reference | Справочник для быстрого поиска факта. |
| guide | Вводный обзор/гайд для новичка в теме. |
| bootstrap | Разовая настройка/развёртывание окружения. |
| template | Скелет для нового документа. |
| analytics / retrospective / postmortem / audit | Снапшоты момента — не пересматриваются. |
| research | Исследование с внешними источниками. |
| decision | ADR: одно решение с контекстом, альтернативами, последствиями. |

## Правила выбора

1. **Закрытость.** Не изобретать тип на лету. Нужен новый — ADR движка.
2. **Один тип на документ.** Намешан интент (принципы + процесс + шаги) → **СТОП**, предложить разбить
   на 2–3 документа.
3. **Функция, не слово.** «регламент» → `workflow`/`standard`; «FAQ» → `reference`/`guide`;
   «чек-лист» → `instruction`; «handbook» → выяснить реальную функцию и разложить.
4. Имя файла берёт префикс типа из [Конвенции именования](<Стандарт — Конвенция именования.md>).
