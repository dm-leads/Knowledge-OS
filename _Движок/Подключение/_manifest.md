# Подключение — _manifest

Эта папка — цель ссылки `.kos` в корне каждого подключённого проекта. Её файлы импортируются в `CLAUDE.md`
проектов и грузятся в каждую сессию. Поэтому они короткие, а имена у них латиницей: Claude Code не
импортирует пути с кириллицей (проба 28.09.2026). Это исключение из конвенции именования, закреплено в
[ADR-0004](<../0 — System Docs/ADR-log/0004-connect-any-project-by-link-and-passport-block.md>).

| Файл | Что это | Кто импортирует |
|---|---|---|
| `agent-rules.md` | Правила работы агента — канон: язык, постановка, долгие задачи, субагенты, достоверность, код и данные, git, связь с каноном | блок «Канон Knowledge-OS» в `CLAUDE.md` проекта (`@.kos/agent-rules.md`) |

Править — только здесь. Правка сразу видна во всех подключённых проектах, в новых сессиях.
Подключение проекта — [Плейбук — Подключить проект к канону](<../Сценарии/Плейбук — Подключить проект к канону.md>).
