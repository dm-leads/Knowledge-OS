# Шаблоны Knowledge-OS — _manifest

## Что это

Копируемые скелеты. Каждый файл `Шаблон — <Тип>.md` содержит готовый frontmatter **целевого** типа и
скелет тела: берёшь → переименовываешь по [Конвенции именования](<../Канон/Стандарт — Конвенция именования.md>)
→ заполняешь. Префикс «Шаблон» помечает тулинг; внутренний `type:` — это тип итогового документа.
