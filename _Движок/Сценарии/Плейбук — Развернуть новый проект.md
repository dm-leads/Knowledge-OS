# Плейбук — Развернуть новый проект

> id: `stamp-new-project`. Для нового проекта **с нуля**. Если у тебя уже есть папка с файлами —
> используй [Плейбук — Привести папку к канону](<Плейбук — Привести папку к канону.md>).

## Краткая суть

Скопировать пустой Каркас в новый проект и через короткое интервью заполнить паспорт, чтобы проект сразу
жил по канону.

## Шаги

1. **Интервью.** Спросить: имя проекта (рус, человекочитаемое) + слаг (латиница, kebab-case) + что за
   проект (цель/домен) + направления (будущие области) + нужен ли GitLab.
2. **Копия Каркаса.** `_Движок\Каркас\*` → `D:\Knowledge-OS\<Имя проекта>\`.
3. **Паспорт.** Заполнить `CLAUDE.md` и `_manifest.md` (имя, слаг, описание, направления); поставить первую
   запись в `0 — System Docs\CHANGELOG.md` («Проект развёрнут»).
4. **Стартовые направления.** Под каждое направление создать папку в `02 — Области\<Направление>\` с
   `_manifest.md` из шаблона [Шаблон — Манифест области](<../Шаблоны/Шаблон — Манифест области.md>).
5. **Карта.** Добавить строку проекта в [Справочник — Карта Knowledge-OS](<../Канон/Справочник — Карта Knowledge-OS.md>).
6. **(Опц.) GitLab.** Создать пустой репо в своём GitLab → `06 — Инструменты\mcp.json` по шаблону →
   `опубликуй`.

## Результат

Готовый PARA-проект с паспортом, направлениями и (опц.) облаком. Дальше — наполнение через `create-doc`.
