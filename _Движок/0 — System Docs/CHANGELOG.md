# CHANGELOG — Knowledge-OS

## 2026-10-06 — оценка JEV (TypeSafe AI): карточка, методология о моделях-решателях, черновик навыка `jev`

- Реестр инструментов: `Справочник — Оценка JEV (TypeSafe AI)` — модель, которая вместо текста отвечает «да/нет»,
  «выбор из списка», «оценка по шкале» с вероятностью. Вердикт — только в песочнице: свой клиент на публичных и
  обезличенных данных, официальный плагин не ставим (область `user` по умолчанию), русский язык не заявлен и
  проверяется замером. Строки в матрице и манифесте волта; исходные материалы с описью — в
  `_исходные-заметки/JEV (TypeSafe AI)`.
- `Методологии/Методология — Модели-решатели в конвейере` (черновик): шесть условий, когда брать решатель, порядок
  «от действия к вопросу», порог уверенности по цене ошибки и с замера, проверка на эталоне. Предложение, как
  встроить решатель ступенью в навык `llm-pipeline-economy`, записано в ней; сам навык не менялся — применить после
  первых замеров.
- Навык `Исходники скиллов/jev` (черновик): правила, три шаблона вопросов, клиент `scripts/jev.py` с пробным режимом
  без сети, прогнозом цены до запуска, потолком бюджета, проверкой ответа до записи и сверкой с эталоном; 96 тестов
  без сети. В `~/.claude/skills` не подключён — до замеров на своих данных.
- Зачем: вокруг модели много шума и противоречивых цифр; нужно одно проверенное по документации описание и
  безопасный способ попробовать. Клиент прошёл три круга независимой проверки второй моделью — найденные обходы
  потолка бюджета и утечки ключа закрыты до первого платного вызова.

  гипотезы, роль цвета), правила подачи владельцу, порядок работы и вывод из четырёх фраз.

## 2026-09-28 — growth_engine 1.1.0: дерево цели считается и проверяет покрытие

- Новая команда данных `growth_engine.goal_tree`: снимает цель по веткам из системы цели (раздел `goal_tree`
  конфигурации инстанса: разрез, образцы значений, поток, ветка «остальное», рычаг «конверсия»), проверяет, что ветки
  делят итог без остатка, и пишет на лист снимков помесячные числа веток, цель окна и потолки веток числами модели
  («оценка»). Потолок ветки-потока — лучший месяц ветки в окне истории; рычаг конверсии — прирост при трафике
  последнего месяца. Печатает готовый `--json` для `tree`.
- `tree`: у ветки — причина «гипотез нет» (при записи дерева полем `no_hypotheses` или отдельной операцией);
  показ печатает покрытие и отвечает **кодом 1**, если у ветки нет живой гипотезы и причины или гипотеза реестра
  вне дерева (раньше показ всегда давал 0). Перепривязка гипотезы убирает её из прежней ветки.
- `hypothesis`: идея хранит поданные поля карточки (раньше молча теряла всё, кроме формулировки); новая версия
  до запуска — `--id <номер>.vN` и `supersedes`, прежняя уходит в архив с причиной.
- Адаптер Roistat: разрез `marker_level_2` (второй уровень маркера: поиск по системам, рефералы по донорам).
- Лист «Дерево цели» получает колонку «Почему гипотез нет» сам при первой записи; старые строки читаются.
- Навык `growth-hypotheses`: новая версия идеи и привязка к ветке.
