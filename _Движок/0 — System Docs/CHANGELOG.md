## 2026-09-28 — Знания, волна 1: данные и проверка выводов

Из проверки правил проектов (62 кандидата) подняты самые ценные — общие для любого проекта с данными:

## 2026-09-28 — Принят ADR-0004: любой проект подключается к канону одним запросом

- Правила работы агента впервые лежат в каноне: `_Движок/Подключение/agent-rules.md`. Взяты переносимые правила
  устройства и проверенные уроки проектов, без данных компаний.

- Пробы: импорт с кириллицей в пути и внешний абсолютный импорт не грузятся; через ссылку внутри проекта —
  грузится. Пилот: свежая сессия без доступа к файлам назвала правила и дату сверки.
- [ADR-0004](<ADR-log/0004-connect-any-project-by-link-and-passport-block.md>).

## 2026-06-30 — Канон: стандарт извлечения знаний из обучающих материалов

- Принят **ADR-0002**: обучающие материалы (курсы/транскрипты/таблицы) обрабатываются по единому
  пайплайну, а не ad-hoc по чатам. Причина — три повторяющиеся проблемы: неполное чтение («первые
  строки + домысел»), процесс жил только в чатах (не воспроизводим), дубль-пересказы вместо дельты.
- Добавлен **[Стандарт — Извлечение знаний из обучающих материалов](<../Канон/Стандарт — Извлечение знаний из обучающих материалов.md>)**:
  Ф0 инвентаризация → Ф1 волны + гейт на саб-агентов → Ф2 полное чтение с **реестром покрытия** →
  Ф3 дистилляция с адресами источника → Ф4 сверка (совпадения/противоречия/дельта) → Ф5 применение →
  Ф6 критик. Маршрутизация выходов: сырьё (вне git) / дистилляция / **переносимое ядро в
  `Методологии`** / проектная дельта. Новый тип документа не вводился (`standard` из закрытого списка).
- Ключевой механизм — **реестр покрытия**: источник изучен только при 100% покрытии либо явном списке
  непрочитанного с причиной.
- Скилл автоматизации (`kos-study-source`) намеренно отложен до обкатки стандарта на живом курсе.
