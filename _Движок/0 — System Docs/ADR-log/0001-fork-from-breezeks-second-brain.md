# ADR-0001 — Форк «Второго мозга Бризекс» в Knowledge-OS

- **Статус:** Accepted
- **Дата:** 2026-06-28

## Контекст

Нужно перенести логику и механику «Второго мозга Бризекс» (PARA, канон документа, память, SSOT/DRY,
онбординг) в личный проект, работая через Claude Code. Требования:

1. Переиспользуемость под **любой** будущий проект.
2. **Однообразие** имён/структуры между проектами.
3. **GitLab** как облачное хранилище (свой инстанс, не Бризекс).
4. Базовая работа **без обязательного git** (git — бонус).
5. Русский канон, латинские пути/слаги.

Источник заточен под Cursor-агента (TAIRA/KAIA) и начинён спецификой компании.

## Решение

1. Собрать движок `D:\Knowledge-OS\_Движок` — обобщённый форк канона, очищенный от начинки Бризекса,
   на нативных Claude Code скиллах + `CLAUDE.md`.
2. **Модель A (ссылка):** канон — SSOT в `_Движок\Канон`; проекты ссылаются, не копируют; скиллы —
   user-scope `~/.claude/skills`, исходник в `_Движок\Исходники скиллов`.
3. Каждый проект — **самостоятельное полное PARA-дерево** + свой `CLAUDE.md`.
4. **Git-опционально:** память (CHANGELOG/ADR/BACKLOG) работает без git; GitLab-механику сохраняем,
   но generic (свой инстанс, свои проекты, секреты вне git).
5. **Единый русский нейминг:** один словарь префиксов (максимально по-русски), машинный `type:` —
   английский id; разнобой EN/RU устранён.
6. Закрытый список 17 типов — стартовый, изменяется **только новым ADR движка**.

## Рассмотренные альтернативы

- **Модель B (копия канона в каждый проект):** самодостаточно, но канон расходится между проектами —
  отвергнуто (нарушает SSOT, ту самую болезнь, которую система и лечит).
- **Модель C (гибрид со снапшотом):** оставлено как опция в BACKLOG для переносимости.
- **Git обязателен (как в Бризексе):** избыточно для личного старта — отвергнуто, git сделан бонусом.
- **Оставить смешанные EN/RU префиксы:** противоречит требованию однообразия — отвергнуто.
- **Скиллы project-scope:** не находятся при открытии проекта вне корня OS — отвергнуто в пользу user-scope.

## Последствия

- (+) Правка канона — **один раз** для всех проектов; однообразие; быстрый старт нового проекта.
- (+) Родно для Claude Code (`CLAUDE.md` вверх по дереву, скиллы user-scope).
- (−) Проект не автономен в отрыве от `D:\Knowledge-OS` — митигируется опцией «вморозить снапшот» (BACKLOG).
- Транслит-префиксы (Ранбук/Плейбук/Бутстрап) требуют финального подтверждения — в BACKLOG.
